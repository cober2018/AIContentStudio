# 武器库规则

## 卡片格式（提炼产出）

见 `distill-prompt.md` 的「技巧卡格式」。卡片是素材，不直接进技能。

## 梳理判定

| 判定 | 条件 |
|---|---|
| 新增 | 思路对平台的片子（竖屏讲解、产品视频、Vlog）有用，DaVinci 或 AE 做得出来，现有条目没有 |
| 合并 | 与已有一节同一思路：补进那一节（新的「用在」「不用在」、参数、来源），不另开一节 |
| 替换 | 与已有一节冲突且来源更可信：不直接替换；新做法作为「试用」写进同一节的备选，复盘证明更好后再替换，旧做法退役 |
| 舍弃 | 其他剪辑软件独有且没有思路价值；纯软件入门；与平台现行规则冲突（项目目录、成片命名、响度、字幕生成等以平台为准） |

和平台规则冲突时，平台规则（`finishing.md`、`edit-combos.md`、craft-ae `components.md`、平台流程）优先，课程说法写进该节备注。

## 条目格式

```
### <技巧名>
- 思路：为什么这样剪（一两句）
- 用在：适用场景（片子类型、镜头任务、素材条件）
- 不用在：哪些情况不要用
- 做法：DaVinci 页面 / 工具 / 关键参数，或 AE 效果 / 属性 / 参数
- 脚本：能 / 部分 / 不能（能的写接口名）
- 检查：怎么判断做好了
- 常见错误：……
- 状态：试用 | 常用 | 退役（退役写原因和日期）
- 来源：<来源名> 第 N 集 / 参考片 / 用户经验 <日期>
```

## 换算要求

- 做法只写 DaVinci Resolve 或 After Effects；其他软件的按钮名、快捷键不出现。
- 对方软件的功能在 DaVinci / AE 没有直接对应时，写替代做法；替代不了只保留思路和检查标准，并在「脚本」写「不能」。
- DaVinci 接口名必须用 `search_scripting_api` 查到；AE 用 ExtendScript 属性名，不确定的不写接口名。
- 数值写范围，并说明以什么为准（帧、秒、百分比、像素）。

## 状态

| 状态 | 条件（起始值，复盘时可调，调整记 log.md） |
|---|---|
| 试用 | 新加入的招 |
| 常用 | 在 3 条用户最终采用的片子里用过，且没有明确针对它的修改意见 |
| 退役 | 2 条及以上明确针对它的修改意见，或被更好的做法取代；`choose.md` 移除，条目保留并写原因和日期 |

一条修改意见只有在明确指向该手法（提到它，或指向用了它的镜头且内容和手法有关）时才算针对它。

## 版权

条目全部用自己的话写；只写来源名和集数；不放逐字稿、截图、原话。
