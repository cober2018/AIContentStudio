## MODIFIED Requirements

### Requirement: Aggregated project Versions view
Versions SHALL include immutable Candidate, candidate-bound approval and delivery references from real entities.

### Requirement: Append-only project activity
Activity SHALL record stable candidate/review/delivery events transactionally.

### Requirement: Derived project Overview
Overview SHALL expose pending Content Approval, Delivery Authorization and reconciliation decisions; unknown delivery shall not be flattened into success.
