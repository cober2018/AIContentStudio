- 需求：复刻口播 / 带货视频还缺的叠加效果，和成片三套字一起加进平台。来源见 `../clone-reference-video/findings.md`。

## 要加的
1. 贴在实拍上的贴纸 / 特效 AE 模板：关键词贴纸（黄底描边弹出，如「敏宝可吃」）、红叉划掉（「无香精」）、箭头指向小黄车、手绘圈线、人像抠图白描边换背景、开场钩子（大字 + 特效底）。
2. 字幕关键词变色（如「秋冬换季」变黄）。
3. 数字人 / 口型同步（没有真人出镜时用）。
4. 成片三套字（用户定）：

| 用途 | 字体 | 来源 |

| 钩子 / CTA | 荆南麦圆 | https://github.com/NightFurySL2001/KNMaiyuan |
