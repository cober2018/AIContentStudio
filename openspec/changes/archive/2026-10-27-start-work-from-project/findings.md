# 发现与决定

- 商品视频只能从工作台建，`product-skus/{id}/works` → `save_launch` 每次都新建项目；内容项目里建的项目接不上商品工作台。
- 商品视频工作台按「项目里有没有商品作品」列项目（`/production-workspaces`），所以只要在已有项目里加一条商品作品，它就会出现在工作台。
- 角色内容已经能在项目「作品」页添加，缺的只是新项目的引导。
- 实施时发现：现有商品 SKU-000003（儿童地板鞋）的主图素材（版本 64）已被归档，用它新建视频会报「商品素材不存在、已撤销或版本已变化」，从工作台建也一样。和本次改动无关，没有动，告知用户。
- 商品选择直接复用工作台：项目页跳到工作台时带 `?project=`，不另做一套选商品界面。
- 2026-10-28 发现（既有问题，未改代码）：在项目「作品」页删除商品作品时，`delete_unit` 只删作品，不删 `product_sku_work` 和 `product_creation_launch` 里指向它的记录，之后该商品的「已有作品」列表接口 500。已手工清掉项目 42 旧作品 81 留下的两条记录。
