## 暂不做（需要平台功能，不是 skill）

| clipforge 方法 | 原因 |
|---|---|
| 新增免费来源（Coverr 视频，Freesound 音效，Jamendo 音乐；Wikimedia、Openverse 平台已接） | 要在平台素材搜索里新接来源，是平台功能；skill #10 先写明这些来源的特点，接入另提需求 |
| 数字人生成本身 | 平台还没有数字人功能；skill #11 先把能力和规则归纳好，功能上线时直接用 |
| 批量防同质化（每条换开头机制、形态、声音、配乐） | 需要跨作品排期的平台功能；以后做批量出片时另提需求 |
| 结构指纹（近期作品太像时预警） | 同上，需要读取账号近期作品 |
| 效果飞轮（按发布数据看哪种形态、开头卖得好） | 平台已有「效果复盘」，要接数据另提需求 |

## 舍弃（与平台冲突或平台已有）

自带合成渲染（FFmpeg / Remotion）、免费配音（Edge TTS，平台用 MiniMax）、按逐字稿剪辑、商品链接抓取（平台已有商品资料）、封面 / 二维码 / 发布导出、它的 MCP 和命令行，以及它的抓取和生成代码本身。
