# 设计要点

## 几何
- `SL(i)` 按张数取小图框 [x, y, 宽, 高]：
  - n≤3 用 v1 的公式 `[540+(i-(n-1)/2)*300,380,272,190]`，所以 2、3 张和 v1 一模一样。
  - n=4 用 `[538+(i-1.5)*236,380,224,156]`。
- 大图框 `BIG` 不变：竖屏 [540,880,920,1180]，横屏 [960,580,1400,720]。
- 横屏：`landscape_layouts` 把 `SL` 整段换成 `[960+(i-(n-1)/2)*340,320,272,190]`。4 张也放得下，不分张数。
- 标签：v1 写死最大宽 900；v2 在 Scale 表达式里按当前框宽算可用宽度，`min(1, (框宽-36)/字宽)`。展开时框变大，字回到原大小。

## 时间
- 合成长度：`LENS={"host-parallel":60}`，其他模板仍用 LEN=10。渲染只出 `_duration_ms` 那一段，所以 7 秒的内容只渲 7 秒。
- beats 解析、默认节奏、最后一张在结束前 0.9 秒收回，照 v1 的表达式，只把槽数从 3 改成 4。

## 检查
- `check_safe_area.py`：版本目录从 `VERSIONS` 取（和 `make_previews` 一样）；新增 `--until 秒`，默认 6，所以其他模板的检查不变。
- A、B 两组内容的安全区检查：
  - 把 v2 工程复制到临时模板库，替换里面的数据段，再把这个临时库交给检查脚本。
  - 用 `--until` 设到这组内容的时长。
  - 不给检查脚本加数据参数。
- 检查渲染用 `$CLAUDE_JOB_DIR/tmp` 里的临时脚本，按 `make_previews` 的做法替换数据、调 aerender。临时脚本用完删。
