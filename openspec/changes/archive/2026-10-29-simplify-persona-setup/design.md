# 设计

| 项 | 做法 |
|---|---|
| 新建角色 | 角色目录「新建角色」显示表单：名称、品牌（下拉，可就地新建品牌）、声音（声音配置下拉，必选）、四个选填项；提交 = 在该品牌下建角色 + 存第一版资料 + 写声音绑定 |
| 声音锁定 | `voiceover.set_persona_preset` 已有绑定时拒绝更改（`voice_preset_locked`）；角色「音频」里的声音选择器在已绑定时只显示；作品层的临时改选不受影响 |
| 资料编辑 | 页面每项一个输入框；保存时：有内容 → 写入该项；空 → 不写（等同原「继承」）。原「清除」不再提供；已有「清除」的值读回显示为空 |
| 表达风格 / 视觉语言 | 页面用多行文字；存储时包成 `{"text": "…"}`（原 JSON 结构的老数据读回时转成文字显示，保存前不改动）；读取方（检查、写作 skill）对 `text` 键已能当说明读 —— 实施前逐一核对 |
| 高级 | `<details>` 收起：公开事实规则（仍为 JSON，带示例说明）、长期观点、价值主张、品牌语气版本、创作配置整页 |
