# 简化角色与账号的设置

## 为什么

用户反馈「角色与账号」要填的太多、选项太多，不知道怎么选，也不确定是否必要。现状：资料 11 项，每项先选「继承 / 清除 / 覆盖」才能填，4 项要手写 JSON；「创作配置」按文字 / 图文 / 音频 / 视频各有主方法、风格预设、质量标准、模型、附加方法等一串下拉；建角色要先进品牌的「关联与管理」，只能填名字。用户同时要求：声音在建角色时定下，之后不能改；同一套声音可以给多个角色用。

## 改什么

1. **建角色一张表单**（角色目录「新建角色」直接可用）：必填名称、所属品牌、声音（选一套声音配置）；选填定位、目标受众、内容领域、内容边界。
2. **声音建完锁定**：角色页只显示所用声音，不能改；老角色还没选声音的，允许补选一次，选定后锁定。同一套声音配置可被多个角色共用。
3. **资料直接填**：去掉每项的「继承 / 清除 / 覆盖」选择，填了就算这个角色（账号、栏目）的，空着就是没有。
   - 常用：定位、目标受众、内容领域、内容边界、风险边界、表达风格、视觉语言（后两项改成大白话填写，不写 JSON）。
   - 「高级」里（默认收起）：公开事实规则、长期观点、价值主张、品牌语气版本。
   - 账号、栏目编辑资料同样处理。
4. **创作配置收进「高级」**：默认不展开；里面原有功能不变。

## 不做

- 不删任何已有资料数据，也不改各项资料在选题、写作、检查里的用法。
- 不改账号的平台连接、内容记忆。
- 角色彻底删除（另提）。
