# 新作品导演稿面板误显示「导演稿 已采用」

## 为什么
新建的商品视频还没写导演稿，左侧步骤栏正确显示「待开始」，但导演稿页的链路面板显示「导演稿 已采用」。
原因：`VideoChainPanel.tsx` 用 STEPS 把链路状态归到「导演稿 / 小样 / 成片」三段，「待开始」（not_started）不在任何一段里，算出来不是当前段；不是当前段时面板一律按「已经过了」处理，导演稿段就写成「导演稿 已采用」。

## 改什么
- 把「待开始」归到导演稿这一段：导演稿页显示「待开始」和说明（在接了 MCP 的第三方模型里说「做这个视频」开始），没有采用/修改按钮；小样、成片段照旧显示「还没到」。

## 不改什么
- 后端状态与其他步骤显示不变。
