# 角色作品也能补镜头；九宫格改成按一致性分组、在弹框里做

## 为什么
- **角色作品卡住：** 作品 94「如何判断过敏体质」（项目 49，角色创作，人设「懒羊羊小王」，没有形象照）的导演稿已经采用。shot-5、10、14、18、21 这 5 个补充镜头没有用户素材。现在生首帧、九宫格、图生视频、手动上传都只给商品作品，所以这个作品卡在这一步。
- **九宫格的用法不对：** 九宫格的作用是让一组镜头里的人物、场景保持一致。现在它默认把所有镜头都画进去，零散、互不相关的补充镜头也一起画，不对。

## 用户确认的做法
- **怎么出视频（每个缺素材的镜头）：**
  - **自动：** 平台调图生视频模型，按条计费，用户自己点。
  - **手动 · 文生视频：** 平台给提示词，中文、英文都有。
  - **手动 · 图生视频：** 平台先出图，再给配套的图生视频提示词。用户拿图和提示词去第三方工具生成视频，再上传。
- **要不要九宫格，模型按规则定，不由人选：**
  - 几个要生成的镜头需要同一个人物，或者在同一个场景里，就归成一组，用九宫格一次出图。
  - 互不相关的零散镜头不归组，单张出图或者用文生视频。
- **九宫格在弹框里做：** 九宫格是针对一组镜头的精细操作，放进单独的弹框。商品作品和角色作品都用这个弹框，旧的九宫格面板删掉。

## 改什么

### 1. 导演稿记分组（模型写，用户审）
- **新字段：** 导演稿加一个可选字段 `consistency_groups`，每组写这些：
  - `id`；
  - `shot_ids`：至少 2 个镜头，一个镜头只能在一组；
  - `person`：这组共用的人物描述，可以空；
  - `setting`：这组共用的场景描述。
- **校验：** 镜头必须存在，不能是模板、素材库镜头（board.source_kind 为 ae_template / library）。不按「已有素材」拦：组里的镜头生成后会挂上视频，之后存导演稿不能因此被拒。
- **审导演稿时：** 导演稿审阅页列出分组，例如「九宫格组 g1：镜头 3、4、5 · 场景：…」，用户采用导演稿时一起看到。
- **模型规则（video_chain 规则和 MCP 说明）：** 写导演稿时，要生成画面的镜头里，需要同一个人物或同一个场景的，归成一组写进 `consistency_groups`；零散、互不相关的镜头不归组。改分组等于改导演稿，要重新采用。
- **作品 94：** 导演稿没有分组，5 个补充镜头都按零散镜头处理，不用重写导演稿。

### 2. 九宫格按组出图
- **接口：** 平台接口和 MCP 的 `generate_storyboard_grid` 改成按组出图（传 `group_id`），用这一组的镜头、人物、场景。不再有「默认画全部镜头」。
- **商品作品：** 照旧带商品主图，逐格做商品检查，最多重画 3 次。
- **角色作品：** 不带商品图，不做商品检查，说明文字不提商品。
- **提示词：** 组里每一镜的首帧提示词、图生视频提示词，都带上这组共用的人物和场景，图和视频前后一致。
- **单格重画、用作首帧：** 和现在一样。

### 3. 页面
- **镜头面板（商品作品、角色作品共用）：** 只列缺素材的镜头。
  - **归了组的镜头：** 显示「九宫格组 g1」和「打开九宫格」按钮，在弹框里出图。
  - **没归组的镜头：** 和现在一样：手动 / 自动、自动生成（先确认计费）、生成首帧、下载首帧、上传做好的视频。角色作品的首帧输入框是空的时候，自动填入按分镜写的提示词。
  - **角色作品手动时，** 没归组的镜头分「文生视频」「图生视频」两栏，提示词中文、英文各带「复制」，底下共用「上传做好的视频」。归了组的镜头只走图生视频。
  - **角色作品文字：** 不提商品。标题叫「补充镜头」，不显示品类、风格，「改回商品原图」改成「不用这张首帧」。
  - **商品作品：** 除了九宫格入口，其他都不变。
- **九宫格弹框：** 一次处理一组：
  - 组里的镜头、共用的人物和场景、参考图；
  - 「生成九宫格」（先确认计费）、生成进度、整张分镜图；
  - 每镜一块：候选图、用作首帧、只重画这一镜、下载首帧、图生视频提示词（中文、英文，可复制）、手动 / 自动、自动生成、上传做好的视频。
- **旧面板：** 删掉 `StoryboardGridPanel` 这块页面面板。
- **人物提示：** 人设没有形象照时，面板和弹框都写明「这个角色没有形象照：生成画面里不出现人物，只拍场景，拿东西只出现手部」。
- **网上找图：** 保留。

### 4. 后端其他改动（同一套接口）
- **接口范围：** 下面这些接口接受角色作品（`production_domain = persona`），其他类型的作品照旧拒绝。改运镜、发布文案照旧只给商品作品。
  - 提示词、手动 / 自动、生首帧、设首帧；
  - 自动图生视频、查进度、上传；
  - 九宫格、单格重画。
- **页面数据：** 读镜头状态的接口对角色作品也返回数据，加 `persona: true` 和分组。
- **角色作品的提示词：** 按这一镜分镜里的画面、运镜、人物态度写，不带商品：
  - 固定规则把「商品外形、logo 不变」换成「画面里的东西不变形、不凭空出现或消失」；
  - 另外返回文生视频提示词（中文、英文，写明画幅和时长）。
- **角色作品生首帧：**
  - 不带商品参考，不检查，生成一次就设为首帧；
  - 有形象照就带上；
  - 不拦亮相镜头；
  - 提示词里已经有人物规则时，不重复追加。
- **人物规则：**
  - 有形象照：人物照形象照来，同一个人，不换脸。
  - 没有形象照：「画面里不出现人物（不露脸、不出现身体），只拍场景；需要拿东西时只出现手部」（英文同义）。所有提示词都带上这句。
- **自动图生视频：** 角色作品没有首帧时，提示「这一镜还没有首帧，先生成首帧，或切到手动」。
- **素材标记：** 不加新标记，手动上传照旧标「上传」。

### 5. MCP 和规则
- **工具说明：** 下面 7 个工具改成「商品作品和角色作品」，写明角色作品的区别和分组规则：
  - `get_shot_video_prompt`、`set_shot_video_mode`；
  - `generate_shot_image`、`set_shot_first_frame`；
  - `generate_shot_video`、`get_shot_video`；
  - `generate_storyboard_grid`。
- **video_chain 规则：**
  - 第 3 条改成两类作品都适用；
  - 加一条分组规则；
  - 加一条角色作品的做法和人物规则。
- **prompt-direction skill：** 九宫格那两处改成按组出图。

## 不做
- 运镜下拉、发布文案不给角色作品。
- 平台不自己判断分组：分组由模型写进导演稿，用户审。
- 不改作品 94 的导演稿，不替用户选素材。
- 验收不调用计费的生图、生视频，自动生成由用户自己点。
- 作品 93 只读，不碰。

## 验收
| 项 | 怎么验 |
| --- | --- |
| 作品 94 的入口 | 数据库副本上读作品 94 的镜头状态：5 个镜头都在缺素材列表里，都没归组，页面上每镜都有入口 |
| 两种提示词 | 副本上取提示词：文生视频、图生视频（中文、英文）和首帧提示词都不提商品，都写了不出现人物 |
| 手动上传 | 副本上上传测试视频：放到那一镜，`get_shot_slots` 读到已选，`prepare_video_edit` 开出的小样任务输入里有它 |

| 生首帧、自动图生视频 | 副本上打桩走通：角色作品首帧不带商品参考，生成后设为首帧，自动图生视频用这张首帧提交 |

| 测试 | 全量测试、前端类型检查通过（已知 5 个旧失败除外）；九宫格相关的旧测试按新的按组出图改预期 |
