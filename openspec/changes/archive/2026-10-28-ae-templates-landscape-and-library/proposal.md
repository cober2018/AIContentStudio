# AE 模板横屏版 + 模板库预览 + 默认由大模型选模板

## Why

上一批 46 个竖屏模板已入库，但：横屏（16:9）片子没有模板可用；模板只能被第三方模型通过「列出模板」看到文字说明，人和模型都看不到动画长什么样；也没有写清楚什么时候由模型自己选模板、什么时候必须用用户点名的效果。

## What Changes

- **横屏版**：46 个模板各加一个 16:9 版本（同一模板 id、同一版本号、同样的字段和用法），横屏单独排版，按 16:9 播放安全区（x 91–1828、y 190–959）排版并用检查工具零越界。渲染时按画幅选工程；某个模板没有该画幅版本时明确报错，不拉伸凑合。分三批做（16 / 16 / 14），每批出「横屏两套内容 + 竖屏对照」的对比视频给用户验收。
- **预览进模板库**：每个模板每个画幅一段预览视频，跟模板工程放在一起；说明书记录预览文件和模板类别（九类）。预览渲染脚本放进 craft-ae（以后新模板照此出预览）。`list_ae_templates` 返回类别和预览位置。
- **设置页「AE 模板库」**：只读页面，和「素材数据源」并列；按类别列出模板，切换竖屏 / 横屏播放预览，显示用法、文字字段、图片要求。
- **谁来选模板**：默认由大模型按内容自己选、自己用；用户在微调时明确点名某个效果，就必须用那个模板。规则写进 craft-ae SKILL.md 和 MCP 工具说明。

## 不做

风格体系（一套风格规定用哪几类效果）；商品工作台的模板（下一个需求）；新增模板种类。

## Impact

- `apps/api/craft_skills/craft-ae/`：make_templates.py（横屏布局）、新预览脚本、manifest（横屏工程、预览、类别）、SKILL.md / templates.md。
- `apps/api/app/services/craft_skills.py`：按画幅选工程、预览文件读取；`creative_mcp.py`：渲染参数加画幅、工具说明。
- `apps/api/app/routers/`：模板列表与预览视频接口；`apps/web`：设置页新增「AE 模板库」。
