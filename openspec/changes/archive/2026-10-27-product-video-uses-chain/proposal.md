## Why

商品视频的制作页还是旧流程（导演方案 → 视觉与声音定样 → 逐镜素材 → 剪辑包装 → 成片与反馈），由平台模型生成。角色视频已经换成第三方模型通过 MCP 主导的新流程（导演稿 → 素材 → 配音与音乐 → 小样 → 成片），用户在页面上审三处。商品视频页面没有这三处审阅，也没有「平台写作 skill」开关：第三方模型做商品视频时写完导演稿会卡住，用户也找不到开关。后台视频链路本身对商品作品是通的（已用项目 42 读到视频需求）。

## What Changes

- **商品视频改用新流程：** 制作页步骤改为「商品与本条目标 → 导演稿 → 素材 → 配音与音乐 → 小样 → 成片 → 交付」，和角色视频一致，由第三方模型主导，用户在导演稿、小样、成片三处审阅。
- **保留商品那一步：** 「商品与本条目标」沿用现有商品页内容（商品资料、购买理由等）。
- **开关随之出现：** 导演稿这一步显示「平台写作 skill」开关。
- **去掉旧的商品步骤页面：** 导演方案、视觉与声音定样、逐镜素材、剪辑包装、成片与反馈这几页不再显示（按「只留新版本」）；旧链接打开时落到新流程当前步骤。

## Impact

- Web：`ProductionWorkspace.tsx` 中视频新流程的判断从「角色视频」扩大到所有视频作品，商品作品的步骤表改为新流程，商品目标一步保留商品组件；旧商品步骤的入口去掉。
- API：不改；如页面需要的状态接口对商品作品有限制，按需放开。
