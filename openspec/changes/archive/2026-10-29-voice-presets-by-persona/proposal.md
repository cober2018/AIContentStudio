# 声音配置跟着账号角色走

## 为什么

用户要不同项目用不同的声音（现在用男声，还要一套女声）。现状：一键配音只用「设置 → 配音」一套；商品作品「制作设置」里的「本作品音色 ID」能填但没人读；角色「音频」配置里选的音色也没接到一键配音。用户决定：内容属于哪个账号角色在建项目时就定下，声音跟着角色走；商品另建一个「电商」角色维护成女声。

## 改什么

1. **声音配置可存多套**（设置 → 配音）：每套有名字，各带音色、情绪、语速、音量、音调等；现有这套迁成「男声」，并设为默认；用户可新建「女声」等。
2. **账号角色选声音配置**：角色的「音频」里原来的音色选择换成选一套声音配置（只留这一处，不再两处各存音色）。
3. **作品属于哪个角色**：
   - 内容作品本来就属于角色，声音跟角色。
   - 商品作品发起时选「属于哪个账号角色」（可留空，空则用默认声音配置）；只借角色的声音和账号身份，脚本仍按商品品类和风格 skill 写。
   - 作品可临时改选另一套声音配置（不改角色）。
4. **生成配音取声音的顺序**：作品临时改选 → 所属角色的声音配置 → 默认声音配置。剧情类多角色配音照旧按角色分声音，旁白用上面这套。
5. 删除商品「制作设置」里手填的「本作品音色 ID」（被第 3 条替代）。

## 不做

- 新建「电商」角色、录女声：由用户在页面上做，平台提供入口。
- 数字人形象。
