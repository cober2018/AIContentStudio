## 流程

| 步骤 | 做什么 | 产出 |
|---|---|---|
| 1 梳理 | 逐张读卡片，必要时看截图；判定保留 / 合并 / 舍弃 | `triage.md`（每张卡一行：判定、理由、去向条目） |
| 2 提炼 | 保留的卡写思路、适用场景、检查标准、常见错误 | 写进对应条目 |
| 3 换算 | 写 DaVinci 或 AE 做法；用 DaVinci Resolve MCP 的脚本文档核对菜单和接口 | 写进对应条目，标注能否用脚本 |
| 4 入库 | 更新两个 `SKILL.md` 的目录表 | 通过 MCP 读一遍每个新条目 |

## 判定规则

- **保留**：思路对竖屏讲解、产品视频或 Vlog 有用，且 DaVinci 或 AE 能做出来。
- **合并**：同一思路拆成了多张卡，或和现有 `edit-combos.md`、`finishing.md`、`components.md` 已有内容重复。和现有内容冲突时，以平台现行规则为准，在条目里写明课程的不同说法。
- **舍弃**：剪映独有且没有思路价值（如 VIP 限制、主轨磁吸）、纯软件入门、和平台流程无关的内容。

## 条目格式

每个条目文件按类别列技巧，一个技巧一节：

```
### <技巧名>
思路：为什么这样剪（一两句）
用在：适用场景
不用在：哪些情况不要用
状态：试用 | 常用 | 退役
DaVinci：在哪个页面、哪个工具、关键参数（或 AE：哪个效果、哪个属性）
脚本：能 / 部分 / 不能（能的写出用哪个接口或 ae_build 字段）
检查：怎么判断做好了
常见错误：……
来源：课程第 N 集
```

## 归属

| 类别 | 放在 |
|---|---|
| 节奏、镜头组接、转场、声音与音乐、调色、导出与规格、工作流效率 | `craft-resolve/techniques/` |
| 包装与特效、字幕与标题（动态文字、跟踪贴字、抠像合成） | `craft-ae/techniques/` |

一个技巧两边都能做时，写在更顺手的那边，另一边引用。

## 版权

条目全部用自己的话写，只标注课程名和集数作为出处；不放逐字稿、截图和原话。

## 选用

- `craft-resolve/choose.md`：按「片子类型 × 镜头任务 × 手头素材」查表，从问题找到一两个候选办法；只列试用和常用的招。
- 克制规则写在 choose.md 开头：默认硬切 + 配音节奏；每招说出解决的问题；同类手法一条片最多一两次；特效、转场、光效只放关键点。
- 导演稿镜头备注写手法和理由；试用招标「试用」。

## 进化

| 状态 | 条件 |
|---|---|
| 试用 | 新进来的招 |
| 常用 | 在 3 条用户采用的片子里用过，且没有针对它的修改意见 |
| 退役 | 2 次以上针对它的修改意见，或被更好的招取代；条目里保留一行退役记录 |

阈值是起始值，复盘时可按实际调整，调整写进维护记录。

## 维护技能 `.codex/skills/craft-arsenal/`

| 文件 | 内容 |
|---|---|
| `SKILL.md` | 何时用（加新招 / 复盘）、两条流程的步骤 |
| `distill-prompt.md` | 给提炼 Agent 的提示词（本次那份，路径参数化） |
| `rules.md` | 卡片格式、梳理判定、DaVinci / AE 换算要求、条目格式、状态规则、版权要求 |
| `log.md` | 维护记录：日期、来源、增删改、依据 |

复盘的数据：平台视频链已有的导演稿（镜头备注）和用户决定、修改意见；通过本地 API 读取。
