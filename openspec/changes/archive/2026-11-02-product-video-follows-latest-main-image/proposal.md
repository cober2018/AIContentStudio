# 商品视频跟随商品最新主图

## 为什么
商品换了主图后，已经建好的视频还在用旧主图。项目 46 / 作品 90 挂在商品 8 的第 1 版（主图素材 315）上，商品已经到第 3 版（主图 319），但镜头静帧生成、商品一致性检查、图生视频参考图都还拿 315。

原因：`product_video.references()` 是这几处共用的取图入口，它读的是作品启动时冻结的那一版（`ProductSkuWork.sku_revision_id`）的主图；只有那一版没有主图时才去找最新版。任务书里显示的主图（`direction()`）同样读冻结版本。

## 改什么
- 主图一律取该商品**最新一版**的主图（最新版没有主图就往前找最近一张）。只换图，卖点、名称等商品资料仍按作品启动时冻结的版本，不变。
- 影响范围（都经 `references()` / `direction()`，改一处全生效）：镜头静帧生成、商品一致性检查、图生视频参考图、导演稿/任务书里显示的主图。
- 作品自己手动指定了商品参考图的，仍以手动指定为准，不被覆盖。
- 已经生成好的静帧和视频不动；之后新生成的才用新主图。
- 作品页在商品参考图旁标注当前用的是「第 N 版主图」，主图换过时显示「已跟随商品最新主图」，方便确认。

## 不改什么
- 不改商品资料冻结规则，不批量重新生成已有镜头。
- 不加「切换主图」按钮：跟随最新是默认行为，不需要手动切。

## 用户已有数据
作品 90 改完后即用主图 319，无需数据迁移。
