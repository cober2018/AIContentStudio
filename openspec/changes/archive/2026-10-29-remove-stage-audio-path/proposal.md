# 删掉「按阶段制作音频」的老路

## 为什么

配音已经统一走一键配音（声音配置 + MiniMax + 文件检查）。平台早期的「按阶段制作音频」（口语稿 → 配音方向 → TTS 阶段 → 音频质检 → 音频字幕识别）以及音频质量标准，现在没有作品在用新的，用户要求不留冗余、直接删掉（MVP 未上线，没有生产包袱）。

## 删什么

- 按阶段配音、音频质检、音频字幕识别三个阶段（`stage_audio.py`、`stage_audio_asr.py`、`audio_quality.py` 的质检部分，对应的节点注册和阶段分支）。
- skill：配音方向（voice-director）、直接配音（tts）、音频质检（qc）。
- 音频质量标准两套（讲解 / 聊天）。
- 「音频」这种作品形态：角色创作配置的「音频」页、两个起步角色模板里的音频配置、文字 / 视频作品上的音频配方选项。
- 商品作品里没人读的 `audio_creative_profile`、`voice_id`（声音只认声音配置）。

## 保留并挪位置

- 视频母带响度（`master_loudness`，剪辑前第三方模型会调用）→ 挪到独立模块。
- 「这个角色的声音」→ 从「音频」页挪到角色「编辑资料」页。
- 口语稿 skill（改成口语稿）→ 保留，作为视频 / 文字共用的写作 skill。
- 视频字幕识别（ASR 建议）、一键配音、素材里的音频、MiniMax 配音接口：不动。

## 已有数据怎么处理

- 用户决定（2026-10-29）：平台只保留看得到的 3 个项目（海底光缆、儿童麸质饼干、测试·头戴耳机开箱），其余 36 个归档项目连同作品、稿子、制作记录、专用配方、只被它们用到的素材一起彻底删除（已执行，见 progress.md）。原本绑着音频阶段的 11 个文字作品随之删除，不再需要解绑。
- 角色修订里的音频配置：各角色存一版新修订去掉，旧修订作历史。

## 不做

- 不删已生成的音频素材（25 条，含配音和母带）。
