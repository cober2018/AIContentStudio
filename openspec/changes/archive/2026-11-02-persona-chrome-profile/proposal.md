# 每个角色用自己的 Chrome 个人资料打开平台

## 为什么
平台不保存 Cookie 和密码，跳转发布页靠浏览器里已有的登录。可同一个浏览器里每个网站只能登录一个号，角色一多就要来回退出重登。
Chrome 的「个人资料」各自有独立的登录状态。一个角色对应一个个人资料，各平台在里面各登录一次，之后切角色不用重登。平台跑在本机，后端可以直接让本机 Chrome 用指定的个人资料打开网页。

## 改什么
1. 角色「编辑资料」里加一块「浏览器」：从本机 Chrome 已有的个人资料里选一个（只读取名称），可不选。
   - 选择保存在系统设置里（和角色声音的做法一样），不进角色资料修订，不进作品快照。
   - 两个角色不能选同一个个人资料（同一平台会互相挤掉登录）。
2. 账号页的「去发布 / 去写作 / 账号主页」：
   - 账号归属角色选了个人资料 → 点击后由本机用该个人资料在 Chrome 里打开；
   - 没选、或是不挂角色的账号 → 和现在一样在当前浏览器新标签打开。
   - 后端只打开这个账号自己的入口地址或主页链接，不接受任意网址。
3. 角色概览「声音」旁显示所选的 Chrome 个人资料名。

## 不改什么
- 不读取、不保存 Cookie、密码或浏览历史；只读 Chrome 的个人资料名称列表。
- 不替你登录、不自动发布。第一次仍要在每个个人资料里把各平台登录一遍；公众号等登录过期的仍要重新扫码。
- 不新建 Chrome 个人资料，个人资料在 Chrome 里自己建。
- 只支持本机 macOS 上的 Google Chrome。
