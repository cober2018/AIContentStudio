# findings

- 本机有 Google Chrome，个人资料列表在 ~/Library/Application Support/Google/Chrome/Local State 的 profile.info_cache（目录名 → 显示名），现有 6 个，其中一个叫「知数造物」。
- 打开方式：open -na "Google Chrome" --args --profile-directory=<目录名> <网址>。
- 用户确认用 Chrome；一个角色对应一个 Chrome 个人资料（不是谷歌账号）。
- 选择放系统设置而不是角色修订：它是本机操作配置，不该进作品快照，和角色声音的存法一致。
- 本机有两个个人资料都叫 datakownledge（Profile 1、Profile 5），下拉里同名的会带上目录名区分。
