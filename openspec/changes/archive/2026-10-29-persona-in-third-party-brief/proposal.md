# 角色资料和定制方法交给第三方模型

## 为什么

视频（导演稿 → 小样 → 成片）和文章 / 图文的「第三方模型」模式，平台给模型的简报里没有角色信息：角色的定位、受众、表达风格、边界都没带，「高级：创作配置」里「在这里完整设置」的主方法、风格预设、质量标准、附加方法也不生效。用户要求两样都接进去。

## 改什么

1. **简报加「角色」一段**（视频简报、文章 / 图文简报都加）：作品所属角色的名称、品牌、所用声音，以及合并后的资料（角色 → 账号 → 栏目逐层覆盖后的结果）：定位、目标受众、内容领域、表达风格（含不能出现的词）、视觉语言、内容边界、风险边界、公开事实规则。
2. **定制方法**：这条作品对应形态（文字 / 图文 / 视频）的创作配置选了「在这里完整设置」时，简报写明：主方法 skill（可直接用 `get_craft_skill` 读）、风格预设的设置、质量标准要查的项、这一步的额外要求、附加方法与参考风格的内容。规则写明：有定制就按定制方法写，没有就按平台创作 skill 的默认选法。
3. **能读到角色指定的 skill**：角色指定的主方法即使不是最新版本，也允许第三方模型读取。
4. **商品作品**：选了角色的，只带角色的资料和声音，不带角色的写作方法（脚本仍按商品品类和风格 skill 写）。
5. 「平台创作 skill」开关关掉时，只带角色资料，不带定制方法。

## 不做

- 不改角色资料、创作配置的填写和存储。
- 不改平台模型按阶段制作的那条路。
