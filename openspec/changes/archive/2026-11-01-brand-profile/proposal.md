# 品牌页放品牌自己的信息，并进入创作

## 为什么

品牌和角色现在共用一套资料字段（定位、受众、表达、视觉、观点与边界），品牌页看起来像在配置角色；品牌填的字段会被旗下角色当成自己的继承下去。现有数据里品牌「母婴博主nina」的定位填的是「母婴博主」，旗下「懒羊羊小王」因此继承了这个定位。用户要品牌页放品牌该有的信息，并且这些信息要进入创作（2026-11-01 确认）。

## 改什么

### 1. 品牌资料换成品牌自己的字段

| 区块 | 字段 |
| --- | --- |
| 品牌是什么 | 一句话介绍、品牌主张 / 口号、主营产品或服务（列表） |
| 品牌调性 | 语气要求（列表）、常用词、禁用词 |
| 视觉识别 | Logo（通用素材库里的图片，最多 3 张，须本人上传、允许模型使用）、主色（色值列表）、字体（名称列表） |
| 统一红线 | 合规要求、不能说的话（列表） |
| 旗下角色 | 只展示关联到此品牌的角色 |

- 品牌的调性直接写在品牌页。现有的「品牌语气版本」是全局模板、不挂在品牌上，创作里也没有使用，品牌页不再提供这个选择（模板本身这次不动）。
- 品牌页的「概览 / 编辑资料」换成上表；「修订历史、关联与管理、内容记忆」保留。

### 2. 角色不再从品牌继承字段

受众、表达、视觉、观点与边界只来自角色、账号、栏目自己的资料；品牌信息作为单独的「品牌」一块，不覆盖角色字段。

### 3. 品牌信息进入创作

- **第三方模型**：视频简报、文章简报里的角色信息旁边加 `brand`：介绍、主张、主营、调性、常用词 / 禁用词、红线、视觉识别（Logo 素材编号、主色、字体），并写明「品牌调性和红线旗下所有角色都要遵守；角色自己的表达优先，与品牌冲突时以品牌红线为准」。
- **平台模型**：作品的身份快照同时冻结当时的品牌资料；平台写稿的任务包带上同一块品牌信息。
- **原稿检查**：品牌禁用词和「不能说的话」与角色的禁用说法一起做硬检查，命中即拦下。

### 4. 现有数据

- 「知数造物」还没有品牌资料，改完后由用户填写。
- 「母婴博主nina」现有的定位 / 受众 / 内容领域（母婴博主；宝爸宝妈；婴幼儿用品与教育）**实施前先给用户看**，由用户决定挪到「懒羊羊小王」角色上还是删除；旧字段不再作为品牌资料保留。
- 已有作品的身份快照不改（历史留痕）；新建作品起用新规则。

## 不做

- 不改「品牌语气版本」模板本身，不删除。
- 不改角色、账号、栏目页面已有字段。
- 不做品牌层级之外的新功能（如多品牌合并、品牌素材库）。
