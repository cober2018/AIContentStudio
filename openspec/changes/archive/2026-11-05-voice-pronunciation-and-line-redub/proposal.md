# 配音指定多音字读音；只重配一句并原位换进现有配音

## Why
作品 95（项目 50）第 34 镜台词里的「去重」被 MiniMax 读成 qù zhòng。平台没法指定读音，只能把台词改成「去掉重复」再整条重配。

整条重配后，新配音每句长短都和原来不同（最多差 1 秒），声音和已经剪好的画面、字幕对不上。最后只能手工把新旧两条配音拼起来：加一条口播声音轨，再让用户多通过一次导演稿。

后面还有 40 篇文章要做，多音字（重、行、长、调、降等）还会遇到。

## What Changes

### 一、指定读音
- **导演稿字段：** `voice` 加可选字段 `pronunciation`（字符串列表），每条写成「原文/(拼音带声调数字)…」，例如 `"去重/(qu4)(chong2)"`。
  - 由第三方模型写导演稿时填写，随导演稿一起给用户通过。
  - `voice.mode` 为 none / recorded / tts 时都可以带。
- **格式校验（`video_documents` 的 video.master.v2 校验）：**
  - 每条不超过 40 字，最多 50 条。
  - 必须是 `原文/(xx1)(yy2)` 形式：原文非空、不含 `/`；括号个数和原文字数一致；拼音是小写字母加 1–5 声调数字。
  - 不合格报 `video_voice_pronunciation_invalid`。
- **生成配音时带上读音：**
  - `minimax_cli_provider._synthesize` 请求体带 `"pronunciation_dict": {"tone": [...]}`（对象，不是数组；平台直接调 t2a_v2，不经过 CLI）。
  - 整条配音、多角色配音、指定镜头配音（dub_persona）、只重配一句，都带上。
  - 配音参数校验（`tts_parameters`）放行这个字段。
  - 「同样台词同样设置直接复用已付费配音」的判断把读音算进去：读音改了不会复用旧配音。
- **配音不丢读音：** 生成配音后改写 `voice` 时保留 `pronunciation`。
- **告诉模型有这个字段：** `get_video_brief` 的配音设置里加一段说明（字段格式和例子）。`save_director_draft` 的工具说明也写上。

### 二、只重配几句、原位换进去
- **入口：** `generate_video_voiceover` 加可选参数 `lines`（script block id 列表，1–20 个）。不给 `lines` 时行为和现在完全一样。
- **适用范围：** 当前 `voice` 是一条整条 TTS 配音（mode tts、有 material_revision_id）。以下情况拒绝并说明原因：
  - 指定镜头配音（dub_persona）的作品。
  - 时间线上有口播声音轨（dialogue）的作品：那时成片的声音由声音轨决定，换整条配音不会生效。
  - 指定的句子不存在。
  - 句子在当前配音里找不到位置。
- **找出当前配音里每句的起止：**
  - 当前配音有逐句时间（TTS 返回的字幕）时，按台词把字幕分组，和现在对齐镜头的做法一样。
  - 没有逐句时间（has_timing=false）时：
    1. 用停顿检测（-40 dB、至少 0.15 秒）把配音切成有声段。
    2. 按台词字数比例，把连续的有声段分给各句。
    3. 核对：有声段至少和句子一样多；每句的语速在整条平均语速的 0.6–1.6 倍之间；导演稿里已有字幕时，每句起点和这句第一条字幕起点相差不超过 0.3 秒。
    4. 任何一项不过就报 `voiceover_line_split_unclear`，说明哪一句对不上，不猜。
- **重配：** 只为指定的句子各调一次 MiniMax（用这句原来的音色和设置，带读音），只收这几句的钱。新音频去掉首尾空白再放。
- **放置：**
  - 新句从原句起点开始。
  - 新句比原句短：后面补静音，下一句不动。
  - 新句更长：先用掉它后面的停顿，和下一句之间至少留 0.25 秒。还放不下就报 `voiceover_line_too_long`，说明还差多少秒，不变速、不挤其他句。
- **拼成新的整条配音：**
  - 原配音只在指定句子前后的停顿里切开，接缝加 1 帧淡变（按作品帧率），总长不变。
  - 存成一条新的配音素材，放进项目「音频」文件夹。
  - 导演稿：
    - 更新 `voice.material_revision_id`。
    - 这几句的字幕换成新音频的逐句时间（没有逐句时间就按字数分配），平移到新位置。
    - 镜头时长、其他句子、其他字幕都不动。
- **返回：** 每句的原起止、新起止、接缝位置（毫秒）、费用句数和新配音的 id。

## 待用户决定
「只换声音、不改画面和时长」的保存，要不要用户再通过一次导演稿？

建议：不需要。现在整条重配后保存也不需要再通过（导演稿只认画面内容的改动），只重配几句和它一致。台词改动本身仍按现有规则，要重新通过导演稿。

## 不在本次范围
- 不改配音页面的其他功能。
- 不改整条重配的现有行为。
- 不处理已经手工拼过、带口播声音轨的作品 95 的现有配音（见上面的拒绝条件）。
