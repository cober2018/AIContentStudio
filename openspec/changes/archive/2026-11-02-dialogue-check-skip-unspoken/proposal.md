# 对白音量检查不算没人说话的镜头

## 为什么
项目 48 / 作品 93 小样（任务 40）提示「对白音量不均」，第 8 镜比中位数低 13.9 LU。第 8 镜是结尾小黄车镜头，没人说话、只有配乐，导演稿写 speaker: "none"，但挂了一句只作屏幕字幕的台词块，于是被当成对白量了配乐。原因：delivery_checks.spans() 只看 script_block_id 判断有没有人说话。

## 改什么
- 判断「有人说话」同时看 board.speaker：speaker 为 none 的镜头不量对白音量、不参与中位数比较；亮度与过曝照查。按时间线和按镜头时长两处都改。

## 不改什么
- 其他检查与阈值不变。
