# 平台账号只记账号本身

## 为什么
现在账号放在「品牌 → 角色 → 账号 → 栏目」这条资料链里，和角色用同一套资料编辑：
- 账号有概览、编辑资料、修订历史，能覆盖角色的说话方式，看起来像第二个角色；
- 账号下面还能建「账号栏目」、设账号默认流程，和角色重复；
- 还能只填名字建一个不属于任何平台的「账号」；
- 真正要用的东西反而没有：点一下打开这个账号的发布页、写作页。

账号该怎么说话全部由角色决定。账号只记账号本身。

现有数据：2 个账号（知数Talk·公众号、百家号1号·百家号），账号资料修订、账号栏目、账号默认流程、账号快照都是 0 条，删掉不丢内容。

## 改什么
1. 账号只剩一页「账号信息」：
   - 平台、账号名、公开标识（已有）；
   - 归属角色：一个账号只属于一个角色，同一角色在同一平台只能有一个在用账号；
   - 主页链接：用户自己填，可空；
   - 跳转入口：按平台给「去发布」「去写作」按钮，打开该平台创作后台，在你已登录的浏览器里直接进入；
   - 公众号接口连接（发草稿用，已有，原样保留）。
2. 删掉账号资料这一层：
   - 账号的概览/编辑资料/修订历史页面和接口删除；
   - 生成、交付、渠道版本不再读取账号资料，只用角色（和品牌）资料；
   - 空表 `content_account_revision` 用迁移删除。
3. 删掉账号栏目和账号默认流程：
   - 栏目只能建在角色下（跨平台栏目，已有）；
   - 「账号栏目」创建接口、账号默认流程接口删除，空表 `account_workflow_default` 删除。
4. 新建账号必须选平台：去掉「只填名字建账号」，统一用「登记平台账号」。
5. 同一角色同一平台第二个在用账号：后端拦下，页面提示「这个角色在该平台已有账号」。归档的不算。

## 不改什么
- 不保存平台密码、不替你登录、不自动发布。
- 公众号接口连接、渠道版本、发布与交付流程本身不改，只是不再叠加账号资料。
- 内容记忆、学习等模块里「账号」这一归属范围本次不动（无数据），页面上账号不再显示「内容记忆」入口；后续单独清理。
- 不改角色、品牌页面。

## 追加（用户 2026-11-01 要求）
- 「角色与账号」页的目录标签按层级排：品牌、角色、账号、栏目（原来是角色、账号、栏目、品牌）。默认仍打开角色目录。
