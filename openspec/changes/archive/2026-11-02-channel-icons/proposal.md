# 渠道名前加平台小图标

## 为什么
账号名大多一样（比如都叫「知数Talk」），靠文字区分平台很难认。在显示渠道的地方加上平台自己的小图标，一眼能看出是哪个平台。

## 改什么
1. 图标来源：各平台官网自己的网站图标（favicon），下载一次存进前端 `public/channel-icons/`，统一转成 32×32 PNG。不自己画、不仿制，页面运行时不再去外网取。
   覆盖渠道：公众号、视频号、百家号、头条、知乎、B站、小红书、抖音、快手、微博、网易号、企鹅号、X、掘金、雪球、YouTube。
2. 新增一个小图标组件：按渠道键显示 16px 图标，找不到图标时不显示（不影响文字）。
3. 显示位置（文字渠道名前加图标）：
   - 角色与账号：账号卡片、账号页标题区和「账号信息」；
   - 账号台（AccountDesk）列表；
   - 渠道版本面板的渠道名、作品的渠道选择列表（非下拉框处）；
   - 审阅与交付中心、候选预览里的渠道名。
   下拉框 `<select>` 里放不了图片，保持文字。

## 不改什么
- 不改渠道名称文字、不改后端。
- 图标只用于在本平台界面里标识渠道，不用于生成的内容、封面或视频。
