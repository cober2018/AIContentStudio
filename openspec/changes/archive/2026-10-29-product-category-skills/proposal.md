# 商品品类与带货风格 skill（参考 clipforge，除数字人外）

## 为什么

用户希望商品工作台像内容工作台的「角色」一样：按商品品类（美妆护肤、食品零食……）分好类型，每个品类下挂自己的 skill 和风格；脚本风格（10 种）本身就是可选的 skill。clipforge 的带货做法是一个完整体系，平台 2026-10-28 只把它的方法写成了参考文字（形态、开头、渠道、品类镜头骨架），用户没有入口去选，品类也只是一段自由文本。数字人以后再接，这次不做。

## 现状与差距

| clipforge 有的 | 平台现状 | 这次 |
|---|---|---|
| 5 大品类，每类有品类要点（看什么、卖点怎么写、违禁词、人群、语气）和若干脚本套路、镜头结构 | 品类是自由文本；五类镜头骨架只是 `product-shots` 参考文字；没有品类到 skill 的对应 | 新建品类，像角色一样有自己的 skill 组合和风格 |
| 10 种脚本风格（4 大形态），用户可选或「智能推荐」 | 写在 `product-script` 参考里，只能由模型自己挑 | 10 种风格各做成一个 skill，品类决定可用哪些、默认哪个 |
| 16 种黄金 3 秒开头，可固定一种，可出多个开头版本 | 有参考文字，模型自选 | 可在发起时固定开头，或要 2–3 个开头版本 |
| 平台 SEO：标题、话题标签、封面字、互动引导、简介 | 没有 | 新 skill 产出这几项文字（不做发布导出） |
| 受众、价格区间、平台、时长、使用优势 | 大多已有（受众、买家处境、顾虑、价格、时长、渠道） | 只补「参考爆款结构」一项 |
| 运镜预设（22 个，可两个叠加、自动排除冲突）、Look（14 个光线色调）、运镜强度三档 | 没有可选预设 | 平台自带运镜库、Look 库、强度三档；每个镜头可选可改；写进网页图生视频交接提示词 |
| 一张商品图自动出整片；给素材剪；部分素材 + 图生视频补 + 免费素材搜索融合 | 有素材匹配和自动补齐（用户素材 → 免费素材 → AE 模板 → 缺口），图生视频只走网页手工 | 三种出片方式都支持（见「改什么」6） |
| 图生视频自动生成 | 只有网页交接 | 加自动（MiniMax H3，商品图 / 关键帧作首帧），和网页手工并存，用开关选 |
| 链式首尾帧、逐镜只重跑动态、提示词工程包（连续单镜头、无人声、冲突消解、AI 拍不出的动作提前拦） | 图生视频靠网页手工交接，没有这些 | 交接里写明「用上一镜尾帧作首帧」、可单独重写某镜运动提示词；工程包规则写进交接提示词和导演稿检查 |
| 真人出镜真实感约束（不是网红脸、不磨皮、不丑化） | `product-shots` 有一句规则 | 有人出镜的生图和交接提示词自动带上 |
| 剧情类脚本多角色、每人固定一个声音 | 配音一个声音 | 剧情风格输出角色表，配音按角色分不同 MiniMax 音色 |

## 改什么

1. **商品品类**：内置 5 个品类，可新增（如「家具」）。每个品类像角色一样有：品类要点、可用脚本风格与默认风格、推荐开头、默认 Look 与运镜计划、各阶段 skill 组合。商品资料选品类（原来的细分文字保留为「细分」）。
2. **10 个脚本风格 skill**：情景短剧、反转剧场、街头采访、剧情故事、开箱测评、物品拟人、对比测评、达人口播、痛点种草、场景安利。`product-script` 升 v3：读品类要点 + 选中的风格 skill + 开头 + 渠道。发起时可选风格，或「按品类推荐」。
3. **开头与 SEO**：发起时可固定开头、选开头版本数；新 skill `studio.product.publish-copy` 产出标题、话题标签、封面字、互动引导、简介。
4. **运镜 / Look / 强度**：平台内置库；导演稿每镜可选（运镜最多叠两个，冲突自动排除）；写进网页图生视频交接提示词；链式首尾帧和逐镜重写运动提示词走交接。
5. **真人真实感约束、多角色配音**。
6. **三种出片方式**（发起时选，可中途换）：
   - 一张图出整片：只给商品图，脚本 → 分镜 → 关键帧 → 图生视频 → 配音 → 剪辑全部走完。
   - 给素材剪：用户素材按分镜匹配，缺的镜头标出来。
   - 混合补齐：先用用户素材，缺的镜头按顺序补——免费公开素材（已接的 Pexels、Pixabay 等）→ 图生视频 → AE 模板 → 仍缺的列出原因。每个镜头标明素材来自哪里。
7. **图生视频开关**：设置里选默认「手动（网页生成）」或「自动（MiniMax H3）」，默认手动；每个作品、每个镜头都可以单独改。自动失败或不满意的镜头一键转手动。自动支持首帧、链式尾帧、画幅和时长；按条计费，提交前显示要生成的镜头数。

全部用平台自己的话重写，不拷贝 clipforge（AGPL-3.0）的代码、提示词原文和示例文案。

## 不做

| 项 | 原因 |
|---|---|
| 数字人、6 个素人主播形象 | 用户定：以后在内容和商品里一起接 |
| 391 个成片配方库 | 用品类的默认组合代替；以后要配方库另提 |
| 批量防同质化、效果回流推荐、热点选题 | 需要批量出片和发布数据，以后另提 |
| 自带合成渲染、免费配音、字幕样式、BGM、封面 / 二维码 / 发布导出 | 平台用达芬奇 / AE / MiniMax，已有或与平台冲突 |

## 追加（2026-10-29）：镜头生图（带商品参考图）

用户确认测试结论：CPA 的 grok-imagine-image（`/v1/images/edits` 传参考图）和 gemini-3.1-flash-image（原生 `generateContent` 传图）都能按商品图出竖屏场景图，grok 对商品外观保持得更好；平台原先把这两条通道的参考图关掉了，从没传过。

改什么：
1. 「用途路由」加一行「镜头生图」：从「生成能力与插件」里绑成「生图」的模型中选（默认 CPA · grok-imagine-image）。
2. 生成时自动带商品主图作参考（可再加一张参考图），画幅跟着片子走，提示词自动加「商品外形、颜色、材质、字样不变」。
3. 生成的图放进项目「图片/图片素材」，标「AI 示意」；可一键设为某一镜的图生视频首帧，再按「图生视频」路由生成、放进视频。
4. 商品亮相和下单引导镜头仍只用商品原图，不用生成图。

5. 主体一致性把关（最重要）：每张生成图出来后，先用能看图的模型对照商品原图检查——外形、颜色、材质、logo / 字样、配件有没有变；不过关就带着问题说明重画，最多 3 次；3 次都不过关就不用，标出原因。通过的图才能当首帧；检查结论随图保存，页面上看得到。
6. 手动 / 自动两条路共用同一张首帧：
   - 手动：页面给出这一镜的首帧图（可下载）和视频提示词，你在网页生成后，把做好的视频文件直接传到这一镜。
   - 自动：从生图、一致性检查、图生视频到放进这一镜全自动；不过关或失败会停下并说明原因。

不做：图片放大 / 超分、批量出图。
