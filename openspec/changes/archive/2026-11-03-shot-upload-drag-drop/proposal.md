# 补充镜头：把视频拖进去就上传

## 为什么
补充镜头里的「上传做好的视频」现在只能点按钮、再到文件窗口里一个个找，不方便。用户要能直接把视频从访达拖进去就上传。

## 改什么（只改页面）
- 「上传做好的视频」按钮改成一块上传区，写「把视频拖到这里，或点击选择」：
  - 从访达拖一个 MP4 / MOV 进来，松手就上传到这一镜，和点击上传走同一个接口、同样的检查。
  - 拖到上面时上传区变色，提示松手。
  - 一次拖多个文件只传第一个，并提示「一镜只能放一条视频」；拖进不是视频的文件，提示「请拖 MP4 / MOV 视频」，不上传。
  - 点击照旧打开文件窗口。
- 上传中按钮置灰，传完和现在一样刷新，显示「已上传，已放进这一镜」。
- 用的是同一个每镜组件，所以九宫格弹框里的每镜、商品作品的手动上传也一样能拖。
- 后端、接口、规则都不改。

## 验收
| 项 | 怎么验 |
| --- | --- |
| 拖进上传 | 页面上模拟拖一个视频到上传区 → 走上传接口（核对时用数据库副本对应的测试服务或拦截请求，不往作品 94 真上传） |
| 拖错文件 | 拖图片 / 多个文件，提示对、不发请求 |
| 点击 | 照旧能点开选择文件 |
| 测试 | 前端类型检查通过 |
