# 角色概览和编辑资料对齐

## 为什么
角色「编辑资料」已经按新结构分成：声音、形象照、逐字稿样本、身份、表达、边界。概览还是旧的样子：
- 新加的几项不按名字显示，而是被塞进「其他资料」，露出 `brand`、`portrait_material_revision_ids` 这样的原始字段和 JSON。
- `brand` 是品牌拆分后带进来的品牌资料，在角色概览里原样出现，看起来像角色还在继承品牌。

## 改什么
1. 概览增加三块，和编辑页同名同顺序：
   - 声音：显示选定的声音名称，没选显示未设置；
   - 形象照：显示缩略图；
   - 逐字稿样本：显示文件夹路径。
2. 角色概览不再显示 `brand` 资料块，品牌只在右侧「归属与关联」显示。
3. 「其他资料」只放真正不认识的字段，上面这些已知字段不再进去。

## 不改什么
- 不改后端和数据，不改编辑页，不改账号、栏目、品牌的概览。
