# 审阅与交付：去掉测试作品；成片可多选发布平台，并一键跳去平台发布页

## Why
1. 审阅与交付列表里有之前的测试 / 不做的作品。现在它按项目列出全部作品，连已删除、已归档的作品和已归档的项目都列着（如 #45 作品已全删仍显示）。用户确认删除 #45、#43、#42、#47。
2. 同一条横版成片可同时发抖音、小红书、公众号等；上一版（4070dd7）授权时只能选一个平台，并在第一次授权后固定在待审版本上。
3. 角色在「角色与账号」里每个平台绑了账号，平台已有各平台「去发布」网址（content_identity.CREATOR_LINKS）和「用角色的 Chrome 个人资料打开」（POST /content-accounts/{id}/open-link），但审阅与交付里没接上。

## What Changes
1. **列表只显示在做的作品**：审阅与交付只列「使用中」（lifecycle=active）的作品；项目已归档或里面没有使用中的作品，整个项目不显示。（顺带：#41 里已归档的作品 79 也不再显示，你之前说过不做了。）
2. **删除 4 个项目里的作品**（等「上线」，先备份）：作品 83、84、91 改为「已删除」（和工作台里「更多 → 删除」一样，可恢复，硬盘文件不动）；项目 #42、#43 归档（#45、#47 已是归档）。作品 93、94 不动。
3. **发布平台多选**（只对成片交付版本）
   - 可选平台：抖音、小红书、视频号、公众号、快手、B站、百家号、今日头条、YouTube（都是能发视频、平台里有发布入口的）。
   - 授权页把「发布平台」改成勾选：列出这些平台，角色在这个平台绑了账号的自动带上那个账号（显示账号名），没绑的也能勾（不绑账号）；点一次授权，勾几个就各生成一个交付目标。
   - 待审版本不再固定平台；同一平台重复授权照旧去重。
4. **一键跳去发布**：交付与回填里每个平台的交付目标旁加「去 <平台> 发布」按钮：有账号时用该角色的 Chrome 个人资料打开这个平台的发布页（沿用 open-link）；没账号、或账号所属没有 Chrome 个人资料时，直接在当前浏览器打开发布页。发布页优先「去发布视频」入口，没有就用「去发布」/「去后台」。每个平台各自下载成品包、各自回填凭证；任一平台回填后作品即「已发布」（不变）。

## 不改
v4 / 渠道变体的老路径；成品包内容；作品 93、94 数据。

## 验收
- 审阅与交付列表不再出现 #42、#43、#45、#47 和已删除 / 已归档作品；其他作品照旧。
- 库副本上作品 95：一次勾抖音、公众号、B站授权 → 3 个交付目标（抖音、公众号、B站各带上知数Talk 对应账号）→ 各自能下载成品包、回填；「去发布」按钮打开对应平台发布页（实际打开 Chrome 只在上线后手点验证）。
