## Why

2026-10-24 用户在海底光缆成片已通过后，在「制作内容」页点了两次「保存当前主稿」（内容没改），平台生成主稿 v24、v25，视频进度只认最新主稿，于是退回「待开始」，页面上成片不见了（文件和记录都在）。

问题有三处：
1. 内容没改也能保存，而且保存一次就打断视频进度。
2. 成片通过后，前面的导演稿、主稿仍能修改、重新审核。
3. 视频的整个流程堆在一页：「制作内容」一页里有视频进度、18 镜分镜表、配音、主稿版本列表、导演包、保存按钮，约 5 屏长，要来回拖。

用户后续推广准备做成桌面端，流程要像桌面应用一样一步一页、点「下一步」翻页。

## What Changes

- **内容没变不算新稿。** 新保存的主稿内容和上一版完全一样时，视频进度照旧（沿用上一版的导演稿）。页面上「保存当前主稿」在没有修改时不可点。改好后海底光缆自动回到「已完成」，不用重做。
- **成片通过后锁住。** 成片通过（已完成）后，平台拒绝再保存主稿（页面和 Claude Code 经 MCP 都一样），页面上导演稿、小样只能看。真要返工，在成片页点「重新打开」并确认；之后 Claude Code 写新导演稿，流程从导演稿重新走，旧成片留在 `导出/成片`。
- **角色视频一步一页。** 角色（非商品）视频的步骤改为：选题与资料 → 导演稿 → 小样 → 成片 → 交付，每页只放这一步的内容，底部「上一步 / 下一步」。
  - 导演稿页：视频进度 + 分镜，**一次看一个镜头**，「上一镜 / 下一镜」翻看。主稿版本、分镜素材制作、导演包、保存主稿等收进「更多」，默认收起。
  - 小样页：播放小样、按秒写意见、通过；配音也在这页。
  - 成片页：播放成片、写意见、通过；完成后显示「重新打开」。
  - 打开作品时直接落在视频当前所在的那一页；还没到的步骤点进去只显示「还没到这一步」。
- 不做：商品视频（六步流程）、文字、图文的页面不改；不做桌面端本身。

## Impact

- API：`services/video_chain.py`（同内容不打断、锁定判断、重新打开）；`services/content_masters.py` `save_revision`（完成后拒绝保存）；`routers/edit_agent.py`（重新打开接口）。
- Web：`ProductionWorkspace.tsx`（角色视频的五步）；`VideoChainPanel.tsx`（按步骤显示、锁定提示、重新打开）；`StoryboardTable.tsx`（逐镜翻看）；`ContentMasterPanel.tsx` / `VideoStudioShell.tsx`（没改不能保存、编辑区收进「更多」、锁定只读）；`CreationRecipePanel.tsx`（导演稿页沿用）。
- 数据：不改表，不改已有记录；海底光缆靠「同内容不算新稿」自动恢复。
