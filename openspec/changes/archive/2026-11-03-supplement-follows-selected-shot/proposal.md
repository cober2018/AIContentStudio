# 补充镜头跟着上面选中的镜头走

## 为什么
「素材」这一步上面是逐镜素材（L01、L02… 一次看一镜），下面的「补充镜头」却把所有缺素材的镜头一次全列出来，和上面选的镜头对不上。用户要的是：上面点到哪一镜，下面就只显示这一镜的补充内容。

## 改什么（只改页面）
- **跟着上面走：** 补充镜头面板放到逐镜素材的正下方，只显示上面当前选中的这一镜：
  - 这一镜缺素材、没分组：显示这一镜的补充入口——手动 / 自动、生首帧、提示词、上传，和现在每镜那一块一样。
  - 这一镜归在九宫格组里：显示「九宫格组 g1 · 打开九宫格」，弹框照旧处理整组。
  - 这一镜已有用户素材：不显示补充入口，只写一句「这一镜已有素材，不用补」。
- **保留：** 面板顶部的统计（共 N 镜、缺几镜）和没有形象照的提示照旧。
- **其他不变：** 网上找图移到补充镜头下面，其他模块不动。
- **商品作品：** 一样跟着走，因为用的是同一个面板。
- **后端、接口、规则：** 都不改。
