# 项目文件夹日期前缀 + 本地输出目录规范

## Why

素材硬盘上的项目文件夹直接用项目名（「儿童麸质饼干」「海底光缆」），按时间找不到、同名难分；仓库里的 `output/` 这段时间临时堆了审片页、项目导出包、吸收资料、安全区图，没有按总目录架构放。用户补充规则：内容项目的文件夹名必须以「年月日」为前缀，例如 `20261029_项目名称`。

## What Changes

- **项目文件夹命名**：内容项目的素材文件夹名为 `YYYYMMDD_项目名称`，日期取项目创建日期，名称沿用现有规则（标题第一个「｜」之前的部分，去掉非法字符；重名加 `(#项目ID)`）。名字定下后不随标题改动而变。
- **已有项目改名**（用户确认）：素材库里已有的项目文件夹按同一规则改名；平台记录的文件夹名、素材位置（相对路径）一起更新，其他项目指向它的快捷方式重新指向新位置。改名前列出清单，改名可回滚。
- **本地输出目录 `output/`**：
  - 跟某个内容项目有关的成果（导出包、交付说明、发布指南）放 `output/YYYYMMDD_项目名称/`；
  - 平台自身的东西放 `output/_平台/`：`模板审片/`（竖屏、横屏审片页）、`规格/`（播放安全区图等）、`吸收资料/`（外部仓库整理）、`剪辑技法/`、`测试/`（截图等临时产物）；
  - 现有内容按上面归位，规则写进根 README 的目录说明，以后生成的东西照此放。
- 项目素材目录规范（`project-material-folders`）和 README 同步写明命名规则。

## 不做

改素材库根目录、通用素材库和外部素材库的结构；改项目内子目录（导演稿 / 视频 / 图片 / 音频 / 导出）。

## Impact

- `apps/api/app/services/project_folders.py`：folder_name 加日期前缀；一次性改名迁移（文件夹、设置、placement、快捷方式）。
- 素材硬盘 `/Volumes/T1000/自媒体素材/` 下已有项目文件夹改名。
- `output/` 目录整理；根 README 目录说明。
