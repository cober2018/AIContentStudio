## 正常入口与用法
1. 内容项目 → 从商品开始创作，或已有项目 → 创作任务书。先填写任意已知内容，右下角AI创作助手点“补齐未填项”；创作目标/受众/意图保留，空白建议逐项采用或跳过。
2. 光标放到带AI支持的内容字段，助手显示字段名，点“润色当前项”。有选区只处理该选区。建议可手改后采用，再对当前项继续润色。采用只写页面草稿，仍需原“保存新版本/保存内容Master”。
3. 建议旁“这次希望如何改”填写反馈，可重写本项或本批仍待确认空白项；“以后也这样”需写明规则与适用商品/品类/风格/阶段，仅保存偏好候选。方法库明确保存后，助手可选择具体偏好版本使用。
4. 商品资料的“商品品类与表现风格”可选现有风格，也可创建风格候选、确认可选用；明确应用后保存。阶段Skills可继续调整，关闭后不会从原风格带回。
5. 视频制作台沿用左选图/中提示词/右回传。先确认并保存精确图片，选择提示词字段，在助手请求据图生成；显示看图观察和图片引用。采用会使旧提示词确认失效，核对后重新确认并保存，再准备网页生成包。
6. Grok/Gemini视频继续人工网页生成回传。product-video-material-director Skill负责图片准确性、据图动作和返回片段检查；配音、音乐、Resolve主剪、AE包装继续原入口。
7. 设置 → 模型与AI → 用途路由，分别选择“表单自动补齐”“当前字段润色”。未明确选用时继承全局默认，实际请求显示真实模型版本；配置保存不会调用模型。

直接入口：[商品任务书](http://127.0.0.1:5173/projects/8?tab=brief)、[现有视频制作台](http://127.0.0.1:5173/projects/8/units/14/production)。
