# 视频导演稿增加「声音轨」：口播声音和镜头画面分开记

## 为什么
口播带货视频常要「画面切到商品特写，口播声音不断」或「声音比画面早半拍进」。现在导演稿只在镜头上记一条画面素材（source_material_revision_id），口播声音从哪来只能写在 board.sound 的文字里。只当声音用的素材不进导演稿的素材清单，也就进不了开剪任务和剪辑清单核对。
复现：项目 48 / 作品 93 导演稿 v1，第 6、7 镜的声音来自素材 455（58ce16fb…mov，10.17 秒），它不是任何镜头的画面；现在只写在文字里（如「画外口播…（58ce16fb…mov 0.70–2.97 秒）」）。

## 现状（可复用的部分）
- timeline.tracks 已有 audio/music 轨，轨上的片段可带素材、成片起止、素材截取（trim）、音量，并且已经作为导演稿素材（timeline_media）进入开剪任务的素材包，剪辑清单核对也以素材包为准。缺的是：口播专用的轨类型、和台词的对应、保存时的检查、页面显示和剪辑做法。

## 改什么
1. **导演稿新增声音轨 `kind: "dialogue"`**（可选，至多 1 条）。每一段写：
   - `material_revision_id`：来自哪条素材；
   - `trim_start_ms` / `trim_end_ms`：用素材的哪一段；
   - `start_ms` / `end_ms`：放在成片哪个时间；
   - `script_block_id`：对应哪句台词（可选）；
   - 声音段可以跨镜头边界；画面轨不变，一个镜头仍只有一条画面素材。
2. **保存导演稿时检查每一段**（不合格拒绝保存，说明哪一段、哪里不对）：素材存在且可用；截取段不超出素材时长；成片位置在成片时长内；截取长度与放置长度一致；同一条声音轨上各段不重叠；台词编号存在。
3. **开剪与核对：** 声音轨的素材随导演稿素材一起进开剪任务（与配乐、配音一样，准备素材时给原始路径），剪辑清单核对把它们算进去（沿用现有素材包机制，核实无遗漏）。
4. **页面：** 导演稿那一步每句台词旁显示「声音：素材 #455 0.70–2.97 秒 → 成片 12.30–14.57 秒」，没有声音轨的台词显示「镜头原声」；方便审剪掉了哪些话。
5. **剪辑规则与 craft-resolve：** 有声音轨就按声音轨铺口播（画面照镜头切），没有就按镜头原声；补衔接做法：
   - 切点放在换气或停顿处；
   - 接缝加 2–4 帧淡入淡出，防咔哒声；
   - 不同素材的口播统一到同一响度，底噪对齐；
   - 接完整条重新听写（ASR），确认没吞字、没多半个字。
   MCP 导演稿工具说明同步写明声音轨字段。

## 不改什么
- 画面轨不变；没有声音轨的导演稿照旧按镜头原声剪。
