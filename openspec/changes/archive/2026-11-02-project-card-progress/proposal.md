# 内容项目卡片显示真实进度，替换「草稿」

## 为什么
项目卡片右上角的「草稿」来自项目的 status 字段：新建默认 draft，系统里没有任何操作会改它，只有归档才变成 archived（正式库 5 个 draft、2 个 archived）。所以它永远是「草稿」，敏贝贝成片已定稿也显示草稿，说明不了项目做到哪了。

## 改什么
1. **项目列表接口多返回一个进度汇总：** 按项目里在用的作品（归档、删除的不算）逐条取当前状态——视频按视频链路状态，文字/图文按文章链路状态——归成四类：
   - 已定稿：链路状态为已定稿；
   - 等你看：导演稿 / 小样 / 成片待你看（以及「正在通过…」这种你刚点过的也算处理中，不算等你看）；
   - 制作中：其余进行中的状态（制作中、按意见修改中、排版中、正在通过…等）；
   - 未开始：链路还没开始。
2. **卡片右上角改成进度：**
   - 全部作品都已定稿 →「已完成」（绿色）；
   - 有等你看的 →「N 条等你看」（醒目颜色），优先显示，提醒你去看；
   - 否则 →「制作中」；一条作品都没有或全没开始 →「未开始」。
   - 卡片下方原来的「视频 2」等数量标签旁加一行小字汇总，例如「1 已定稿 · 1 成片待你看」。
3. 已归档项目照旧显示「已归档」。项目 status 字段本身不改、不删（筛选「进行中 / 已归档」还在用它）。

## 不改什么
- 不改作品链路状态本身；不改项目页里面的显示。
