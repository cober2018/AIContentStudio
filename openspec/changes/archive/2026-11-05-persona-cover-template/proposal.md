# 角色封面样式固定 + 封面可重交、可要求重做

## Why
用户要同一个角色的视频封面风格固定，先做「懒羊羊小王」。参考样式（作品 93 敏贝贝那种）：
- 大标题「敏宝专属小点心」：白字、黄色粗描边；
- 副标题「｜敏贝贝××」：细字、黄描边、靠右；
- 底部三行黄字卖点：红色错位阴影加白色粗描边，每行前一个黄色对勾；
- 画面是商品实拍。

现状（已核对代码和库）：
- 角色资料（`content_persona_revision.profile_json`）没有封面样式。
- AE 模板库 70 个模板里没有封面模板。
- 剪辑任务的封面（role `cover`，可选）登记后不能替换（`creative_execution_output_replacement_denied`）。
- 小样 / 成片审片页只显示封面，没有「重做封面」。

## 和需求原文不同的一处（请确认）
需求里模板字段有「底图」。按 2026-11-02 已定的「封面必须从成片截取」：AE 只出透明字层，叠在成片开头，封面从渲染好的成片里截一帧。如果模板自己带底图，就又回到「AE 拿原片另外合成」，颜色会和成片对不上。
所以这次的建议是：**模板只开放大标题、副标题、卖点 1–3；底图就是成片开头那段商品实拍，不作为模板字段。**

## What Changes
1. **新做一个封面模板入库**：「角色封面 · 大字三卖点」，透明字层，9:16 和 16:9 两版，照参考样式。字段：大标题、副标题、卖点 1–3。
   - 走模板入库流程：做完先渲两版不同内容，叠在真实商品画面上给用户看；用户认可后才写检查记录、变成可用（ready）。
   - manifest 标 `category: "封面"`，角色只能选这一类模板。
2. **角色绑定封面模板**：角色资料加「封面样式」`cover_template: {id, version}`，只能选封面类模板；角色页加选择项和样式预览。不选就和现在一样。
3. **开剪时带上模板**：作品角色绑了封面模板时，剪辑任务的执行包带 `cover_template`（模板 id、版本、要填的字段及字数上限）。规则写明：必须用这个模板 `render_ae_template` 出封面字层，叠在成片开头，再从成片截封面；交封面时 metadata 带 `cover_template_render`（这次渲染得到的素材版本号）作为回执。
   - 平台检查（只提示、不拦交付）：没带回执，提示「封面没用角色的封面模板」；回执不是这个项目里这个模板这个版本的渲染，提示「封面用错了模板」。提示放在审片页交付检查里，和现在的封面色差提示一起显示。
4. **封面可重交**：任务通过前，第三方模型可以再交封面这一格（新一次 attempt），旧版本留在历史里，审片页显示最新一张。
   - 封面不再参与剪辑清单 `output_hashes` 的比对，因为封面可以在清单之后重交。
   - 其他交付文件的规则不变（登记后仍不能替换）。
5. **审片页「重做封面」**：小样 / 成片审片页封面旁边加「重做封面」，可以写备注。
   - 点了只记一条「封面要重做」和备注，不退回整个小样或成片。第三方模型从 `get_video_decision` 看到要重做和备注，重交封面后，这条要求自动算完成。
   - 封面重做没交上来之前，成片的「通过」先不能点，提示「封面重做中」，因为成片通过后任务就锁定，封面不能再交。小样不受影响。

## 不在本次范围
- 平台不生成、不排版封面，排版仍由第三方模型在 AE 里做。
- 不动作品 93、94 的数据和任何模板的现有 v1。
- 已经开出的剪辑任务不补模板，下次开剪才带上。

## Impact
- 后端：`content_identity.py`（角色资料字段）、`craft_skills.py`（按类别列模板）、`video_chain.py`（规则文字、开剪结果、重做封面、成片通过前检查）、`web_video_handoff.py`（执行包带模板、清单比对去掉封面）、`creative_executions.py`（封面可重交、模板回执检查）、`creative_mcp.py`（`get_video_decision` 带重做要求）。
- 前端：角色资料页「封面样式」；`VideoChainPanel.tsx` 的「重做封面」和提示。
- 模板：`craft_skills/craft-ae/templates/<封面模板>/v1/`，AE 工程放模板仓库。
- skill 文字：craft-resolve 交付说明里封面那段。
- 生效要重启 API；不改数据库结构。
