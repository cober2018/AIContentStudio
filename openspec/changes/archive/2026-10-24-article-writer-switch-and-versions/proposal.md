## Why

视频由 Claude Code 经 MCP 自己写导演稿、平台只记录和请用户审；文字、图文却只能由平台里配置的模型写——Claude Code 经 MCP 只能触发平台阶段（`run_stage`），自己写好的稿交不进平台。

用户要求（2026-10-24）：
- 两种都能用：Claude Code 自己的模型写，或调用平台能力（平台配置的模型）写。
- 在页面上放一个**开关**选用哪一种，样式像 iPhone 的滑动开关。
- **每次生成都留一个版本**；版本可以删除。

## What Changes

**1. 写作方式开关（文字、图文作品）**
- 「内容方案」页顶部一个滑动开关：**平台模型 ⇄ 第三方模型**。默认平台模型（现状不变）。
- 平台模型：沿用现有流程（文字 9 个阶段：证据简报 → 角度 → 大纲 → 初稿 → 检查 → 精修 → 标题开头 → 最终稿 → 终检；图文 4 个阶段）。
- 第三方模型：页面不显示平台阶段，只显示「等第三方模型写稿」、版本列表和审稿区。在接了 MCP 的第三方模型（如 Claude Code、Codex）里说「写这篇」，它经 MCP 读资料、自己写、存成新版本；你在页面上「采用」或写意见让它改。采用后定稿，和视频一样不能再改，要调整就复制一份。
- 开关定稿前随时可切；切换不删已有版本。MCP 在开关是「平台模型」时拒绝第三方模型存稿，提示去页面切换。

**2. 版本列表（两种方式共用）**
- 每次生成（平台阶段产出的稿、第三方模型存的稿）都是一个版本，列表显示：版本号、来源（平台模型 / 第三方模型）、时间、状态（当前 / 已定稿）。
- 每个版本可查看；可「用这一版」（设为当前，生成一个新版本，旧的都留着）；可**删除**（从列表移除，不能恢复）。当前版本、已定稿版本、被渠道版本用到的版本不能删。

**3. MCP 新增三个工具**
- `get_article_brief`：选题、任务书、事实边界和来源原文、角色口吻、写作方式、当前状态和当前稿、稿件格式说明（文字 `text.master.v2` / 图文 `graphic.master.v2`）。
- `save_article_draft`：存一版稿（图文的图片用已有的生图工具或素材库素材），然后停下等用户。
- `get_article_decision`：读用户的采用 / 修改意见。

**不做**：视频不加开关（仍由 Claude Code 主导）；不改平台模型写作的阶段内容；不改表结构。

## Impact

- API：新服务 `article_chain.py`（开关、状态、存稿、决定、版本删除）；`creative_mcp.py` / `mcp_settings.py`（三个工具）；`content_masters.save_revision` 定稿锁扩展到第三方模型写作的文字/图文；路由（开关、决定、版本列表与删除）。
- Web：新的滑动开关组件；`CreationRecipePanel` / `ProductionWorkspace` 在 第三方模型方式下换成审稿区；新的版本列表组件；复制一份已支持图文，补文字。
- Skill：`.codex/skills` 增加写文章的说明（用这三个工具，三处停等用户同视频）。
