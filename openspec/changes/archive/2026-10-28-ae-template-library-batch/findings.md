# 发现与决定

- 用户 2026-10-28 按 13 类挑了 46 张卡（混合 shotcraft / talkcraft）；numberne-vertical = step-timeline-vertical，colory-transition = color-slam-beat-card。
- 现有 render() 只出 MP4 无透明，叠加类模板需要 alpha 输出。
- 分 3 批，每批用户看过再做下一批。
- 搭建脚本卡住的原因：模板中途出错留下未保存项目，`app.newProject()` 弹「另存为」且不受 `beginSuppressDialogs` 控制。改为新建前 `close(DO_NOT_SAVE_CHANGES)`，并加上屏蔽对话框和 30 分钟 AppleScript 超时。
- AE 脚本坑：往形状组里加填充 / 描边后，先前取到的矩形、路径引用失效（「对象无效」），要重新取；矩形自己的 Position 表达式读不到 Size，左对齐色块要在 Position 里重算尺寸；「填充」效果的颜色表达式会让构建报「数字结果无效」，金句卡改为每行一白一亮两层按数据显示。
- 本机 ffmpeg 没有 drawtext，预览用的示意截图只画色块。
- 第一版观感差的原因：只借节奏、沿用平台深底荧光绿、苹方最粗只到中粗、预览背景是色块。改为照原卡的设计语言（特粗黑体、白块托字、纯色强调、细线细描边）在 AE 里自行实现；版式按竖屏重新排，不逐张描原卡，示例文字自写，原卡代码和素材不使用。
- 原卡截图只用于本地对比，不入库、不提交。
- 2026-10-28 用户问是否支持 16:9。结论：现有 23 个模板全是 1080×1920，横屏要重新排版，不能拉伸。用户定：先做完三批竖屏，再统一补横屏（横屏另起需求，届时先写提案）。
- 2026-10-28 第二批实现要点：数据序列统一用逗号分隔的文本字段（points/values/labels/options），时间轴用「日期|标题|说明;…」；数值字段留空按 0 处理，模板把 0 当「用默认」（highlight/stop/current）。number-roll 涨跌按国内习惯红涨绿跌；metric-trend 箭头只表方向、颜色跟数字。折线图刻度按 1/2/2.5/5 规整步长计算，柱状图从 0 起，保证图表严谨。界面截图类（before-after-scrub）按完整放进框内，不裁切。
- 2026-10-28 第三批要点：主题色统一用 color 字段（ink/blue/red/violet/teal/orange），实现上每种颜色一层、按字段显示，避开 AE 颜色表达式在构建时出错的老问题。色块扫屏约 0.55 秒全屏覆盖，作为切点中间件。网格收成主角、焦点接力都用表达式按时间插值几何，图片按当前框大小铺满。
- 2026-10-28 安全区：用户图里透明部分即安全区（实测像素见 safe-zones/README.md）。叠加类模板原先压在 y 1300–1700，正好落进手机底部文案 / 评论区，整体上移约 200；居中文字最大宽度收到 692（右边界 886），左对齐文字收到约 720–740。大块卡片、底板允许伸到右侧按钮列下面（挡的是边角），文字和标签、按钮、图钉等不行。地图示例占位图改为 9:16，检查才有意义；落钉下落距离由 140 收到 50，避免起始帧出上边界。
