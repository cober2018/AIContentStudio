## Why

「设置 → 高级运行环境」里挂着 15 个旧版本页面（旧选题、旧稿件工作台、旧审核、旧母稿交接……）和原管理员运行配置。旧版本只做过测试，没发布过任何内容。用户要一个干净的、只有新版本的系统（2026-10-24），两条原则：

1. **新版本功能还在用的旧后端，保留后端**，把它的页面和路径搬进新版本的结构里（设置的对应分区、新页面的组件目录）。
2. **只属于旧版本的东西全部删掉**：页面、后端、数据表和测试数据都不要。

用户特别说明：
- 数据接入要保留——它是内容机会的数据源（例如每天的行情自动写一篇），搬进「设置 → 数据源」。
- 模板要保留——平台模型写出好作品后，把风格沉淀成模板 / Skill，让便宜的模型也能写出不错的效果；搬进「设置 → 规则与模板」。

## What Changes

**A. 整个删掉（页面 + 后端 + 空表）**——数据全是 0，新版本不用：

| 旧页面 | 后端 / 数据 |
|---|---|
| 旧选题 `/topics` | topics 路由、`topic_brief`（0） |
| 旧稿件工作台 `/workspace` | Draft 编辑 / 生成 / 检查：`generate`、`checks` 路由，`draft`、`content_job`、`draft_check_run`、`draft_claim` 等（0） |
| 旧审核 `/legacy/review` | `reviews` 路由里 Draft 审批（0） |
| 旧母稿交接 `/handoff` | `article_handoff` 路由、`mother_revision`、`draft_media`（0） |
| 素材兼容页 `/legacy/materials` | 旧 Draft 挂载素材的接口（0） |
| 旧概览 `/dashboard`、旧首页 `/legacy/landing` | `dashboard` 路由 |

新版本里引用这些的地方（例如素材删除时统计「旧 Draft 使用」）一并去掉。空表用数据库迁移删除，删前备份数据库。

**B. 后端保留，页面搬进新版本，旧路径删掉**

| 旧页面 | 搬到 |
|---|---|
| 数据接入 `/connectors` | 「设置 → 数据源」（现在已内嵌，改为正式归属，组件移到新目录） |
| 模板 `/templates` | 「设置 → 规则与模板」（同上） |
| 来源 `/sources`、证据包 `/fact-packs` | 新页面在用的组件（导入来源、来源抽屉、建证据包）移到新目录；独立旧页面删掉。项目「来源与事实边界」、「素材与知识」照常 |
| 旧审核与发布 `/review-publish`、旧内容资产 `/legacy/assets` | 新「审阅中心」已用同一套后端；旧页面和审阅中心里的「兼容入口」链接删掉 |
| 独立工作流 `/workflows` | 见 C |
| 原管理员运行配置 `/legacy/settings` | 逐项核对：新「模型与 AI」等分区已有的删掉；还在用、新设置里没有的（如 AI 生图、dsh、技能目录）搬进对应新分区；只是展示基础设施信息的删掉 |
| 能力方法库 | 现行功能，从「高级运行环境」挪成设置里单独一项 |

最后删掉「高级运行环境」分区。

**C. 工作流：只留底层引擎和内置流程，去掉设计层**（用户 2026-10-24 确认）
- 保留：工作流引擎（平台模型写作的阶段运行、尝试记录、等人接受、历史；34 个后端文件依赖）和内置流程（角色默认 10 个、商品默认 2 个），只作平台模型写作的内部运行方式。
- 删掉：独立「工作流」页面、作品页「高级」里的「高级自动化」（工作流设计器与运行调试）、按项目覆盖流程、按角色设默认流程的编辑入口与接口，以及数据库里 40 个自动复制出来的项目级流程副本（删前确认没有运行在用它们；在用就改指向对应内置流程）。
- 理由：与第一设计原理「平台定结果不定步骤」相反；方向是强模型探路、把风格沉淀成模板 / Skill 给便宜模型用，不需要人画流程图。

**不做**：不改新版本功能；不删新版本数据（海底光缆等）；不新做「风格沉淀成 Skill」的功能（模板保留，后续单独提）。

## Impact

- Web：删 `pages/` 下旧页面及 `App.tsx` 路由；仍在用的组件移到 `product/`；`ProductSettingsPage.tsx` 分区调整。
- API：删 topics / generate / checks / reviews 中 Draft 部分 / article_handoff / dashboard 等路由与服务、对应模型；新增一个迁移删空表；保留 sources / facts / fact_packs / connectors / templates / workflows / settings 等新版本在用的后端。
- 测试：只针对被删代码的旧测试随之删除。
