# 已引入的原始素材文件夹看得见，并能更新素材

## 为什么
「引入原始素材文件夹」是一次性动作，路径不保存，重新打开输入框是空的，用户以为引入丢了。同一个文件夹后来放进新素材，也没有入口补进来。

## 改什么
1. 输入框下面列出这个项目已引入的文件夹：文件夹、文件数、已搬进项目文件夹几个。从已登记文件的原始路径推算，不新增存储；子文件夹并到同样被引入的上级文件夹，但不会扩大到没选过的文件夹。
2. 每个文件夹有「更新素材」：按原路径重新引入一次，只补新文件，已有的计为「已在项目里」。
3. 旧数据里从项目文件夹引入的（现在规则不允许）、或原文件夹已不在的，只显示不能更新。

## 不改什么
- 引入规则、成片通过后搬进项目文件夹的规则不变。
