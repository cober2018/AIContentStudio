# 配乐放进通用素材库时进 音频/BGM

## 为什么
新登记了 32 首配乐（素材 340–371），另有 3 首旧配乐（Dream Culture、Cipher、Thinking Music）。它们是候选状态，按存储清理规则，30 天未采用且未归档到项目或通用素材库的候选会被删，所以要放进通用素材库。
但「放进通用素材库」（`project_folders.to_common`）对所有音频都放进 `音频/音效`；只有视频制作里选作配乐的（role=music_audio）才进 `音频/BGM`。

## 改什么
- `to_common` 选文件夹时：带配乐信息（修订的 metadata 里有 `music`）的音频进 `音频/BGM`，其他音频照旧 `音频/音效`。
- 改完把上述 35 首配乐放进通用素材库。

## 不改什么
- 视频制作里的放置规则不变；图片、视频的规则不变。
