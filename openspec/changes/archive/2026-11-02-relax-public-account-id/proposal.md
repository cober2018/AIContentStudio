# 放宽账号公开标识的填写规则

## 为什么
登记 X 账号填「Kubo酱｜冲浪少女」被拦：除公众号外，公开标识只允许字母、数字、汉字和 `_ . @ -`。可国内很多平台没有对外 handle，只能填昵称，昵称里常有「｜」、空格、表情等字符。这条规则真正要防的是把密码、密钥、网址填进来，现在把正常昵称也拦了。

## 改什么（公众号以外的平台）
- 允许：任意文字，包括空格、全角符号、表情；首尾空格自动去掉；1–64 个字。
- 继续拦：
  - 换行、制表等控制字符；
  - 网址（含 `://` 或以 `www.` 开头）；
  - 含 password / secret / token / appsecret / bearer / api_key / apikey / credential 字样；
  - 以 `sk-` 开头（原来是「包含 sk-」，像 `desk-talk` 这样的正常名字会被误拦）；
  - 32 位以上、只由字母数字和 `+/=_-` 组成的长串（像令牌）。
- 页面提示同步改成：「其他平台填账号名、@handle 或昵称；不要填密码、密钥或网址。」
- 报错仍不回显填写的内容。

## 不改什么
- 公众号仍只收 wx 开头的 AppID（发草稿要用）。
- 「平台 + 公开标识」唯一、同角色同平台一个账号的规则不变。
