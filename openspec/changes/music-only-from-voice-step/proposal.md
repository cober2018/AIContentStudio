# 配乐只认「配音与音乐」这一步

## 为什么

商品作品的制作设置里有旧字段 `music_direction`，默认「不使用配乐」。只有旧流程「视觉与声音定样」能改它，视频作品的新流程里这一步已经不显示，用户看不到也改不了；但它仍随制作设置冻结进剪辑任务包，剪辑方读到后当成用户要求。项目 42 / 作品 83 的小样（任务 15）因此没铺配乐，用户其实要欢快轻快的配乐。新流程选配乐的地方是「配音与音乐」（主稿 payload.music），两个来源会互相矛盾。

## 改什么

1. **删掉 `music_direction`**：制作设置不再有这个字段；旧记录读回时丢掉（和已删的 voice_id 等同样处理），新任务包里不再出现。表单助手、旧「视觉与声音定样」输入框、作品留存里的字段同步删掉。
2. **主稿配乐三种状态**：
   - 选了音乐：`music = {material_revision_id}`（现状）
   - 不用配乐：`music = {none: true}`（新增，用户在「配音与音乐」里点「不用配乐」）
   - 未定：`music = {}`（没选过）
3. **「配音与音乐」页**：音乐区加「不用配乐」按钮；选了不用之后显示「这条不用配乐」，可以再拖音乐进来改回。
4. **剪辑方看到的**：视频简报和剪辑任务里写明配乐状态（已选哪首 / 用户明确不用 / 未定）。未定时提醒用户先在「配音与音乐」里定，不能自己当成不用。

## 不做

- 不改已经冻结的旧任务（任务 15 不动；作品 83 重做小样时按新规则来）。
- 不改音乐素材怎么找、怎么铺（音量、淡入淡出）。
