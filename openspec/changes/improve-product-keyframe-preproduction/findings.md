## 2026-10-17 第9节实施发现
1. **freeze manifest 形状缺口（本会话修复）**：`draft_stages()` 对 unit 绑定请求返回 `freeze_production_stages` 的 manifest（`{"schema", "stages": [行], ...}`），项目级请求才返回 dict 形状。前会话 `draft_method_projection` 只按 dict 形状解析，商品作品（总有 unit）实际请求的 configured_methods 恒为空。已改为两种形状兼容；version/package_hash 取自 manifest 方法本体，applicable_fields 在 manifest 形状下从注册表回查（仅展示用，冻结本体以 instruction+hash 为准）。
2. **方法条目 id 合法字符不含 `@`**：`validate_production_stages` 的 id pattern 为 `[A-Za-z0-9][A-Za-z0-9_.:-]{0,99}`，skill_ref 可带 @1 但 id 必须去版本（前端 mergedStages 用 `ref.split("@")[0]` 与探针一致）。
