# 从项目进商品视频，直接打开新建 SKU

## 为什么

新建项目后选「商品视频」，链接是 `/production?workspace=product&project=<项目号>`，工作台默认停在商品库列表（主界面）。用户期望直接进入「新建 SKU」（2026-10-30）。

## 改什么

1. 带 `project` 参数进入商品视频工作台时，一打开就是「新建 SKU」表单；顶部仍提示视频会加到哪个项目。
2. 表单上加一个「改选已有商品」，点了回到商品库列表，选已有 SKU 也能加进这个项目（现有逻辑）。
3. 从侧边栏直接进商品视频工作台（不带 project）不变，仍是商品库列表。
4. **商品主图支持粘贴图片**（用户 2026-10-30 追加）：主图旁加一个粘贴框，点一下再按 ⌘V，剪贴板里的图片（截图、网页右键复制的图）直接上传，和选文件一样；只收 png / jpeg / webp，剪贴板里不是图片就提示。新建 SKU 和编辑商品资料都能用。

## 不做

- 不改新建 SKU 表单的其他字段、保存逻辑和开始制作流程。
