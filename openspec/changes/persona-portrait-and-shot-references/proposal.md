# 角色形象照，以及生成画面自动取商品和人物参考

## 为什么

九宫格分镜（clone-reference-video）只靠两句文字描述人物和场景，不带商品主图，也没有人物来源：生成的人是模型随手编的，画面里的商品可能走样。用户定：建角色时带上照片；商品作品已有主图；没给素材时，平台据此生成画面；有形象照才生成带人的画面（2026-10-29）。

## 改什么

1. **角色形象照**：新建角色表单加「形象照」（选填，1–3 张真人照片），编辑资料里可补、可换。照片进素材库（通用素材，图片），作为这个角色的人物参考；角色资料只记照片的素材版本号。
2. **生成画面自动取参考**（九宫格分镜、每镜首帧、图生视频都按这条）：
   - 商品：自动带这个商品的主图；画面里有商品的格子 / 镜头逐个对照主图检查，不过关只重画那一个。
   - 人物：作品所属角色有形象照 → 带上照片，人物长相照它来。
   - 没有形象照：生成的画面不出现人物（不露脸、不出现身体），只拍商品和场景；需要拿商品的镜头只拍手部特写。导演稿里写了人物的镜头，提示改成商品 / 场景镜头或先给角色补照片。
3. **有素材照旧**：用户提供的实拍和素材优先，上面这套只补没有素材的镜头。
4. **九宫格去掉「商品镜头一律排除」**：有主图后商品镜头也能进九宫格，靠逐格检查保住商品原样；商品纯特写仍建议单独生成。

## 不做

- 数字人 / 口型同步。
- 不改已有作品的「共同视觉参考」手动选择；手动选了的优先于自动取的。
