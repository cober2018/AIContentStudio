# 内容机会页显示数据源运行情况

## 为什么

2026-10-31 排查发现两个故障在现有页面上都看不出来：21 个单独信息源两周没被安排抓取（没报错）；卡哟哟聚合站停更 5 天（每次同步「成功」但 0 条新内容）。用户只要一个地方集中看数据源情况，不要告警。

## 改什么

1. 「内容机会」页顶部加「数据源运行情况」表，默认展开，可收起。
2. 每个未合并的信息源一行：名称（标聚合站）、状态（正常 / 报错及原因 / 已暂停）、最近成功抓取、下次抓取（无角色使用时显示「未被安排」及原因）、近 7 天每天新内容数、最近一条新内容时间。
3. 后端新增只读接口 `GET /content-opportunities/discovery/source-health`，数据从现有表计算，不改数据库。
4. 原因「credential_required」（网站返回 401/403）的提示由「需要登录凭据」改为「网站拦截访问」。
5. 每个角色今日选题数沿用页面现有的运行状态条，不重复做。

## 不做

- 不做告警、通知、定时巡检。
- 不改现有信息源列表和首页状态行。
