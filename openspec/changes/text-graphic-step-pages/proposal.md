# 文字 / 图文作品改成「一步一页」，删掉旧的制作页

## Why
文字和图文作品的制作页还是旧的五步：选题与资料 → 内容方案 → 制作内容 → 审阅修改 → 交付。
现在写稿、采用、出图、验收都在「内容方案」里做完，「制作内容」「审阅修改」放的是旧的主稿编辑器、手动出图工作台、执行包、方法等，用户看了没用、还会误点。
产品还没上线，旧东西不挪进「高级」，用不上的直接删（只留新版本）。「平台模型」写作是基础功能，保留。

## What Changes
1. **新步骤**（角色的文字 / 图文作品；商品作品和视频不动）：

   | 步骤 | 图文 | 文字 |
   |---|---|---|
   | 1 选题与资料 | 不变 | 不变 |
   | 2 稿子 | 写作方式开关；第三方模型：看稿、采用或写意见；平台模型：在这里跑平台创作流程，出的稿同样在这里采用或写意见 | 同左 |
   | 3 成图 | 看平台出的每张图，验收通过或写意见退回 | 没有这一步 |
   | 4 交付 | 发布文案；送审状态（已送进审阅与交付 / 失败原因和重试） | 发布文案（有就显示）；渠道版本面板，从这里进审阅与交付（沿用现有面板） |

   每一步只显示这一步的内容；没到的步骤显示「还没到这一步」和「去当前步骤」，做法同视频。
2. **平台模型接上同一条链**：平台创作流程采用的稿子，同样停在「稿件待你看」由用户采用；图文采用后同样出图 → 成图验收 → 送审。写意见时：第三方模型照旧出下一版；平台模型在「稿子」一步重跑创作流程。
3. **删除（只服务旧五步的部分）**：
   - 文字 / 图文作品页上的「制作内容」「审阅修改」两步、主稿编辑器（版本在「稿子」一步的版本列表里看），以及页面底部「渠道、执行、方法与高级工作流」整块（文字的渠道版本面板搬进「交付」）。
   - 手动出图工作台（GraphicRenderPanel，每张画布「渲染 → 接受 → 绑定」）及只给它用的两个接口 `media-render-previews`、`media-render-outputs` 和对应测试；出图统一走平台自动出图。
   - 图文编辑器里只服务手动出图的部分；平台创作流程审阅阶段提案时仍要看图文 / 文字内容，那部分保留为只读预览。
   - 旧链接 `workstep=make / review` 落到当前所在步骤。

## 不做
- 不动视频、商品作品的页面和流程。
- 不改出图样式和字体。
- 不删共用的组件（主稿面板、创作流程、执行包、方法面板等商品作品和视频「高级」还在用）。

## 验收
- 图文作品页只有 4 步、文字 3 步，没有旧的编辑器和底部高级块。
- 第三方模型、平台模型两种写法都能走完：稿子 → （图文）成图验收 → 交付 → 审阅与交付。
- 手动出图接口和页面已删除，相关测试已删或改。
- 作品 101 页面按新步骤显示，停在「成图」一步等验收。
