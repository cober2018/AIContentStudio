# 剪辑任务可以交封面图

## 为什么

商品视频要一张单独的竖版封面（1080×1920，实拍画面当背景，上面大字商品名和卖点），发布时选它当封面（2026-10-30）。现在剪辑任务能交的文件里没有封面（web_video_handoff.edit_contract），导出目录也只有「导出/小样」「导出/成片」（project_folders.export_dir），第三方模型做好了也交不上、用户拿不到。导演稿的「封面」栏是输入素材，不是剪辑结果。

## 改什么

1. **剪辑任务多一个可选交付「封面图」**（cover）：小样和成片任务都有；一张，jpg 或 png，不交也能完成任务。
2. **封面放「导出/封面/」**：交付时文件必须在项目的「导出/封面/」里，平台原地检查登记，不复制（和小样、成片一样）；开剪时告诉第三方模型这个目录。
3. **审片页显示封面**：小样 / 成片审片时，视频旁边显示这次交的封面图；没交就不显示。
4. **成片通过后就是作品封面**：用户通过成片时，这次任务交的封面写进作品主稿的封面（payload.cover）；没交就不动原来的封面。
5. **剪辑规则加一条**：封面竖版 1080×1920，实拍画面当背景，大字商品名和卖点；同一张可以剪进视频开头当 0.5 秒第一帧（剪辑时做，平台不管）。

## 不做

- 不在平台里生成或排版封面（第三方模型在 AE / 达芬奇里做）。
- 不强制检查尺寸，只在规则里写明。
- 导演稿「封面」栏（输入素材）不变。
