## 1. 出图与登记
- [x] 1.1 采用图文后，按画布逐张用本地出图工具出 PNG，校验尺寸，存为成图素材（权限随画布图片，有一张不可公开就停）

## 2. 送审
- [x] 2.1 按作品渠道和形式生成渠道版本、跑检查、冻结候选，进「审阅与交付」待审批
- [x] 2.2 失败不撤销定稿；记录失败原因

## 3. 页面
- [x] 3.1 作品页显示出图 / 送审状态和失败原因；已定稿无候选时显示「重新出图并送审」
