# 先对应素材，再给缺画面的镜头生成视频

## 为什么

用户审导演稿时，页面上每个镜头都摆着手动 / 自动和提示词，自动生成还能在采用前就点；但素材和镜头的对应要等采用后才做，所以看不出哪些镜头已经有自己的素材、根本不用生成，可能白花生成费（2026-10-30）。用户定的顺序：审导演稿只看内容 → 采用后对应素材 → 对应完还缺画面的镜头再选手动或自动。

## 改什么

1. **导演稿这一步只看内容**：去掉商品镜头面板（手动 / 自动、提示词、首帧、生成按钮）；导演稿表格里不再显示每镜的素材状态（这时还没对应，全是「待补」没有意义）。
2. **采用前不能生成**：首帧生图、自动图生视频、切换手动 / 自动在导演稿采用前一律拒绝，提示「先采用导演稿，对应完素材再生成」。九宫格分镜本来就要求采用后，不变。
3. **素材这一步先看对应结果**：最上面一句汇总，例如「共 12 镜：7 镜已用你的素材 · 5 镜缺画面」；下面按镜头列：
   - 已有素材的镜头：显示用的哪条素材，不出现生成选项；
   - 缺画面的镜头：才显示手动 / 自动、提示词、首帧和生成按钮。
4. **第三方模型的顺序写进规则**：采用后先把用户素材对应到镜头（set_shot_materials），再只给缺画面的镜头生成；不给已有用户素材的镜头生成。

## 不做

- 不改导演稿内容的写法和审核方式。
- 不改手动 / 自动生成本身（提示词、计费确认、首帧检查都照旧）。
- 已有素材的镜头仍可手动换成生成（在素材那一步把素材拿掉即可变成缺画面），不另加开关。
