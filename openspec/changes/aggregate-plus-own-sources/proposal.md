# 聚合站 + 自己订阅的信息源一起用

## 为什么

10-16 接入卡哟哟聚合站后，规则是角色选了聚合站就只认聚合站（和本角色的新词雷达），自己订阅的 21 个单独信息源（Simon Willison、宝玉、阮一峰、Hugging Face、GitHub Blog、少数派等）从此不再抓取。10-26 起两个卡哟哟站上游停更，平台每天 0 条新素材，内容机会 10-29 起每天 0 个选题（2026-10-31 排查）。另外，日常生活方式博主从 10-27 起每天的选题任务因「聚合证据被撤回」整次被拦下。

## 改什么

1. **单独信息源照常抓**：角色选了聚合站，仍然按原有节奏抓取它订阅且已启用的单独信息源；角色允许使用的来源 = 聚合站 + 新词雷达 + 自己订阅且启用的单独信息源。
2. **选题证据一起用**：每天出选题时，聚合站、新词雷达和单独信息源的新内容一起作为证据；每天的选题上限、模型调用预算和评分规则不变。
3. **一条聚合证据失效不拦整天**：聚合站把某条内容撤下时，只去掉这一条证据，其余证据照常出选题；全部证据都失效才算没有选题。
4. **恢复积压**：改完后，停在 10-16 的 21 个单独信息源下一轮就到期，按现有补抓规则补回最近的内容，不额外设置。

## 不做

- 不修卡哟哟上游（用户那边处理）。
- 不给没订阅信息源的角色（如懒羊羊小王）自动加源。
- 不改信息源的验证、暂停、失败重试规则。
