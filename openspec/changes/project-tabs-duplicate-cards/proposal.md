# 项目页切换子页后出现重复的「商品创作」卡片

## 为什么
项目 48「敏贝贝动物小饼干」在「项目资料 → 项目素材」里出现了 3 张一模一样的「商品创作」卡片。数据没问题：这个项目只有 1 次商品创作、1 条作品；「商品创作」卡片按代码也只该出现在「创作任务书」子页。
原因：`PersistentProjectPage.tsx` 里各子页组件（总览、商品创作卡片、创作任务书、来源与证据、作品、项目素材、版本、活动等，共 9 个）是同一层的兄弟，却都用了同一个 key（项目编号）。React 遇到同层重复 key 时，切换子页可能留下没卸掉的旧节点，于是「商品创作」卡片每切一次就可能多留一张，出现在别的子页里。

## 改什么
- 每个子页组件的 key 加上子页名（如 `brief-launch-48`、`assets-48`），同层不再重复。

## 不改什么
- 不改各子页内容和数据。
