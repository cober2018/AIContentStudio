# 复刻参考视频：拆解成导演稿、视频提示词规则、九宫格分镜

## 为什么

用户想用平台复刻爆款口播 / 带货视频（样本见 findings.md）。平台能做配音、字幕、商品镜头、AE 卖点动画和剪辑，但缺三样：把参考视频拆成导演稿的工具；让人物镜头有态度、有表演的提示词规则；多个镜头里人物和场景保持一致的分镜方法。

## 改什么

### 1. 拆参考视频 → 导演稿初稿 + 拍摄清单
- 作品页「导演稿」一步可以上传或选一条参考视频（素材库里的视频也行）；MCP 同时给第三方模型一个「拆参考视频」工具。
- 平台在本机做不花钱的部分：逐词转写（带时间）、切点、每段关键帧拼图、响度。结果存成这条作品的「参考拆解」，不改原视频。
- 第三方模型按新 skill「拆参考视频」（借 hypit 的方法）写两样东西：整体分析（想表达什么、为什么抓人、有哪些画面系统：字幕、贴纸、特效、配乐）和时间线（每段口播、画面、叠加元素、作用）。
- 再据此出这条作品的导演稿初稿：口播换成本商品 / 本角色的说法，结构和节奏照参考；每镜标明素材来源是「需要实拍」「商品图 / 生图」「AE 模板」「素材库」。
- 「需要实拍」的镜头汇总成拍摄清单（拍什么、谁出镜、景别、机位、时长、注意事项），页面上能看、能导出。
- 参考里的品牌声明（证书、医院、成分）只记成「需要品牌真实资料」，不照抄、不生成。参考视频的水印和原画面不进成片。

### 2. 视频提示词规则（新 skill「视频提示词」，并收进平台默认规则）
- 人物镜头：先写人物态度和对谁说（如「第一次吃到自己能吃的零食，又惊又喜」），再写一两个关键反应；不给每句配动作。
- 首帧 / 人物图：按「拍摄方式 / 人物 / 动作与镜头 / 场景」四段写；手机实拍感用固定写法。
- 每种输入各管一件事：商品图管商品外观，人物图管长相，提示词只写这一镜的态度、动作和运镜，不重复描述包装。
- `motion_prompt` 加「态度」一项：导演稿每镜可写 `attitude`，有就排在提示词最前面。
- 参考视频作为生成输入：规则先写进 skill；MiniMax H3 只支持首尾帧，换到支持参考视频的模型时再生效。

### 3. 九宫格分镜图（可选）
- 导演稿采用后，可以一键生成「九宫格分镜」：一次生图把最多 9 个人物 / 场景镜头画在一张 3×3 图里，人物、服装、房间、光线一致。
- 平台自动按格裁成每镜关键帧，放大到目标清晰度，作为这一镜的首帧候选；哪一格不满意，只重画那一镜。
- 商品特写镜头不进九宫格（格子太小商品容易变形），仍按商品原图单独生成并对照检查。
- 超过 9 镜分成多张，第二张带上第一张做参考，保持一致。
- 关键帧之后照常走图生视频（自动或手动）。

## 不做
- 贴在实拍上的贴纸 / 特效 AE 模板、数字人 / 口型同步、字幕关键词变色（另提）。
- 不装 hypit 程序、不用它的模型服务；只借方法写进我们的 skill。
- 不下载网上视频；参考视频由用户提供。
