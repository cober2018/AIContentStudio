# 声音配置支持语言增强和声音调整

## 为什么

用户给了男声的一版 MiniMax 配置，其中 `language_boost`（中文增强）和 `voice_modify`（音调 / 强度 / 音色）平台发不出去：平台经 mmx 命令行配音，命令行没有 voice_modify，language_boost 平台也没往下传。

## 改什么

1. **配音改成直接调 MiniMax 的配音接口**（`/v1/t2a_v2`），不再经命令行。只留这一条路；钥匙和地址沿用设置里已有的 MiniMax 配置，不新增。
2. **声音配置加 4 个字段**（设置 → 配音，每套声音单独设）：
   - 语言增强：不设置 / 自动 / 中文 / 粤语 / 英语 等 MiniMax 支持的值。
   - 声音调整：音调、强度、音色，各 −100 到 100，默认 0（不调整）。
3. **男声按用户这版配**：语言增强 = 中文；音调 2、强度 −2、音色 0（其余参数上一轮已配好）。
4. **字幕照旧按句**：接口返回的字幕时间转成现在用的 SRT，配音面板、剪辑不受影响。

## 不做

- 逐词字幕（下一轮和贴纸、字体一起做；换成接口后只需打开 `subtitle_type: word`）。
- 音效类声音调整（sound_effects）。
