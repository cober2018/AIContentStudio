## 试用中发现并已修的问题
- 本体页「当前稿件」不显示列表块，「做法与口径」「出处」看起来是空的 → 补上列表和引用的显示。
- 长文出公众号版本失败（机械映射只收纯段落）→ 公众号文章本来支持标题、引用、列表，改成按本体逐块搬过去（同样的字、同样的顺序），存成普通编辑版本。
- 形态相关的报错经 MCP 只剩 `creative_domain_conflict` → 让 body_/form_ 开头的错误把中文原因带给模型。
- 重做后旧作品还能再点重做 → 标「已按新本体重做」并拒绝第二次。

## 没做 / 留给后面
- tasks 3.2：现有视频、图文、文章写作 skill 还没逐条改成引用 craft-writing、删掉重复条目。现在是 brief 里统一附上写作标准。
- 本体改版后，长文的公众号版本不会自动跟着出新版；渠道变体页会显示它的来源不是最新，要在那里手动再出。
- 「节选要标注」只写进了标准，平台查不出来；数字检查只查阿拉伯数字，口播里写成中文的数字（「百分之十二」）查不到。
- 平台机械限制表的数字是按各平台发布页常见限制登记的，没逐个登录后台核对；公众号「简介 120 字」是文章摘要的限制，视频发公众号是否同样适用未核实。
- 健康检查里 `schema_head_mismatch` 是之前就有的（批准的库版本常量还写着 websearch0001），这次没动。
