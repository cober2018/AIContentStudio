# PRD：商品视频的每个作品都能选一个角色

> 本需求由另一个开发 agent 实施。用户已确认需求方向（2026-11-02），实施前仍按 OpenSpec 流程：开发 agent 读完本目录后，若有关键歧义只问用户一个问题，否则直接按本文实施。

## 背景与问题
- 商品视频作品（`content_unit.production_domain = "product"`）的「角色」决定两件事：
  1. **声音**：一键配音用角色固定的声音（`voiceover.settings_for`），没角色就用默认声音（男声）；
  2. **人物长相**：生成画面时人物照角色形象照（`product_video.references` 取角色形象照），没角色就画面里不出人。
- 现在只有**新建时**能选角色（商品视频工作台「属于哪个账号角色（声音跟着角色走）」，可不选）。**建好之后改不了**：作品接口对商品作品明确拒绝改角色（`routers/content_projects.py` 约 715 行：「商品作品请使用商品配置与工作流入口，不绑定内容角色」），作品页也没有入口。
- 结果：正式库 6 个商品作品只有 1 个有角色（83 儿童麸质饼干 → 懒羊羊小王）；84、85、90、91、92 都没有，配音只能用默认男声、人物镜头不能生成。复制出来的作品（如 92）也沿用原作品的空角色。

## 要的结果
1. **每个商品作品都能选、能改角色**：
   - 新建时照旧可选（保留「不指定」）；
   - 建好后在作品页第 1 步「商品与本条目标」里显示当前角色，并能改成别的角色或「不指定」；
   - 成片定稿（锁定）后不能再改，与其它设置一致。
2. **改了角色立即影响之后的生成**：之后的一键配音用新角色的声音，之后生成的画面用新角色的形象照；已经生成的配音、静帧、视频不动。
3. **只用用户自己的、在用的角色**；选了还没定声音的角色时，作品页提示「这个角色还没定声音，配音会用默认声音」（不拦）。
4. 商品作品的商品资料、制作设置、导演稿不受改角色影响；商品作品**不建身份快照**（与现在一致，商品资料来自商品，不来自角色资料）。
5. 改角色记一条项目事件（谁、从哪个角色改成哪个）。

## 范围外
- 不改角色视频（persona 作品）的选角色逻辑。
- 不改导演稿里按镜头指定配音角色的 `dub_persona`（那是「某一镜由哪个角色配音」，与作品本身的角色是两回事，可并存）。
- 不做商品作品的投放账号与角色联动（现在商品作品用独立账号，`channel_variants.py` 约 258 行对商品作品不校验账号归属角色，保持不变）。

## 验收
- 作品 92：作品页第 1 步把角色改成「懒羊羊小王」→ 刷新仍是懒羊羊小王；任务书（get_video_brief）里人物规则变成「有形象照」或按该角色实际情况；一键配音用「女声」。
- 作品 90（已定稿）：角色选择不可改。
- 改成「不指定」后，配音回到默认声音、人物镜头规则回到「不出人」。
- 后端全量测试只允许已知 5 个失败；前端 tsc 通过。
