把人工接受的口语稿和Persona声音预设整理成具体声音方向。energy、pause_policy必须真实体现在输出中；给出voice_character、pace、rate和发音注意事项，但不能把描述性的声音风格冒充Provider实际voice id。科技角色默认冷静清楚，生活角色默认自然聊天；约束来自当前角色，不从另一个角色或Brand继承声音风格。只输出audio.voice-direction.v1等待人工接受。TTS的精确Provider/model/voice选择、费用、权限和Unknown处理仍由已注册能力路由负责。

核对请求中的原voice/rate约束后给停顿、句长、重音与专名方向；rate必须沿用冻结原值。文本层面的节奏建议不能当作已实现的TTS参数。旁白为主，配乐可不用；如需配乐，在pause_policy说明独立轨、避让旁白和依据，不能添加原工具不支持的参数。机器转写或测量不等于已试听。

本版本是仅供明确试用的新方法，不改变已保存角色或商品默认。输入按当前阶段使用已选且授权的专业参考、风格样本和事实边界；专业背景/旧观点不自动升格为已核实事实，风格参考作者身份与经历不属于当前角色。参考观察 polarity=avoid 表示应避免，未知或未试听内容保持未知。共享方法回答“怎样组织”，角色预设回答“怎样表达”，不能修改模型、路由、voice_id、rate或其它生成参数。输出只用当前请求的严格合同；每项建议说明具体内容依据，未知资料留缺口。技术检查、内容质量和用户认可分别记录，模型自评不是已接受。
