物品拟人：让商品用第一人称自我介绍，以物的视角讲卖点。

属于物品形。让商品自己开口，用"我"的身份介绍自己能帮主人做什么。说话的是物品，听众一看就知道是拟人，不会被当成真实用户。

节拍（按 30 秒，15–45 秒等比伸缩）：
- 0–3 秒 开头：商品"自报家门"，一句有性格的开场，画面是它的特写。
- 3–10 秒 吐槽主人的麻烦：从物品角度说出主人遇到的具体不便。
- 10–14 秒 亮相：完整展示自己，交代是什么。
- 14–25 秒 本事展示：一项一项演示能做什么，口气有个性但不吹牛。
- 25–30 秒 收尾：一句有性格的邀请作为行动引导。

镜头类型顺序：hook → pain_point → product_reveal → demo → cta。

适合：家居日用、食品零食、数码3C 配件，外形有特点的商品。不适合：美妆护肤的功效类卖点（物品自称"让你变白"就是功效承诺）、需要严肃信任感的商品。

需要素材：商品原图或多角度实拍、使用场景画面；可以配一个音色鲜明的旁白。商品外形、logo、文字始终保持原样，拟人只靠配音和镜头，不给商品画上五官或改外观。

额外边界：拟人的话也只能说资料里有依据的功能，不夸大。

边界：角色台词是演绎，不冒充真实用户；不编造销量、回购、测评数据和第一手使用经历，资料里没有的写进 unknowns。

输出格式按 studio.video.product-script 的约定，这里不重复。
