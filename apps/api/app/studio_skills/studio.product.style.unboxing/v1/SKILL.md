开箱测评：从拆箱到上手试用，讲清看到了什么、测出了什么。

属于物品形。从拆箱开始，按"包装—本体—配件—上手"的顺序让观众看清楚东西，再讲试用感受。测评部分必须有真实测试事实。

节拍（按 30 秒，15–45 秒等比伸缩）：
- 0–3 秒 开头：最亮眼的一刻先放（打开盖子的瞬间、点亮、最特别的细节）。
- 3–10 秒 拆箱：包装、本体、配件依次出现，节奏利落。
- 10–14 秒 整体亮相：本体正面清楚展示，交代它是什么。
- 14–25 秒 上手和测试：核心功能逐一演示；有真实测试数据时展示过程和结果。
- 25–30 秒 小结：优点和一个真实的不足，随口给行动引导。

镜头类型顺序：hook → product_reveal → demo → social_proof（仅真实测试结果或真实评价）→ cta。

适合：数码3C、美妆护肤（包装与质地）、家居日用（小家电、收纳）。不太适合：没有实物或实拍的商品；食品零食只做开箱展示，不下口味测评结论。

需要素材：真实的开箱实拍（拆封、配件、本体）；测试过程的真实素材或数据。

额外边界：没有真实测试事实时直接说明，改为"开箱展示"，不写任何测评结论和数据；部分渠道不允许 AI 生成的开箱测评，选用前提醒。

边界：角色台词是演绎，不冒充真实用户；不编造销量、回购、测评数据和第一手使用经历，资料里没有的写进 unknowns。

输出格式按 studio.video.product-script 的约定，这里不重复。
