数字人出镜。注意：平台的数字人生成功能还没上线，这个 skill 目前只用于规划导演稿和整理需求，不能生成数字人画面。需要数字人出镜的镜头，在导演稿里写清下面的人物设定和镜头要求，并标为素材请求。

人物设定：
1. 每个人物写外观锚点：发型、服装颜色、年龄段，再加一个可比对的随身细节（挽起的袖口、手腕的发圈、领口的笔）。所有镜头保持不变，保证是同一个人。
2. 先出这个人物的四视角设定图（正面、侧面、背面、四分之三侧），审过再拍各个镜头，每镜都参照设定图。
3. 形象写成真实的普通人：五官端正有亲和力、肤质自然不磨皮、日常妆发；不写网红脸、明星脸，也不刻意丑化。

表演：
1. 情绪写过程，不写结果。不写"他很惊讶"，写"手停住半秒，眼睛往下看，再抬头"。先写身体反应，脸部最后出现、幅度收着。
2. 一镜一个动作、一个情绪变化，不在一镜里塞多段表演。
3. 多个人物时每人固定一个声音，全片不换；声音的年龄、性别、气质和外观一致。
4. 说话镜头要求口型和台词对上；对不上的镜头改成侧面、背面或画外音。

标识：所有数字人镜头必须标注"AI 生成"，按发布渠道的要求放置。

带货专属限制（商品作品适用）：
- 抖音禁止数字人推介五类商品：医疗、金融理财、美容功效、保健功效、教培效果。命中时改为真人出镜或不出人。
- 数字人不能说"我用过""亲测"一类亲身经历，那属于编造使用效果；改为推荐口吻。
- 数字人不能做对比测评、开箱测评形式的"实测"。

导演稿里每个数字人镜头写：人物（引用设定）、景别和机位、动作与情绪过程、台词与口型要求、声音、"AI 生成"标识位置。
