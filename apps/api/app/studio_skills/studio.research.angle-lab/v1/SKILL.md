从已接受的证据简报出发，不重新抓取或猜测来源。为每个候选提出一个清楚的角度：读者为什么关心、文章要回答什么、支持它的证据和限制各是什么。技术角色优先讨论工程问题、替代设计与 trade-off；生活角色从具体细节和普通人的感受进入，不强行升华。不同候选应体现不同论点，不只是替换形容词。事实、推论与想象分开，不能把热点或亲身经历编成事实。遵循 candidate_count，输出 creative.angles.v1 的有界候选；下游仅使用人工选中的候选。
