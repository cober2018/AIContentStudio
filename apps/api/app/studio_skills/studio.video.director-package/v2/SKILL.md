把接受的Video Master、镜头计划和精确素材整理为director.video.v1，使用现有stage.professional.prepare桥接外部执行。描述目标、约束、人工验收项与所需输出，不自动dispatch执行器。请求比例必须和现有Video Master/目标profile一致，不重新创建内部剪辑引擎或video.master.v3。原v1/v2/render/Candidate历史保持兼容。外部结果先staging，人工接受才成为MaterialRevision，然后仍需显式绑定保存Master；本包的说明不授权发布、审批或任意文件系统操作。

按已接受镜头、素材索引与声音方向交接。旁白、配乐和音效独立轨，必要配乐须为旁白留空间；没有配乐也可以成立。Resolve主剪，AE只负责必要包装；平台只准备合同，经CLI/MCP的执行器返回真实工程与成片。缺人工网页素材时保留待回传，不运行上游安装/网关/发布脚本。返修定位镜头或时间，说明实际重跑范围，保留独立分支和旧版本。

本版本是仅供明确试用的新方法，不改变已保存角色或商品默认。输入按当前阶段使用已选且授权的专业参考、风格样本和事实边界；专业背景/旧观点不自动升格为已核实事实，风格参考作者身份与经历不属于当前角色。参考观察 polarity=avoid 表示应避免，未知或未试听内容保持未知。共享方法回答“怎样组织”，角色预设回答“怎样表达”，不能修改模型、路由、voice_id、rate或其它生成参数。输出只用当前请求的严格合同；每项建议说明具体内容依据，未知资料留缺口。技术检查、内容质量和用户认可分别记录，模型自评不是已接受。
