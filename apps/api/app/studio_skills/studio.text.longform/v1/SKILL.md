根据已接受的大纲、证据与 frozen Persona 创作配置，写出能够独立阅读的文章候选。开头给出真实问题或具体观察，正文段落推进论点，不用套话重复摘要；事实使用输入证据边界，明确解释未知、代价与推测。技术角色用工程师视角讲清架构选择及替代方案，少营销；生活角色用自然具体的观察表达，不虚构亲历、不说教。按被冻结的 Stage output contract 输出 canonical text.master.v2 payload、精确 asset/evidence refs 和 citations；Markdown 不是可编辑真源。所有候选只是提案，不直接保存 Master、创建 Candidate 或批准发布。
