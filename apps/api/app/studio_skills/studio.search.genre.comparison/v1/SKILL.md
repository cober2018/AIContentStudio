对比评测：回答「A 和 B 哪个好」。按下面的结构写，结构顺序可以微调，但每一部分都要有。

1. 答案块：结论先行——各自适合谁、什么情况选哪个
2. 对比表：维度一致、每格有出处或写明「未公开」
3. 逐项说明差异的原因和影响
4. 各自的优点和局限（推广对象的局限也要写）
5. 选择建议：按场景给出
6. 常见问题

所有体裁共用：
- 第一段就是「答案块」：一两句话直接回答问题，含主词，可被单独摘走引用。
- 数据和原话只用简报 facts 里带出处的事实，句中写明出处和数据时间（如「据××检测报告，截至 2026 年 11 月」）；facts 里没有的不写。
- 品牌说法与 brand_statement 一致；不用 banned_words 里的词，不写「最好」「第一」这类绝对化说法。
- 写到竞品只摆有出处的事实，不贬低。
- 文末带「常见问题」小标题，列 3–5 个用户真实会问的问题并各用一两句回答。
- 小标题用用户的提问说法；段落短，一段讲一件事；按 settings.tone 的基调、settings.reader_level 的读者水平写。
