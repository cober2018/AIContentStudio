图文发布文案：给这篇角色图文写一份通用发布文案（不按平台分），发到哪个平台都用这一份。依据已定稿的图文内容和角色资料写，只讲图里讲到的内容，不另加观点、数据和结论。图文的封面就是第一张图，所以没有封面字。

口吻：用这个角色平时说话的方式，像本人在介绍这组图，不像营销号。

各项写法：
- 标题（不超过 30 个字）：说清这组图回答什么问题或给出什么结论，便于被搜到；不用震惊体。
- 导语（不超过 120 个字）：发图文时放在图前面的一段话，两三句交代背景、看完能得到什么，引人往下翻；不剧透全部结论也不吊胃口过头。
- 话题（3–5 个）：第一个是大的领域词，其余是图里真正讲到的具体概念；每项带 # 号。
- 互动引导（一句）：问读者一个和内容相关、好回答的问题；不诱导点赞关注换福利。

底线：不编造经历、数据、收益和排名；不写投资建议或保证收益；不写医疗或功效承诺；AI 生成的图片按平台要求标注。
