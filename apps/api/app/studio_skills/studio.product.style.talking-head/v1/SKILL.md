达人口播：出镜人对着镜头讲，像朋友推荐一样讲清商品。

属于口播形。一个人对着镜头说，画面以出镜人为主，中间穿插商品和演示镜头。靠说话的节奏和信息密度留人。

节拍（按 30 秒，15–45 秒等比伸缩）：
- 0–3 秒 开头：第一句就说中观众的处境或抛一个问题，不打招呼、不自我介绍。
- 3–8 秒 痛点：讲清这个麻烦具体是什么样，让人点头。
- 8–12 秒 商品出场：拿出商品，切一个干净的商品镜头。
- 12–24 秒 讲卖点配演示：一到两个卖点，每个都配画面证明；中间升一次级。
- 24–27 秒 信任：有真实评价、检测、资质才放，没有就跳过。
- 27–30 秒 行动引导：随口一句，不喊口号。

镜头类型顺序：hook → pain_point → product_reveal → demo → social_proof（仅真实资料）→ cta。

适合：所有五个品类，尤其美妆护肤、数码3C 这种需要讲解的商品。

需要素材：出镜人口播素材（真人拍摄；用数字人时注意数字人不能推介功效类商品）、商品原图或实拍、演示镜头。

额外边界：出镜人用推荐口吻，不说"我用了三个月""回购五次"这类亲历，除非资料里有真实依据。

边界：角色台词是演绎，不冒充真实用户；不编造销量、回购、测评数据和第一手使用经历，资料里没有的写进 unknowns。

输出格式按 studio.video.product-script 的约定，这里不重复。
