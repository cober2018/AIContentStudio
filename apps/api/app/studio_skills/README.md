# Studio Creative Skill packages

Product-owned declarative methods for the approved Persona Creative Studio requirement. These resources do not install Agent Skills or execute scripts.

## Structure

Each version directory has `SKILL.md`, `STUDIO-CONTRACT.json` and `STUDIO-META.md`. Existing research/Text packages also retain `tests/fixtures.json`; this consolidated batch adds no new test files. Runtime reads only the selected exact package; inventory remains bounded metadata.

## Decisions / dependencies

Skills belong to one system — product, persona or shared (`studio_creative_catalog.skill_system`); a work only sees its own system plus shared ones. 
Workflow remains Recipe truth. Skills propose results; domain services own explicit acceptance. Contracts and provenance hashes are frozen in Attempt receipts. Existing API startup is unchanged; packages ship as application data with no new dependency or migration.
