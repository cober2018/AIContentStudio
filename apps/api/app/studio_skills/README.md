# Studio Creative Skill packages

Product-owned declarative methods for the approved Persona Creative Studio requirement. These resources do not install Agent Skills or execute scripts.

## Structure

Each version directory has `SKILL.md`, `STUDIO-CONTRACT.json` and `STUDIO-META.md`. Existing research/Text packages also retain `tests/fixtures.json`; this consolidated batch adds no new test files. Runtime reads only the selected exact package; inventory remains bounded metadata.

## Complete / TODO

Twenty research/Text/Graphic/Audio/Video v1 packages are shipped. Every package is bounded and resolves exact contracts; execution support is reported separately. Graphic composition and QC are registered deterministic tools. Additive Audio TTS/QC and Director wrappers use existing domain services. Portable recipe/resource smoke passes, while independent integration review and real-provider creative-quality acceptance remain separate gates. Persona trial v2 packages exist for the fourteen planning methods; `studio.video.script@3` and `studio.video.shot-director@3` (2026-10-21, change distill-material-aware-video-skills) add material-aware planning: each beat uses exact catalog material, is rewritten to fit available material, or keeps a structured material request. Trial versions never change saved Persona or product defaults without explicit adoption.

## Decisions / dependencies

Workflow remains Recipe truth. Skills propose results; domain services own explicit acceptance. Contracts and provenance hashes are frozen in Attempt receipts. Existing API startup is unchanged; packages ship as application data with no new dependency or migration.
