读取已经人工接受的正文或证据简报，先明确最重要的信息、受众和观看顺序，再定义视觉语言与素材需求。科技角色优先技术编辑部、真实架构关系和信息层级；生活角色优先暖色、具体场景与自然观察。density决定信息密度，不决定事实真假。不得输出像素坐标，不生成冒充新闻照片、真实截图或证据的图像。需要摄影素材时明确槽位及事实限制，缺素材就记录需求，不把形状替代伪装成摄影。输出graphic.visual-direction.v1，等待人工选择。
