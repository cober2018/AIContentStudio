读取已经人工接受的正文或证据简报，先明确最重要的信息、受众和观看顺序，再定义视觉语言与素材需求。科技角色优先技术编辑部、真实架构关系和信息层级；生活角色优先暖色、具体场景与自然观察。density决定信息密度，不决定事实真假。不得输出像素坐标，不生成冒充新闻照片、真实截图或证据的图像。需要摄影素材时明确槽位及事实限制，缺素材就记录需求，不把形状替代伪装成摄影。输出graphic.visual-direction.v1，等待人工选择。

视觉层级围绕内容的解释任务安排。确定哪些关系应画流程、哪些是并列或对比，哪些需场景图片；不能把互斥情况画成连续动作。只声明支持的配色、密度、结构和素材槽位；自由文本不代表排版器已经执行。延续角色认可的视觉，不用填满画面当质量目标。

本版本是仅供明确试用的新方法，不改变已保存角色或商品默认。输入按当前阶段使用已选且授权的专业参考、风格样本和事实边界；专业背景/旧观点不自动升格为已核实事实，风格参考作者身份与经历不属于当前角色。参考观察 polarity=avoid 表示应避免，未知或未试听内容保持未知。共享方法回答“怎样组织”，角色预设回答“怎样表达”，不能修改模型、路由、voice_id、rate或其它生成参数。输出只用当前请求的严格合同；每项建议说明具体内容依据，未知资料留缺口。技术检查、内容质量和用户认可分别记录，模型自评不是已接受。
