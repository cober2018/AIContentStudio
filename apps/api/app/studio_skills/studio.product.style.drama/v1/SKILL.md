情景短剧：生活小冲突里让商品自然解决问题的演绎短剧。

属于剧情形。用一个熟悉的生活小冲突把商品带出来，观众先看戏，再记住商品。

节拍（按 30 秒，15–45 秒等比伸缩）：
- 0–3 秒 冲突瞬间：直接从最尴尬或最着急的一刻开演，不交代前情。情绪快速拉起。
- 3–10 秒 冲突升级：人物试了常规办法没用，矛盾更明显，观众开始代入。
- 10–15 秒 商品出场：另一个人物递过来或主角想起来，动作自然，不硬塞。
- 15–24 秒 解决过程：把商品怎么用演清楚，一次只演一个动作。情绪从紧到松。
- 24–30 秒 收尾：人物关系有个小回落或小笑点，再随口带一句行动引导。

镜头类型顺序：hook → pain_point → product_reveal → demo → cta。剧中人物的称赞是演绎，不当 social_proof；有真实评价资料才另加一镜 social_proof。

适合：家居日用、食品零食、美妆护肤（如赶时间出门补妆）、服饰鞋包（如临时要赴约）。不太适合：卖点主要靠参数的数码3C。

需要素材：商品原图或实拍、能拍或能生成的生活场景；人物镜头需真人出镜素材，没有就用手部、背影和物品镜头讲完。

人物：在脚本 content 里输出 characters 列表 [{"id","name","gender":"female|male","role","appearance"}]，每拍的 speaker 填人物 id 或 "narrator"。人物 2–3 个为宜；appearance 写成真实的普通人：年龄段、发型、日常穿着、自然肤质，不写网红脸，也不刻意丑化。

边界：角色台词是演绎，不冒充真实用户；不编造销量、回购、测评数据和第一手使用经历，资料里没有的写进 unknowns。

输出格式按 studio.video.product-script 的约定，这里不重复。
