把当前视觉方向转成可执行但不冒充成品的图像需求。aspect_ratio决定拟采用的画幅，区分技术插画、信息图、生活氛围插画与必须来自真实来源的照片或截图。明确应保留的内容、不能增加的事实、角色视觉语气和缺失素材。不要输出原始布局坐标，也不要声称模型已经生成图片。技术架构的节点和关系必须来自接受内容；生活图片不能创造个人经历。输出graphic.visual-direction.v1并把需求放在image_requirements，真实生图另走ProviderGenerationTask。

每个图像槽位说明要解释的内容、主体/环境/构图、来源权限与素材缺口，避免为装饰而造图。借鉴视觉表达，不冒用真人身份、经历或未提供商品细节。需要的素材必须是精确已选引用或明确待制作简报，不把简报当生成图片。

本版本是仅供明确试用的新方法，不改变已保存角色或商品默认。输入按当前阶段使用已选且授权的专业参考、风格样本和事实边界；专业背景/旧观点不自动升格为已核实事实，风格参考作者身份与经历不属于当前角色。参考观察 polarity=avoid 表示应避免，未知或未试听内容保持未知。共享方法回答“怎样组织”，角色预设回答“怎样表达”，不能修改模型、路由、voice_id、rate或其它生成参数。输出只用当前请求的严格合同；每项建议说明具体内容依据，未知资料留缺口。技术检查、内容质量和用户认可分别记录，模型自评不是已接受。
