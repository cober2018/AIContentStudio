口播脚本评审：配音、生成画面或开拍之前先过这一关。留不留得住人，很大程度看台词像不像人话；改文字几乎不花钱，返工画面很贵，所以评审放在最前面。做法是请四个评委逐句挑毛病，每人只管一个角度，然后改写。商品口播和角色口播都适用。

四个评委各自只看一个角度，要严格，一个问题都没挑出来的评委要再看一遍：
1. 节奏：观众会不会留下。第一句停不住手指，整条就失败，其他优点救不回来。每一句都要让人想听下一句；标出回答了没人问的问题的句子、又长又绕的句子和低信息量的填充。
2. 口语：是说出来的，还是写出来的。开头像从对话中间切进来；"大家好""今天给大家介绍"直接判死。少量口头语和一处没说完的话是好的，全片一两次。"因此""综上所述"这类书面连接词、金句收尾、人生道理收尾都要改。行动引导要随口说，不能像口号。检验办法：读出来，像文案的就改成说话。
3. 新鲜：观众是不是看过。标出套路开头、用烂的梗、同类视频都会说的话；标出放在任何商品上都成立的安全说法。一个具体细节胜过三个形容词。
4. 结构：整体有没有升级、落地。铺垫 → 升级 → 落点要真的往上走，标出开头之后就平了的脚本；结尾落在说教或金句上算问题，在想法自然收住或被打断的地方结束。

改写规则：
- 保留意思、卖点和每一条事实，只改说法。不新增功效和价格主张。
- 每句改写后长度变化不超过两成，因为配音时长通常已和镜头对齐。
- 粗糙胜过精致：像文案的就改成说话。
- 同一批多条脚本，变换说话人、场景和句式，重复是最大的破绽。
- 开头留不住人、某个说法商品资料撑不住，在生成前就直接指出。

口语评委的参照只能是真实创作者的口播逐字稿，不能是获奖广告文案；用精致文案校准，会把每条脚本都"改进"成广告。

返回：每位评委的判定（通过 / 不通过）和逐句问题，然后是改写后的逐句脚本与修改说明。改写后再评一轮，四位都通过才算定稿。
