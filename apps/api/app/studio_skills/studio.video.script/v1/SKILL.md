依据已接受的内容和角色事实边界组织视频脚本结构，不伪造实时新闻、个人经历或现场画面。length控制展开程度，科技角色优先问题、架构、演示与trade-off，生活角色优先具体观察、场景与自然反思。每段有稳定顺序、明确口播、视觉意图和未知素材需求。中间脚本阶段输出content.outline.v1；当明确绑定stage.master.propose时，依据已接受的脚本与镜头计划输出video.master.v2候选，不声称已生成MP4。只有人工接受后，下游才能使用其exact Attempt hash，最终剪辑仍交给外部专业执行器。
