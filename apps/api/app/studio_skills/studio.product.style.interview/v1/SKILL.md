街头采访：演绎式街头随机提问，路人回答后引出商品。

属于剧情形。用"随机问路人"的形式开场，问题贴着买家的真实顾虑，回答把话题引到商品上。所有路人都是演员，台词是演绎。

节拍（按 30 秒，15–45 秒等比伸缩）：
- 0–3 秒 抛问题：采访者对着镜头问一个让人想回答的问题。
- 3–12 秒 两三个路人回答：答案有差异、有生活感，最后一个说出痛点。
- 12–16 秒 揭晓商品：采访者拿出商品，或请路人现场试。
- 16–25 秒 试用和反应：演清楚怎么用，反应收着，不夸张。
- 25–30 秒 收尾：采访者总结一句，随口给行动引导。

镜头类型顺序：hook → pain_point → product_reveal → demo → cta。路人反应不当真实口碑，不写"十个人里有八个说好"一类统计；有真实评价资料才加 social_proof。

适合：食品零食（试吃反应）、服饰鞋包（路人点评搭配）、美妆护肤（使用习惯类问题）。不太适合：要讲参数的数码3C、需要长时间才看得出变化的商品。

需要素材：采访者与路人出镜素材（需真人拍摄，或只拍手部、背影和麦克风）；商品原图或实拍。

额外边界：不把演绎包装成真实街访，不加"真实路人""未经剪辑"一类说法。

人物：在脚本 content 里输出 characters 列表 [{"id","name","gender":"female|male","role","appearance"}]，每拍的 speaker 填人物 id 或 "narrator"。人物 2–3 个为宜；appearance 写成真实的普通人：年龄段、发型、日常穿着、自然肤质，不写网红脸，也不刻意丑化。

边界：角色台词是演绎，不冒充真实用户；不编造销量、回购、测评数据和第一手使用经历，资料里没有的写进 unknowns。

输出格式按 studio.video.product-script 的约定，这里不重复。
