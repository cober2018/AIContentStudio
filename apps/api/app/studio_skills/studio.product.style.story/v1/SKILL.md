剧情故事：有起承转合的完整小故事，商品在转折处起作用。

属于剧情形。比情景短剧更完整，讲一个人的一段小经历，有起承转合，情绪是主线，商品在转折处起作用。适合 30–45 秒。

节拍（按 40 秒，15–45 秒等比伸缩）：
- 0–4 秒 起：一个有画面感的瞬间交代人物和处境，让人好奇后面。
- 4–15 秒 承：人物遇到一个具体的困难或心结，慢慢加重。
- 15–20 秒 转：商品进入故事，可以是别人送的、自己发现的，转折要自然。
- 20–32 秒 用起来：通过商品，人物的处境一点点变好，不夸张。
- 32–40 秒 合：情绪落地，留一点余味，最后随口提一句商品和下一步。

镜头类型顺序：hook → pain_point → product_reveal → demo → cta。旁白可以贯穿全片（speaker 用 narrator）。

适合：家居日用（搬家、独居）、食品零食（家乡味、团聚）、服饰鞋包（重要场合）、作为礼物的数码3C。不太适合：主要卖点是功效或参数、需要快速信息密度的商品。

需要素材：多个连贯的生活场景，人物前后一致；商品原图或实拍。故事是虚构的，不写成"真实经历"。

人物：在脚本 content 里输出 characters 列表 [{"id","name","gender":"female|male","role","appearance"}]，每拍的 speaker 填人物 id 或 "narrator"。人物 2–3 个为宜；appearance 写成真实的普通人：年龄段、发型、日常穿着、自然肤质，不写网红脸，也不刻意丑化。

边界：角色台词是演绎，不冒充真实用户；不编造销量、回购、测评数据和第一手使用经历，资料里没有的写进 unknowns。

输出格式按 studio.video.product-script 的约定，这里不重复。
