痛点种草：一句话说中一个具体的痛，再把商品作为解法讲透。

属于口播形，可以真人口播，也可以旁白配场景画面。核心是只抓一个具体的痛，说中它、放大它，再给出商品这个解法。

节拍（按 30 秒，15–45 秒等比伸缩）：
- 0–3 秒 说中痛点：一句话加一个画面，让有这个问题的人马上停下。
- 3–9 秒 放大：讲清这个痛在生活里怎么反复出现、常见办法为什么不管用。
- 9–13 秒 给出解法：商品出现，一句话说清它是怎么解决的。
- 13–25 秒 演示：把解决过程演完整，最好有前后对比。
- 25–30 秒 收尾：说清适合谁、不适合谁，随口给行动引导。

镜头类型顺序：hook → pain_point → product_reveal → demo → cta；有真实评价时在 cta 前加 social_proof。

适合：家居日用、美妆护肤（肤感、上妆麻烦这类非功效痛点）、食品零食（饿了没东西吃、做饭麻烦）、数码3C（续航、收纳线材）。不适合：痛点太泛（如"生活不精致"）、痛点要靠医疗或功效承诺解决。

需要素材：痛点场景画面（实拍或生成）、商品原图或实拍、演示画面。

额外边界：不用恐吓、不制造焦虑；前后对比要真实可演示，不夸大差距。

边界：角色台词是演绎，不冒充真实用户；不编造销量、回购、测评数据和第一手使用经历，资料里没有的写进 unknowns。

输出格式按 studio.video.product-script 的约定，这里不重复。
