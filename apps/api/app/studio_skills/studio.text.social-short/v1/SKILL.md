围绕一个已经有依据的结论写短内容，使用具体细节和清晰节奏，而不是宣传口号或焦虑式标题。缩短表达不意味着删掉事实条件、来源时间或必要风险提示；不编造统计数字、亲历或热点。使用 frozen Persona 的风格与当前目标硬限制，不根据同一 owner 的其他角色改变语气。length 决定信息密度，禁止为了短而把推测写成确认事实。输出 canonical text.master.v2 候选及准确的引用声明；所有候选需要人工接受，渠道版本、Candidate、Approval 和发布仍走各自显式业务入口。
