# 免费素材来源

## 平台已接入（start_material_match 会搜）

| 来源 | 擅长 | 许可 | 注意 |
|---|---|---|---|
| Pexels | 生活方式、人物、城市、自然的高清视频和图片，竖拍较多 | Pexels 许可，可商用、不强制署名 | 不能把画面里可识别的人或品牌当作代言 |
| Pixabay | 视频、图片、插画，题材广 | Pixabay 内容许可，可商用 | 同上；部分素材画质参差，挑时看原片 |
| Openverse | 聚合多个开放库的图片 | 多为 CC 各版本，每条不同 | 逐条看许可：CC0 / BY 可用，NC / ND 交人确认 |
| Wikimedia Commons | 地点、历史、科普、实物的图片和少量视频 | CC0、CC BY、CC BY-SA 等 | BY 必须署名；BY-SA 改编后要同样共享，交人确认 |
| NASA Images | 太空、地球、航天器、科学影像 | NASA 媒体使用准则，一般可用 | 不能暗示 NASA 背书；标志和人员肖像另有限制 |
| Internet Archive | 老影片、历史资料、公有领域影像 | 多为公有领域，也有其他许可 | 逐条确认许可；老片画质低，适合做年代感 |

## 还没接入（以后另提需求）

| 来源 | 擅长 | 许可 |
|---|---|---|
| Coverr | 竖屏和横屏的短视频空镜，生活、科技、办公 | 免费可商用 |
| Freesound | 音效（环境声、动作声、界面声） | 每条不同：CC0 / CC BY / CC BY-NC |
| Jamendo | 独立音乐，适合配乐 | 多为 CC，商用通常要另购许可 |

在这些来源接入前，需要它们的素材时只写进素材请求，说明来源和用途，不自行下载。
