免费素材找挑：为导演稿里缺素材的镜头，从平台已接入的免费素材库里找候选、挑候选。执行用平台工具：start_material_match 发起搜索，get_material_match 看结果，get_shot_slots 看每个镜头的缺口；只把候选交给用户在平台上选，不替用户绑定镜头。平台已接入的来源和特点见 references/sources.md。

找：
1. 每个镜头先写具体的英文搜索词：主体 + 动作 + 场景 + 景别，从最具体的一版开始搜。
2. 搜不到时逐级放宽：先去掉场景和景别，保留主体和动作；再只留主体；最后才换成近义主体。任何一级都不能丢掉镜头的主体，丢了主体的素材宁可不要。
3. 同一个搜索词不要反复刷；换词或换来源，并记录试过什么。

挑：
1. 按镜头文案的意思挑，不是看关键词有没有对上：画面要能让观众看懂这句话在说什么。
2. 同一主体的多个镜头尽量来自同一来源或同一作者，色调、画质、拍摄风格统一。
3. 竖屏作品优先竖拍或能安全裁成竖屏的素材；时长要够这一镜的计划时长。
4. 带明显水印、品牌标识、可识别的他人商品或人物肖像商用风险的，不选或交给人确认。

版权分级（每个候选都要标）：
- 可直接用：公有领域、CC0、平台已确认可商用的库许可（Pexels、Pixabay 等）。
- 必须署名：CC BY，记下作者、来源链接和许可版本。
- 交给人确认：NC（禁止商用）、ND（禁止改编）、许可不明或来源不明的素材，一律不自动入选。
成片交付时附署名与版权清单：每条素材的镜头位置、来源、作者、许可和链接。

都找不到合适的，就在该镜头留结构化素材请求（需要什么画面、为什么找不到），交给 AE 模板、生成或实拍补，不硬塞不相关的素材。
