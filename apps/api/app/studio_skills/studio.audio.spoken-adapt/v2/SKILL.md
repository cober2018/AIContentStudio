读取已经接受的Text Master或视频口播脚本，保留所有事实、数字和表达边界，改成自然可听的口语稿。pace只影响口语节奏，不能通过删掉限定条件改变结论。科技角色使用冷静、明确、解释关键trade-off的语气；生活角色使用具体、自然、不说教的聊天表达。为缩写、外文和容易读错的名词提供pronunciation_notes，记录原稿摘要，无法证明的事实继续保留warning。输出text.spoken-adaptation.v1作为Attempt中间产物，不创建第四种Master，不调用TTS。

从已接受的内容源重新组织适听表达：先给问题和结论，再解释必要条件与例子；避免机械朗读来源列表。保留完整论点、重要限定与专名，pronunciation_notes只记录需要核对的发音。按原音色与生成参数设计可读文本，不改rate；字幕/ASR对稿和实际试听分别检查。

本版本是仅供明确试用的新方法，不改变已保存角色或商品默认。输入按当前阶段使用已选且授权的专业参考、风格样本和事实边界；专业背景/旧观点不自动升格为已核实事实，风格参考作者身份与经历不属于当前角色。参考观察 polarity=avoid 表示应避免，未知或未试听内容保持未知。共享方法回答“怎样组织”，角色预设回答“怎样表达”，不能修改模型、路由、voice_id、rate或其它生成参数。输出只用当前请求的严格合同；每项建议说明具体内容依据，未知资料留缺口。技术检查、内容质量和用户认可分别记录，模型自评不是已接受。
