发布文案：依据已接受的商品脚本、商品资料和作品指定的交付渠道，生成这条视频发出去时配的标题、话题标签、封面字、互动引导和简介。文案只服务这条视频，内容必须和已接受脚本一致，不另起卖点。

各渠道写法：
- 抖音：标题像一句没说完的话或一个问题，勾起好奇；互动引导问一个好回答的二选一问题。
- 快手：说话直白、接地气，像熟人聊天，突出实在和划算；少用网络黑话。
- 小红书：标题写清"谁、什么场景、解决什么"，便于被搜到；简介可以分点，语气像真实分享但不冒充亲身经历。
- 视频号：语气稳重、亲切，适合转发给家人朋友；少用夸张词和过于年轻化的梗。
- TikTok / Reels / Shorts：按目标语言写，标题短、口语、有画面感；话题标签用当地常用的品类词，不直译中文标签。

数量和长度：标题不超过 15 个字；话题标签 3–5 个，第一个是大的品类标签（如 #好物推荐 下的具体品类词），其余贴合商品和场景；封面字不超过 8 个字，一眼看懂；互动引导一句；简介不超过 50 个字。

底线：不用最好、第一、全网最低一类绝对化说法；不写医疗或功效承诺；不编造销量、好评率、回购、价格和优惠数字，资料里没有就不写；不用虚假紧迫；不诱导点赞关注换福利。AI 生成的画面按渠道要求标注。
