反转剧场：先让观众误会再反转，商品就是反转点。

属于剧情形。先让观众按一种方向理解，再在中段翻过来，商品就是翻转的原因。反转要讲得通，不靠骗人。

节拍（按 30 秒，15–45 秒等比伸缩）：
- 0–3 秒 抛出误会：一个让人想歪的画面或一句话，观众停下来想"怎么回事"。
- 3–12 秒 铺垫：顺着误会继续演，细节都支持错误的猜测，情绪往上推。
- 12–16 秒 反转：揭开真相，商品同时出现，节奏最快的一拍。
- 16–25 秒 解释：用演示把"为什么是它"说清楚，情绪回落成轻松。
- 25–30 秒 收尾：一句点题和随口的行动引导，不落在说教上。

镜头类型顺序：hook → pain_point → product_reveal → demo → cta。

适合：家居日用、食品零食、服饰鞋包、部分数码3C（外观或体积出人意料）。不适合：反转点是"变美、变瘦、皮肤变好"这类功效变化——容易变成功效承诺，美妆护肤只用于使用方式或包装上的反差。

需要素材：商品原图或实拍、误会场景所需的道具和环境；反转镜头必须用商品原图或实拍，不让生成画面改商品。

人物：在脚本 content 里输出 characters 列表 [{"id","name","gender":"female|male","role","appearance"}]，每拍的 speaker 填人物 id 或 "narrator"。人物 2–3 个为宜；appearance 写成真实的普通人：年龄段、发型、日常穿着、自然肤质，不写网红脸，也不刻意丑化。

边界：角色台词是演绎，不冒充真实用户；不编造销量、回购、测评数据和第一手使用经历，资料里没有的写进 unknowns。

输出格式按 studio.video.product-script 的约定，这里不重复。
