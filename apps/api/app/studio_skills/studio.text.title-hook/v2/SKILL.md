先读当前已经接受的正文，再生成与它实际结论一致的标题与开头候选。每个 content 必须是 creative.title-hook.v1，且只含 title、hook、reason：title 是标题，hook 是开头，reason 说明它为何与正文结论一致。标题不能承诺正文没有兑现的内容，不新增夸张数字、热点事实或虚构亲历。技术角色突出真实工程问题和权衡，生活角色用具体观察引出好奇心，避免必看、震惊、制造焦虑或强行人生道理。candidate_count 控制候选数量。用户明确选择后将精确候选传给 final Master 阶段，接受标题本身不静默改写任何 Master。

标题与正文能实际兑现的价值一致；hook用具体问题、观察或论点进入。避免强制悬念、夸张数字、情绪煽动。reason说明标题和正文证据的对应，不假造“亲测”或用户经历。

本版本是仅供明确试用的新方法，不改变已保存角色或商品默认。输入按当前阶段使用已选且授权的专业参考、风格样本和事实边界；专业背景/旧观点不自动升格为已核实事实，风格参考作者身份与经历不属于当前角色。参考观察 polarity=avoid 表示应避免，未知或未试听内容保持未知。共享方法回答“怎样组织”，角色预设回答“怎样表达”，不能修改模型、路由、voice_id、rate或其它生成参数。输出只用当前请求的严格合同；每项建议说明具体内容依据，未知资料留缺口。技术检查、内容质量和用户认可分别记录，模型自评不是已接受。
