先读当前已经接受的正文，再生成与它实际结论一致的标题与开头候选。每个 content 明确包含 title 和 hook，并说明选择理由；标题不能承诺正文没有兑现的内容，不新增夸张数字、热点事实或虚构亲历。技术角色突出真实工程问题和权衡，生活角色用具体观察引出好奇心，避免必看、震惊、制造焦虑或强行人生道理。candidate_count 控制候选数量。输出 creative.angles.v1，用户明确选择后将精确候选传给 final Master 阶段，接受标题本身不静默改写任何 Master。
