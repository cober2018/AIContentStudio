# 品类镜头组合候选

每个组合是"开头 → 痛点 → 商品亮相 → 演示 → 信任 → 行动"的镜头骨架，时长为参考。只作候选：按实际素材删减或换序。"信任"一格只用真实资料（真实评价、真实数据、真实检测），没有就删掉这一格，用演示细节补足。

## 美妆护肤
| 组合 | 镜头骨架 |
|---|---|
| 素颜到妆后 | 近脸特写（3s）→ 肤况问题慢拉远（4s）→ 商品居中展示（3s）→ 手部上妆过程配分屏对比（8s）→ 真实前后对比（3s）→ 完妆特写叠商品（4s） |
| 成分讲解 | 成分表特写 → 肤质问题近景 → 商品全景配成分图示 → 质地与涂抹过程 → 前后对比 → 商品配价格卡 |
| 即时变化 | 使用瞬间近景 → 变化过程 → 商品亮相 → 多次使用演示 → 行动 |

## 服饰鞋包
| 组合 | 镜头骨架 |
|---|---|
| 穿搭变化 | 穿好后的全身镜头先放（倒叙）→ 衣柜犯难 → 平铺或衣架展示配面料特写 → 上身正、侧、背面加细节 → 全身配商品信息 |
| 一件多穿 | 多套穿搭快切 → 衣服只穿一次的问题 → 单品平铺与面料触感 → 三四种搭配依次展示 → 四宫格收尾 |
| 身材问题 | 同角度穿前穿后 → 试穿不合适 → 设计细节标注 → 上身效果（显高、修饰）→ 行动 |

## 食品饮料
| 组合 | 镜头骨架 |
|---|---|
| 试吃 | 掰开或咬开的瞬间特写 → 找零食、零食柜空 → 拆箱或商品阵列俯拍 → 拆袋近看、入口咀嚼特写（配咀嚼声）→ 商品堆叠配价格 |
| 简单做法 | 成品热气特写 → 外卖堆积或厨房狼藉 → 包装正面 → 倒入、翻炒、出锅、装盘快剪 → 成品配商品 |
| 分享场景 | 大家分着吃的场面 → 下午犯困 → 打开分享装 → 分发与试吃反应 → 行动 |

## 家居日用
| 组合 | 镜头骨架 |
|---|---|
| 问题解决 | 脏乱问题特写 → 传统方法失败 → 商品从画外滑入居中 → 使用过程配对比分屏 → 前后对比配商品 |
| 开箱布置 | 包装开箱瞬间 → 旧物或单调空间 → 全角度与细节微距 → 放入真实空间的氛围画面 → 全景配商品 |
| 省时省力 | 家务堆积 → 传统做法的辛苦 → 商品登场 → 使用过程配计时 → 行动 |

## 数码电器
| 组合 | 镜头骨架 |
|---|---|
| 开箱首测 | 最亮眼功能的瞬间 → 旧设备的不便 → 开箱、配件、各角度 → 核心功能逐一演示加屏幕录制 → 商品配购买信息 |
| 效率场景 | 使用前后效率分屏 → 工作学习中的卡点 → 桌面全景中亮相 → 真实使用演示 → 桌面全景收尾 |
| 耐用测试 | 测试最精彩的瞬间 → 日常损坏场景 → 正面展示配卖点标注 → 测试全过程 → 结果汇总 |

"耐用测试"只用真实测试素材；生成画面不能冒充跌落、防水、承重测试。
