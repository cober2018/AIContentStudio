# AI 视频拍不好的动作

规划生成镜头前逐条对照。命中时按右边的办法改写；改写后还不行，就改用实拍、录屏或后期包装（AE 模板）来完成，并在 visual 里写明。

| 拍不好的动作 | 为什么不行 | 怎么改 |
|---|---|---|
| 手指在手机或屏幕上精细点按，屏幕上的文字、界面跟着变化 | 手指会变形，界面和文字会乱码、跳变 | 拍手拿设备的大动作，屏幕内容用真实录屏在后期贴进去 |
| 画面里能读的文字在变化（价格变动、计时器、包装上的字翻转） | 生成的文字几乎都会糊或变成乱码 | 画面里不放要读的字，文字和数字统一用后期字幕或 AE 卡片 |
| 液体精确倒进小口径容器（瓶口、杯中小口、滴管） | 液体流向、液面和容器口很难对上，常常穿模或溢出得不自然 | 改成倒进大碗或大杯，或只拍液体流动的特写，不拍对准瓶口 |
| 多人互动且手有接触（握手、递东西、帮忙整理衣领） | 两人的手容易融在一起、多出手指，人物脸会走样 | 一镜只放一个人，递东西拆成"伸手递出"和"接住"两镜 |
| 商品被拆开、组装、折叠等复杂结构变化 | 商品结构会凭空变形，零件出现或消失 | 用实拍；生成镜头只拍组装前和组装后两个静止状态，中间用转场 |
| 精细的手部操作（系鞋带、扣小扣子、拧小螺丝、涂指甲） | 手指数量和关节容易出错，小物件会跟着手变形 | 拍完成后的结果，或拉远到看不清手指细节的景别 |
| 快速旋转或抛接商品 | 商品会在运动中变形、logo 和文字走样 | 改成慢速转台或镜头慢慢环绕静止的商品 |
| 人物开口说话、对口型 | 口型和配音对不上，脸部容易崩 | 生成镜头不说话，配音用旁白；需要说话的口播用真人实拍 |
| 前后对比要求同一张脸、同一处皮肤的真实变化 | 生成的变化不是真实效果，会被当成功效承诺 | 只用真实拍摄的前后对比；没有就不做这一镜 |
| 商品数量、颜色在一个镜头里精确保持（一排排列的多件商品） | 数量会增减，颜色会互相串 | 一镜只放一件商品，多件用后期拼接成宫格 |
