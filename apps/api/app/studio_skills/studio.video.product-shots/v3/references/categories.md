# 五个品类的镜头结构

每个结构写成镜头类型顺序（hook 开头 / pain_point 痛点 / product_reveal 商品亮相 / demo 演示 / social_proof 信任 / cta 行动），后面写每一镜拍什么。只作候选，按实际素材删减或换序。social_proof 只用真实资料（真实评价、真实检测、真实数据），没有就删掉这一镜，用多一镜演示细节补上。product_reveal 和 cta 用商品原图或实拍。

## 美妆护肤

| 结构 | 镜头类型顺序 | 每镜拍什么 |
|---|---|---|
| 质地先行 | hook → product_reveal → demo → demo → cta | 膏体或液体被挤出、挑起的微距 → 商品立在台面上 → 手背上推开看延展 → 上脸后的近景肤感 → 商品配名称收尾 |
| 场景救急 | hook → pain_point → product_reveal → demo → cta | 出门前照镜子发现问题的一瞬 → 时间紧、常规办法来不及 → 从包里拿出商品 → 几步完成的上妆过程 → 出门背影叠商品 |
| 成分讲清 | pain_point → product_reveal → demo → social_proof → cta | 换季时手摸脸颊的近景 → 商品正面和成分表特写 → 成分作用用简单图示配质地画面 → 真实检测或备案资料 → 商品配规格 |
| 妆前妆后 | hook → demo → product_reveal → demo → cta | 完成妆面的近脸 → 回到素颜开始一步步上妆 → 中途商品入镜 → 关键一步的细节 → 完整妆面叠商品 |

## 食品零食

| 结构 | 镜头类型顺序 | 每镜拍什么 |
|---|---|---|
| 一口入魂 | hook → product_reveal → demo → cta | 咬下或掰开的慢镜特写配声音 → 整包俯拍 → 拆袋、倒出、入口和咀嚼反应 → 多包摆放配名称 |
| 加班救星 | pain_point → hook → product_reveal → demo → cta | 深夜工位饿着肚子的侧影 → 撕开包装的声音 → 商品在键盘旁边 → 吃的过程和表情放松 → 抽屉里摆好的商品 |
| 快手做法 | hook → pain_point → product_reveal → demo → cta | 成品热气腾腾的近景 → 外卖盒堆着或厨房很乱 → 包装正面 → 下锅、搅拌、出锅、装盘的快剪 → 成品旁边放着包装 |
| 分享时刻 | hook → product_reveal → demo → social_proof → cta | 几只手同时伸向桌上的零食 → 分享装打开 → 分给朋友、各自试吃的反应 → 真实评价截图（有才放）→ 商品配规格 |

## 家居日用

| 结构 | 镜头类型顺序 | 每镜拍什么 |
|---|---|---|
| 乱到整齐 | hook → pain_point → product_reveal → demo → cta | 整理后的空间先放 → 回到原来乱成一团 → 商品摆正亮相 → 一件件收进去的过程 → 整齐空间全景叠商品 |
| 一擦见效 | hook → product_reveal → demo → social_proof → cta | 污渍表面的微距 → 商品拿在手里 → 擦拭或使用的一次完整动作和前后对比 → 真实测试资料（有才放）→ 商品配规格 |
| 小空间改造 | pain_point → product_reveal → demo → demo → cta | 狭小角落、东西没处放 → 商品全貌和尺寸参照 → 安装或摆放过程 → 放好后使用的样子 → 空间新样子配商品 |
| 解压声音 | hook → product_reveal → demo → cta | 商品使用时有标志性声音的特写 → 商品干净亮相 → 连续几次使用的节奏剪辑 → 商品定格 |

## 服饰鞋包

| 结构 | 镜头类型顺序 | 每镜拍什么 |
|---|---|---|
| 换装反差 | hook → pain_point → product_reveal → demo → cta | 一个转身换好装的瞬间 → 穿旧衣服在镜子前不满意 → 衣架或平铺展示 → 上身正、侧、背面和走动 → 全身定格配商品 |
| 一件多搭 | hook → product_reveal → demo → demo → cta | 几套搭配快切 → 单品平铺 → 面料手感和细节特写 → 通勤、周末、约会三种搭法 → 多宫格收尾 |
| 细节说话 | product_reveal → demo → demo → social_proof → cta | 商品整体亮相 → 走线、五金、内衬的微距 → 上身或上脚走几步 → 真实评价（有才放）→ 商品配尺码信息 |
| 场合出发 | pain_point → hook → product_reveal → demo → cta | 临出门不知道穿什么 → 打开衣柜一眼看到它 → 商品近景 → 穿上出门、在场合里的样子 → 背影叠商品 |

## 数码3C

| 结构 | 镜头类型顺序 | 每镜拍什么 |
|---|---|---|
| 开箱上手 | hook → product_reveal → demo → demo → cta | 打开包装盖子的一瞬 → 本体各角度和配件 → 第一次开机或连接 → 核心功能演示（屏幕内容用录屏后期合成）→ 商品配购买信息 |
| 痛点替换 | pain_point → product_reveal → demo → social_proof → cta | 旧设备没电、线乱、卡顿的场景 → 新商品放在桌上 → 同样场景下用新商品顺畅完成 → 真实参数或测试资料 → 桌面全景收尾 |
| 参数说话 | hook → product_reveal → demo → cta | 一个关键参数用大字卡开场（只用官方数据）→ 商品亮相 → 参数在真实使用里的表现 → 商品配规格卡 |
| 随身场景 | hook → product_reveal → demo → demo → cta | 通勤路上拿出设备的手部特写 → 商品近景 → 地铁、办公桌、出差三个场景使用 → 收进包里 → 商品定格 |
| 细节做工 | product_reveal → demo → demo → cta | 商品慢速环绕 → 接口、按键、材质微距 → 手握或佩戴的尺寸感 → 商品配购买信息 |

跌落、防水、续航、承重等测试只用真实测试素材，生成画面不能冒充。
