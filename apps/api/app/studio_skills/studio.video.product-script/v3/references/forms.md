# 带货脚本形态

先选一种形态再写。每种给出骨架、情绪走向和什么时候别用。人物台词是演绎，旁白和字幕不得声称是真实用户的话。

## 剧情类

| 形态 | 骨架 | 情绪走向 | 适合 / 不适合 |
|---|---|---|---|
| 剧情故事 | 小事铺垫 → 冲突或尴尬 → 商品作为解决的道具出现 → 结局回落 → 顺势介绍 | 好奇 → 紧张 → 转折 → 满足 → 想要 | 适合能在日常场景里"救场"的商品；故事 15–25 秒内讲完，商品登场单独给特写 |
| 情景短剧 | 两个角色开场就起冲突 → 第二回合更狠 → 被压的一方拿出商品反击 → 局势翻转 → 一句旁白收尾 | 冲突 → 升级 → 意外 → 爽 → 种草 | 只放两个人，关系自带张力（朋友、夫妻、同事）；对白用正反打，关键两句各占一镜；不适合没有可演示卖点的商品 |
| 反转剧场 | 先立一个观众会信的说法 → 再加固 → 被商品打脸 → 说出打脸的具体细节 → 自嘲式收尾 | 认同 → 更认同 → 意外 → 恍然 | 反转原因必须就是核心卖点；揭晓前一镜可只给反应，下一镜立刻揭示，不用黑屏卖关子 |
| 街头采访 | 抛一个有好奇缺口的问题 → 受访者先怀疑 → 上手试 → 反应变化 → 主持人一句收尾 | 好奇 → 怀疑 → 试用 → 信服 | 受访者说话要像路人，有犹豫、不完美；这是演绎形式，不写成真实采访记录 |

## 物品类

| 形态 | 骨架 | 情绪走向 | 适合 / 不适合 |
|---|---|---|---|
| 开箱测评 | 开箱动作带悬念 → 第一印象 → 上手做可见的测试（撕、拉、泡水、称重） → 主动说一个无关紧要的小缺点 → 结论写清谁适合、谁不用买 | 好奇 → 挑剔 → 被说服 → 信任 | 第一人称、手部和商品特写为主，可不露脸；没有真实上手素材就不写"实测" |
| 物品拟人 | 商品用第一人称自我介绍 → 吐槽自己被频繁使用 → 亮出本事 → 傲娇式收尾 | 反差萌 → 共鸣 → 被圈粉 | 画面全是商品被拿起、被使用的特写，不出现真人脸；适合日用高频品 |
| 对比测评 | 提出要解决的问题 → 按公平的维度并排比较 → 用画面说话 → 说清为什么选它 | 好奇 → 信任 → 确认 | 只用真实比较资料；不点名、不贬低竞品；AI 生成的对比测评在部分渠道被禁止，交付前提醒合规检查 |

## 口播类

| 形态 | 骨架 | 情绪走向 | 适合 / 不适合 |
|---|---|---|---|
| 达人口播 | 先抛结论 → 三条具体理由快节奏叠（数字、对比、场景）→ 拍板 → 引导 | 被结论吸住 → 想知道理由 → 被说服 | 2–4 秒一镜，半身对镜头穿插商品特写；拍板前必须已有三条以上有依据的理由；身份背景只写真实的 |
| 痛点种草 | 具体的痛点场景 → 商品在最痛时登场 → 前后对比 → 自然收尾 | 焦虑 → 共鸣 → 期待 → 心动 | 痛点要具体到画面，不写抽象问题；没有真实活动就不写限时限量 |

## 场景类

| 形态 | 骨架 | 情绪走向 | 适合 / 不适合 |
|---|---|---|---|
| 场景安利 | 具体生活场景切入 → 商品自然出现被使用 → 融入生活的好瞬间 → 像分享好东西一样推荐 | 日常 → 代入 → 向往 → 想要同款 | 适合颜值、氛围型商品；口吻是"忍不住分享"，不是"你必须买" |

## 选择提示

- 素材以商品实拍为主、没有人物：开箱测评、物品拟人、场景安利。
- 有真人出镜素材：达人口播、痛点种草、街头采访。
- 需要两个以上演员或大量情境画面：剧情故事、情景短剧、反转剧场；先确认素材或生成能力够用。
