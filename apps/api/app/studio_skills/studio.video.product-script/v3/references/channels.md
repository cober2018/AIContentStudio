# 渠道差异

只读作品交付渠道对应的一节。各渠道共同的底线：不用绝对化用语，AI 生成内容按渠道要求标识，不写没有依据的功效。

## 抖音
- 完播最重要：前 3 秒必须有开头机制；大约每 5 秒给一个新信息或转折，防止划走；结尾不放"谢谢观看"之类的收尾信号。
- 语速偏快，约每秒 3.5–4 个字。
- 口播里可自然放一两句互动引导（问看法、提醒收藏），不堆砌。
- 有真实的原价和活动价时先说原价再说活动价；最后几秒给清楚的购买入口说法。

## 快手
- 偏接地气，开头从日常场景切入，有聊天感。
- 语速比抖音稍慢，约每秒 3–3.5 个字；时长 20–40 秒较合适。
- 称呼和互动更亲近、直接；性价比讲透是重点。
- 信任话术只用真实依据，不写没有发生过的"自用""回购"。

## 小红书
- 偏精致感和教程感，节奏可以慢，画面讲究。
- 口吻是真实分享和体验对比，少说"赶紧买"。
- 引导以收藏、提问为主；标题含品牌、品类和核心卖点关键词。

## 视频号
- 靠朋友点赞和转发进入推荐，开头要让人愿意转给朋友或家人群；转发比点赞更重要。
- 偏信任感和实用价值，避免硬广腔。
- 中老年和下沉人群占比高：语速可稍慢，卖点和实惠讲清楚。
- 可引导关注、到小店下单；字幕全程在屏。

## TikTok Shop
- 三段式：3–6 秒开头（第一帧就是商品或效果）→ 3–5 个利益点各配一个画面 → 清楚的下单引导。
- 常用四种贯穿方式：真实试用、前后对比、开箱、教程，任选其一。
- 节奏更快，每 2–3 秒一个信息点；多数人静音看，字幕全程在屏，价格优惠用画面贴片。
- 面向海外受众时口播用目标语言。

## 通用写法（没指定渠道）
按抖音的节奏写，但语速取中间值，互动引导最多一句。
