视频提示词：写有人物的镜头（口播、试吃、上手演示、剧情）时，让人有态度、有表演，而不是摆姿势。平台的图生视频提示词由 get_shot_video_prompt 拼好：board.attitude 有值就排在最前面，后面是画面、运镜、光线、强度和固定规则。你要写好的是 board.attitude、board.visual 和首帧图的提示词。

一、人物镜头：先写态度，再写一两个关键反应
1. attitude 写这个人怎么看这件事、对谁说，一句话就够：「跟闺蜜吐槽价格太贵，又好气又好笑」「第一次吃到自己能吃的零食，又惊又喜」。一个态度能同时带动表情、身体和节奏。
2. 「活泼」「有表现力」只说了能量高低，要写出他对内容的具体反应才有方向。
3. 只给最关键的一两个反应：在哪个点眉毛一挑、停一下、点头。不给每句话都配一个手势，那只会变成编舞。
4. 克制也要有理由：严肃是在掂量、在坚持还是在质疑；放松是在逗、在不屑还是在感兴趣。动作很少时也要写他对内容的反应。
5. 动作写在画面里真实存在的人和物上：看镜头、拿起包装、递给孩子。说的内容和看得见的动作分开：嘴上说「零添加」，画面里不出现「零添加」三个字，字由 AE 后期加。
6. 少用比喻，视频模型会把比喻画成真东西；数字交给口播和字幕，别让手指比数字。

二、首帧 / 人物图：四段写
1. 拍摄方式：手机实拍感用固定写法「普通手机后置摄像头直出画面，现场自然光，不调色，略有噪点，构图随意」，或选 look 里的写法；不要每次自己换说法。
2. 人物：选两三个最能定住这个人的特征（年龄、身份、气质、发型、穿着），写成真实的普通人，不磨皮不网红脸。
3. 动作与镜头：这一刻在干什么、和镜头的关系、景别。
4. 场景：两三个说明地方的细节（米色布沙发、窗边自然光、茶几上的零食盒），不用列清单。
画面里不写任何文字、字幕和水印。

三、每种输入只管一件事
1. 商品图管商品外观；人物图 / 角色形象管长相；首帧管这一镜从哪个画面开始。
2. 提示词只写这一镜的态度、动作和运镜，不重复描述包装颜色和字样（重复写反而让模型改商品）。
3. 同一个人跨镜头：用同一张人物图或九宫格分镜里的那一格作参考，保持长相、服装、房间、光线一致。
4. 人物图只来自角色形象照（或作品「共同视觉参考」里手动选的人物图），平台生成画面时自动带上。角色没有形象照时生成画面里不出现人物，只拍商品和场景，拿东西只出现手部；要人物出镜就写成实拍，或请用户先补形象照。

四、三种生成方式怎么选
1. 只用文字：画面不依赖已有的人、物、构图。
2. 首帧（和尾帧）：这一镜必须从某张图开始或停在某张图，现在平台的自动图生视频（MiniMax H3）就是这种。
3. 参考视频：要照搬参考里的动作节奏、运镜或表演时，把那一小段参考视频作为生成输入。现在的模型只支持首尾帧，这一条等换到支持参考视频的模型再用；在那之前把关键动作写进 attitude 和 visual。参考视频的原画面永远不直接进成片。

口播、孩子试吃、商品演示的完整例子见 references/examples.md。
