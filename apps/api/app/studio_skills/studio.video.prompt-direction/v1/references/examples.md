# 例子

每个例子给出：board.attitude、board.visual、首帧四段。拍摄方式统一用手机实拍固定写法。

## 1. 口播（宝妈对镜头）

- attitude：跟同样被孩子过敏折腾的妈妈说心里话，先是无奈，说到这支霜时松了口气
- visual：宝妈坐在卧室床边对镜头讲，说到「终于找到了」时拿起手边的霜看一眼再看回镜头，中近景
- 首帧：
  - 拍摄方式：普通手机后置摄像头直出画面，现场自然光，不调色，略有噪点，构图随意
  - 人物：三十出头的中国妈妈，素颜淡妆，低马尾，米白色家居服，真实皮肤纹理
  - 动作与镜头：坐在床边看着镜头准备开口，手边放着一支护肤霜，中近景，手机略低于视线
  - 场景：卧室，浅色床品，窗边白天自然光

不要写成：「她举起右手，然后左手指向产品，再微笑，再点头……」（每句一个动作）。

## 2. 孩子试吃

- attitude：第一次吃到自己能吃的零食，又惊又喜
- visual：孩子咬下第一口，愣一下，眼睛亮起来，马上伸手要第二块，中景
- 首帧：
  - 拍摄方式：普通手机后置摄像头直出画面，现场自然光，不调色，略有噪点，构图随意
  - 人物：4 岁左右的中国小男孩，短发，浅黄色卫衣，脸上自然的表情，不像童模
  - 动作与镜头：坐在沙发上，双手捧着一块饼干正要咬，中景，大人手机平拍
  - 场景：客厅墨绿色布沙发，旁边放着饼干盒，下午窗光

关键反应只写一个（咬完愣一下再眼睛亮）。包装的颜色和字样不写，商品图会管。

## 3. 商品演示（手上操作）

- attitude：抹开时有点意外，没想到这么好推开
- visual：手指挤出一点霜，在手背上一推，停半秒再轻轻推开，近景跟拍
- 首帧：
  - 拍摄方式：普通手机后置摄像头直出画面，现场自然光，不调色，略有噪点，构图随意
  - 人物：女性的手，自然指甲，不做美甲特写
  - 动作与镜头：一只手拿着打开的霜，另一只手指刚蘸上一点，近景
  - 场景：浅色木桌面，窗边自然光

九宫格和镜头生图都自动带商品主图作参考，每张画面对照主图检查，不过关只重画那一张。商品纯特写可以进九宫格，但单独用镜头生图画得更准。
