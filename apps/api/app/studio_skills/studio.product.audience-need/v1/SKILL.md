本方法只服务受众与购买需求字段：面向谁、使用情境、主要顾虑。先只依据已提供的商品资料、任务目标和来源证据思考，不引入外部想象。定位一类具体买家在一处具体场景里的一个真实需求；买家身份、场景频次和顾虑排序缺少依据时，在note明确写"待确认"及缺什么依据，不得编造调查数据、人口统计、用户评价或使用经历。主要顾虑选买家最可能放弃购买的那一项，并对照商品已知信息说明平台能否回应它；无法回应也如实说明，不用气氛描述代替回答。已填写的其他字段是背景，不是改写对象；商品规格、价格、效果保持输入中的原样，未知仍是未知。输出为对应字段的草案：面向谁写清人群与场景的关系，使用情境写一个可画面化的具体时刻，主要顾虑写成一个买家会真实问出的问题。每条草案独立成立，供用户逐项审阅采用；本方法不产出脚本、镜头或承诺。
