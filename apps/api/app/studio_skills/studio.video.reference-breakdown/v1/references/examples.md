# 例子

下面三个例子只示范拆法和改写方式，商品事实以作品 brief 为准。

## 1. 口播（宝妈真人口播，约 1 秒一镜）

参考：0–2 秒火焰背景 + 四角大字「敏宝妈妈」；之后宝妈对镜头讲，穿插涂抹演示、证书图、成分图、红叉「无香精 / 无激素」，结尾箭头指向小黄车。22 个切点，响度 −7.6 LUFS。

整体分析可以这样写：真人口播做信任，素材穿插做证据，前 2 秒靠特效抢注意。字幕关键词变色是一套贯穿的系统；证书、成分图是参考品牌的声明。

改写成导演稿：
- 第 1 镜 0–2 秒：ae_template，开场钩子卡，大字写本角色的身份（如「过敏宝宝的妈妈」），notes 写「对应参考的火焰背景开场」。
- 第 2–4 镜：shoot，宝妈对镜头讲痛点，attitude「跟同样被孩子过敏折腾的妈妈吐苦水，又急又心疼」。
- 证书镜：brand_material 记「需要品牌的检测报告 / 证书原件」；没有就删掉这一镜，不生成。
- 结尾：ae_template 下单引导。

## 2. 孩子试吃（30 秒实拍，约 3 秒一镜）

参考：全程实拍孩子在家吃 + 手拿包装；小号白色手写体字幕常驻；关键词黄底描边贴纸弹出（敏宝可吃 / 无麸质无蛋 / 非油炸 / 嘎嘎香）；手绘黄线标包装。9 段，响度 −12 LUFS。

timeline 一段的写法：
- start_ms 18600，end_ms 21000
- speech：还添加了益生元，呵护宝宝小肠胃
- picture：孩子坐沙发上吃，包装放在面前，中景，手机平拍
- overlays：左上角黄字「嘎嘎香」弹出后停住；底部白色字幕
- purpose：用孩子真实吃得香来证明好吃

改写到本作品（儿童饼干）：
- shoot：孩子第一次尝饼干，attitude「第一次吃到自己能吃的零食，又惊又喜」，景别中近景，3 秒。
- product_image：手拿包装正面特写，只用商品原图。
- 关键词贴纸写进 notes，交 AE 后期；参考的水印「出品」字样不复刻。

shot_list 一条：what=孩子坐在沙发上吃饼干，吃完伸手要第二块；who=3–5 岁孩子；framing=中景；camera=手机平拍、固定；seconds=4；notes=家里自然光，别让孩子看镜头，包装放在画面里但不挡脸。

## 3. 商品演示（手上操作）

参考：手把商品打开、挤出、抹开，近景跟拍，每个动作一镜，字幕说质地。

改写：
- 打开 / 挤出 / 抹开各一镜，source_kind 有实物就 shoot，没有就 generated（notes 写 AI 示意，首帧用商品原图作参考）。
- attitude 写手的主人对质地的感受：「抹开时惊讶它这么好推开」，只配一个关键反应（手指停一下再推开），不给每句都配动作。
- 质地、成分这类功效说法只用品牌真实资料；没有的不说。
