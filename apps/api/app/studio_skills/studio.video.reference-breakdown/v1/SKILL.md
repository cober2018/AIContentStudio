拆参考视频：用户给了一条爆款口播 / 带货视频，要用本平台复刻。目标不是照抄画面，而是弄懂它为什么抓人，再用本作品的商品、角色和说法把同样的结构和节奏做出来。

一、先拿本机拆解（平台免费做，不调用付费模型）
1. analyze_reference_video 开始拆，get_reference_video 看结果，status 为 done 再往下。
2. 结果里有：转写（带时间的每句话）、切点和每段的起止时间、每页一张拼图（每段首 / 中 / 尾三帧，下方写着原视频时间）、响度（LUFS）。拼图和 transcript.json、cuts.json 的绝对路径在 summary.files 里，打开拼图逐页看。
3. 转写可能有错字（品牌名、新词最容易错），结合画面里的字幕和商品资料理解意思，不要因为错字误判内容。

二、先整体，后细节，两头互相修正
1. 从头到尾看一遍：开头靠什么抓人，中间怎么推进（痛点 → 发现 → 证据 → 下单），结尾让观众做什么，整体想让观众产生什么感觉。
2. 再逐段看具体做法：这一段说了什么、画面是谁在干什么、景别和机位、叠了什么（字幕、关键词贴纸、箭头、手绘线、证书图、小窗），它们什么时候出现、停多久、怎么离开，对观众起什么作用（建立信任、放大关键词、给证据、引导下单）。
3. 跨镜头一直存在的东西（常驻字幕、同一种贴纸样式、背景音乐）算一套画面系统，只描述一次，再在时间线里标出它的变化。
4. 节奏写成数：切点个数、平均几秒一镜、响度多少，方便照着剪。
5. 看到的和推断的分开写：「画面里有黄底描边字『敏宝可吃』」是看到的，「用来放大卖点」是推断。

三、写两份记录，用 save_reference_breakdown 存下（字段见 references/fields.md）
1. analysis 整体分析：想表达什么、为什么抓人、有哪几套画面系统（字幕、贴纸、特效、配乐）各起什么作用、哪些关系复刻时要保留、哪些要换。
2. timeline 时间线：按段写 start_ms / end_ms（原视频时间）、speech 口播、picture 画面、overlays 叠加元素、purpose 作用。
3. shot_list 拍摄清单：本作品里必须实拍的镜头，写拍什么、谁出镜、景别、机位 / 运镜、秒数、注意事项。
4. brand_material：参考里出现的证书、医院联合研发、检测报告、成分图、销量数字，都是参考品牌自己的声明，只记成「需要品牌真实资料」，不照抄、不生成、不编。

四、改写成本作品的导演稿初稿（save_director_draft）
1. 结构和节奏照参考：段落顺序、每段时长、切镜密度、开头几秒的抓人方式。
2. 口播换成本商品 / 本角色的说法，事实只用 brief 里的商品资料和事实；参考里的卖点不能直接搬给本商品。
3. 每镜 board.source_kind 写素材从哪来：shoot 需要实拍、product_image 商品图、generated 生图 / 图生视频、ae_template AE 模板、library 素材库。人物镜头写 board.attitude（见 studio.video.prompt-direction）。
4. 参考视频本身、它的水印和原画面一律不进成片，只当理解用的证据。贴纸 / 特效类叠加先写进 board.notes，由 AE 后期做。

例子（口播、孩子试吃、商品演示）见 references/examples.md。
