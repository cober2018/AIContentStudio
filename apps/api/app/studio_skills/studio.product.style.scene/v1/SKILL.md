场景安利：把商品放进两三个真实生活场景，用氛围和用法打动人。

属于场景形。不讲大道理，把商品放进两三个熟悉的生活场景里，让观众看到"我也会这样用它"。旁白轻、画面为主。

节拍（按 30 秒，15–45 秒等比伸缩）：
- 0–3 秒 开头：最好看、最有氛围的一个画面先出来。
- 3–7 秒 商品亮相：干净地展示商品本身。
- 7–24 秒 场景串联：两到三个场景（如早上出门、办公桌、周末出游），每个场景一个清楚的用法，场景之间情绪逐步升高。
- 24–30 秒 收尾：回到商品，一句随口的行动引导。

镜头类型顺序：hook → product_reveal → demo（多个场景）→ cta；有真实评价资料时可加 social_proof。

适合：服饰鞋包（不同场合穿搭）、家居日用（空间布置）、食品零食（不同时刻吃）、数码3C 配件（随身使用）。不太适合：卖点需要参数讲解或测试证明的商品、功效类护肤。

需要素材：多个生活场景画面（实拍或生成，生成的人物只拍手部、背影或侧影，需要正脸用真人拍摄）；商品原图或实拍；场景之间光线和色调保持统一。

额外边界：场景是示意，不暗示真实用户的使用经历。

边界：角色台词是演绎，不冒充真实用户；不编造销量、回购、测评数据和第一手使用经历，资料里没有的写进 unknowns。

输出格式按 studio.video.product-script 的约定，这里不重复。
