对比测评：用真实、公平的测试把商品和常见做法或同类放在一起比。

属于物品形。把商品和常见做法或同类商品放在同样条件下比，用结果说话。前提是有真实的对比测试事实。

节拍（按 30 秒，15–45 秒等比伸缩）：
- 0–3 秒 开头：把最终对比结果最强的一帧先放出来，或抛出要比的问题。
- 3–8 秒 交代规则：比什么、怎么比、条件是否一致，一句话讲清。
- 8–12 秒 参赛者亮相：商品和对照组并排出现。
- 12–24 秒 对比过程：按维度逐项比，每项给真实结果。
- 24–30 秒 结论：说清楚赢在哪、也说清楚不适合谁，随口给行动引导。

镜头类型顺序：hook → pain_point → product_reveal → demo → social_proof（真实测试结果汇总）→ cta。

适合：数码3C、家居日用（清洁、收纳、小家电）。谨慎：美妆护肤（肤感因人而异，不比功效）、食品零食（口味主观，只比分量、规格等客观项）。

需要素材：真实对比测试的实拍或数据，对照组的真实信息。

额外边界：没有真实测试事实就说明这一点，不写本风格，建议改用场景安利或痛点种草；不点名贬低竞品，对照组可用"普通款""常见做法"；不挑对自己有利的不公平条件；部分渠道禁止 AI 生成的对比测评，选用前提醒。

边界：角色台词是演绎，不冒充真实用户；不编造销量、回购、测评数据和第一手使用经历，资料里没有的写进 unknowns。
