# 领域知识（复盘看板方法论 + 指标字典）

本目录存放量化平台官方输出的两份解读知识 + 一份入口索引（从 DreamOAgents `docs/review/` 复制）：

| 文件 | 内容 | 注入方式 |
|---|---|---|
| `方法论.md` | 看盘顺序、每张图怎么读、跨图剧本 A–N、五类成稿模板、自检清单 | 全文注入生成/荐题 prompt |
| `指标字典.md` | 逐字段口径/公式/阈值/组合用法/误读红线（情绪 39 列、生命周期 190 列、前瞻风险 26 列…） | 按本稿涉及指标裁剪注入；红线节注入 LLM Reviewer |
| `复盘看板指标定义与财经写作方法论.md` | 入口索引（人读） | 不注入 |

规则：

- 知识是**解读规则，不是事实**——不进 FactPack、不参与 FactCheck 数字校验（FactCheck 只对数字负责，语义误读由 LLM Reviewer 按红线记 warning）。
- 文件缺席时系统行为与没有知识层完全一致（优雅降级，见 `app/services/domain_knowledge.py`）。
- 替换文件即生效（mtime 缓存自动失效），无需重启。
- 来源：DreamOAgents 平台 Agent 产出，版本随平台方法论演进同步更新。
