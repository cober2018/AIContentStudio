# 声音

先读 `choose.md`。响度、音乐压低、淡出时长以 `finishing.md` 为准，这里只补手法。

### 气口太紧：微叠 + 底噪
- 思路：两句接得太近会显得急；切点处一刀断开还会有「哒」声。让两段轻微重叠，并垫一层安静的房间底噪。
- 用在：口播剪掉停顿后，两句听起来急促或有断裂感。
- 不用在：TTS 配音（没有底噪也没有断裂）。
- 做法：切点前后两段音频在停顿里重叠约 2–4 帧（约 0.1 秒）并各加极短淡入淡出；重叠和淡变只落在停顿里，不压到字上；切点离字头或字尾不到 3 帧时，淡变只用 1 帧。从同一段录音里截一段无人说话的房间声，放在下方音轨垫在切点下。接好后整条重新听写（ASR），核对每段第一个字和最后一个字都在。
- 脚本：部分。重叠与淡入淡出能按帧设置（`SetFades`）；挑底噪片段需听判断。
- 检查：切点听不出断裂；底噪连续，没有突然的真空；重新听写里每段首尾字都在。
- 常见错误：一刀断开；用别处录的底噪，音色不一致；淡变压到字上，吃掉第一个或最后一个字。
- 状态：试用
- 来源：第 2 集

### 只有一边耳朵有声音
- 思路：单声道素材放进立体声轨，可能只有左边或右边有声。
- 用在：录音素材、采访素材导入后。
- 不用在：平台 TTS 配音与已母带化的声音。
- 做法：检查片段的声道映射（`GetSourceAudioChannelMapping`）；只有一个声道有内容时，改映射让两边都取这一声道（`SetSourceAudioChannelMapping`），或在 Clip Attributes 里设为 Mono 放进立体声轨（Resolve 21 单声道会在立体声轨两侧播放）。导出后用耳机复查。
- 脚本：能。
- 检查：左右声道音量一致。
- 常见错误：不戴耳机检查，导出后才发现。
- 状态：试用
- 来源：第 2 集

### 对白逐段拉齐（必做：粗剪后、导出小样前）
- 思路：不同时间、不同地点录的实拍对白，音量和底噪各不一样；不先拉齐，整片响度达标了，单句还是忽大忽小。
- 用在：每段实拍对白（同期声、采访、口播）。
- 不用在：平台 TTS 配音与已母带化的声音（已在 −16 LUFS）；音乐、音效。
- 做法：
  - 逐段测响度（`ffmpeg -i <段落> -af ebur128 -f null -`），用片段音量把每段对白拉到约 −16 LUFS。
  - 只有明显底噪（空调、风声、电流声）时轻度降噪，宁轻勿重，人声不能发闷、发水。
  - 只有一边声道有声的按「只有一边耳朵有声音」修成两边。
  - 之后再按 `finishing.md` 混音标准（整片约 −14 LUFS、真峰值 ≤ −1 dBTP）。
- 脚本：部分。片段音量、声道映射能脚本；降噪需手动。
- 检查：戴耳机逐句听，相邻对白段听不出忽大忽小；回执写明哪些对白段调了音量、调了多少、哪些降了噪。
- 常见错误：只看整片响度；降噪开太重；对白没拉齐就去压整片。
- 状态：在用
- 来源：2026-11-02 素材统一要求

### 声音轨口播衔接
- 思路：导演稿有 dialogue 声音轨时，口播按声音轨铺、画面照镜头切；口播由几段素材拼成，接缝要听不出来。
- 用在：导演稿有 dialogue 声音轨（口播从别的素材借声音、声音比画面早进或晚出）。
- 不用在：没有声音轨的导演稿（用各镜头原声）；TTS 配音。
- 做法：
  - 每段按 `trim_start_ms`–`trim_end_ms` 截取，放到成片 `start_ms`–`end_ms`，不变速；画面轨照镜头切，两者各管各。
  - 切点放在换气或停顿处，不切在字中间；声音轨给的截取点落在字上时，在不改总长的前提下往最近的停顿挪几帧，并写进回执。
  - 每个接缝加淡入淡出（`SetFades`）防咔哒声：重叠和淡变只落在停顿里，不压到字上，一般两边各 2–4 帧；切点离字头或字尾不到 3 帧时，淡变只用 1 帧（例：一段从 7.733 秒起、字头在 7.76 秒，2 帧淡入就吃掉了「每」字）。
  - 来自不同素材的段先按「对白逐段拉齐」统一到同一响度；底噪不一致的，按「气口太紧：微叠 + 底噪」垫同一段房间声对齐。
  - 接完整条口播单独导出，重新听写（ASR），和对应台词逐句对照，逐段核对第一个字和最后一个字都在。
- 脚本：部分。截取、放置、淡入淡出能脚本；挑停顿和听感需判断。
- 检查：重新听写的文字和台词一致，每段首尾字都在，没有吞字、没有多出半个字；接缝听不出咔哒和底噪跳变；相邻段响度一致。
- 常见错误：照毫秒硬切切进字里；淡变压到字头字尾；不同素材音量、底噪不一；接完不重听写，漏掉半个字。
- 状态：试用
- 来源：2026-11-03 导演稿声音轨

### 上升音效蓄力
- 思路：一个向上爬的声音让观众预期「要来了」，画面出现时能量释放。
- 用在：开场第一个画面、段落大转折、揭示结果的瞬间。
- 不用在：配音正在说关键句时；一条片超过两三次。
- 做法：上升类音效的峰值对准画面入点帧，起点在入点前 1–2 秒；音量低于配音，峰值后马上收。音效从项目素材或通用素材库找，没有就不加。
- 脚本：能。音效起点 = 入点帧 − 音效峰值所在帧。
- 检查：峰值和画面切换同帧；不盖人声。
- 常见错误：峰值没对上画面；到处加。
- 状态：试用
- 来源：第 4 集

### 混响尾音
- 思路：音乐被截断时，加一点混响尾音让它自然消散，或者当作两段之间的声音过门。
- 用在：音乐在重拍上收尾后需要一点余韵；段落之间需要一个声音过门。
- 不用在：音乐垫在配音下面（会让人声发糊）。
- 做法：在 Fairlight 给音乐所在轨道（不是片段）加 Reverb 插件：轨道效果在片段结束后仍会继续发声，尾音自然延续，不需要做静音副本。只想要尾音时，把这条轨道单独渲染成音频文件，再截出尾音部分使用。混响湿声比例保持适中，不糊住节奏与低频。
- 脚本：部分。插件需在 Fairlight 中添加；渲染与截取能脚本。
- 检查：切点之后有余韵，没有突然静音或咔哒声；节奏不糊。
- 常见错误：把混响加在片段上，片段一结束尾音就被切掉。
- 状态：试用
- 来源：第 4 集

### 自录音效降调
- 思路：随手录的声音（敲杯子、晃钥匙）降调、放慢后会变得厚重、有质感，可以做成独有音效。
- 用在：素材库里找不到合适音效、而画面有明确的撞击或机械动作时。
- 不用在：有现成合适音效时。
- 做法：近距离、安静环境录制 → 放进音轨 → 用 `AudioPitchSemiTones` 降 3–7 个半音，或配合变速放慢 → 和画面动作点对齐。
- 脚本：能。`SetProperty("AudioPitchEnabled", True)` 与 `AudioPitchSemiTones`。
- 检查：音色变厚、没有刺耳感；和动作点对齐。
- 常见错误：直接用原始录音，声音单薄刺耳。
- 状态：试用
- 来源：第 4 集

### 收尾：重拍优先，淡出兜底
- 思路：音乐能收在重拍上就收在重拍上（见 `beat-and-speed.md`）；收不了，再按 `finishing.md` 淡出。
- 用在：每条片的音乐结尾。
- 不用在：无。
- 做法：先找最近的乐句末尾重拍；与画面结尾差距超过 1 秒时改用淡出（`SetFades` 的 FadeOut）。
- 脚本：能。
- 检查：结尾不戛然而止。
- 常见错误：一刀切断。
- 状态：试用
- 来源：第 2、4 集
