# 声音

先读 `choose.md`。响度、音乐压低、淡出时长以 `finishing.md` 为准，这里只补手法。

### 气口太紧：微叠 + 底噪
- 思路：两句接得太近会显得急；切点处一刀断开还会有「哒」声。让两段轻微重叠，并垫一层安静的房间底噪。
- 用在：口播剪掉停顿后，两句听起来急促或有断裂感。
- 不用在：TTS 配音（没有底噪也没有断裂）。
- 做法：切点前后两段音频重叠约 2–4 帧（约 0.1 秒）并各加极短淡入淡出；从同一段录音里截一段无人说话的房间声，放在下方音轨垫在切点下。
- 脚本：部分。重叠与淡入淡出能按帧设置（`SetFades`）；挑底噪片段需听判断。
- 检查：切点听不出断裂；底噪连续，没有突然的真空。
- 常见错误：一刀断开；用别处录的底噪，音色不一致。
- 状态：试用
- 来源：第 2 集

### 只有一边耳朵有声音
- 思路：单声道素材放进立体声轨，可能只有左边或右边有声。
- 用在：录音素材、采访素材导入后。
- 不用在：平台 TTS 配音与已母带化的声音。
- 做法：检查片段的声道映射（`GetSourceAudioChannelMapping`）；只有一个声道有内容时，改映射让两边都取这一声道（`SetSourceAudioChannelMapping`），或在 Clip Attributes 里设为 Mono 放进立体声轨（Resolve 21 单声道会在立体声轨两侧播放）。导出后用耳机复查。
- 脚本：能。
- 检查：左右声道音量一致。
- 常见错误：不戴耳机检查，导出后才发现。
- 状态：试用
- 来源：第 2 集

### 上升音效蓄力
- 思路：一个向上爬的声音让观众预期「要来了」，画面出现时能量释放。
- 用在：开场第一个画面、段落大转折、揭示结果的瞬间。
- 不用在：配音正在说关键句时；一条片超过两三次。
- 做法：上升类音效的峰值对准画面入点帧，起点在入点前 1–2 秒；音量低于配音，峰值后马上收。音效从项目素材或通用素材库找，没有就不加。
- 脚本：能。音效起点 = 入点帧 − 音效峰值所在帧。
- 检查：峰值和画面切换同帧；不盖人声。
- 常见错误：峰值没对上画面；到处加。
- 状态：试用
- 来源：第 4 集

### 混响尾音
- 思路：音乐被截断时，加一点混响尾音让它自然消散，或者当作两段之间的声音过门。
- 用在：音乐在重拍上收尾后需要一点余韵；段落之间需要一个声音过门。
- 不用在：音乐垫在配音下面（会让人声发糊）。
- 做法：在 Fairlight 给音乐所在轨道（不是片段）加 Reverb 插件：轨道效果在片段结束后仍会继续发声，尾音自然延续，不需要做静音副本。只想要尾音时，把这条轨道单独渲染成音频文件，再截出尾音部分使用。混响湿声比例保持适中，不糊住节奏与低频。
- 脚本：部分。插件需在 Fairlight 中添加；渲染与截取能脚本。
- 检查：切点之后有余韵，没有突然静音或咔哒声；节奏不糊。
- 常见错误：把混响加在片段上，片段一结束尾音就被切掉。
- 状态：试用
- 来源：第 4 集

### 自录音效降调
- 思路：随手录的声音（敲杯子、晃钥匙）降调、放慢后会变得厚重、有质感，可以做成独有音效。
- 用在：素材库里找不到合适音效、而画面有明确的撞击或机械动作时。
- 不用在：有现成合适音效时。
- 做法：近距离、安静环境录制 → 放进音轨 → 用 `AudioPitchSemiTones` 降 3–7 个半音，或配合变速放慢 → 和画面动作点对齐。
- 脚本：能。`SetProperty("AudioPitchEnabled", True)` 与 `AudioPitchSemiTones`。
- 检查：音色变厚、没有刺耳感；和动作点对齐。
- 常见错误：直接用原始录音，声音单薄刺耳。
- 状态：试用
- 来源：第 4 集

### 收尾：重拍优先，淡出兜底
- 思路：音乐能收在重拍上就收在重拍上（见 `beat-and-speed.md`）；收不了，再按 `finishing.md` 淡出。
- 用在：每条片的音乐结尾。
- 不用在：无。
- 做法：先找最近的乐句末尾重拍；与画面结尾差距超过 1 秒时改用淡出（`SetFades` 的 FadeOut）。
- 脚本：能。
- 检查：结尾不戛然而止。
- 常见错误：一刀切断。
- 状态：试用
- 来源：第 2、4 集
