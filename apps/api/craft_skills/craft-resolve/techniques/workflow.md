# 工作流效率

先读 `choose.md`。

### 代理与回放分辨率
- 思路：剪辑时读小文件，交付时换回原素材，画质不受影响。
- 用在：4K 及以上素材、长时间线、播放卡顿。
- 不用在：短片且播放流畅时。
- 做法：先把 Playback → Timeline Proxy Resolution 调到 Half 或 Quarter；仍卡时为素材生成代理（Resolve 21 支持后台生成）或优化媒体，交付前确认渲染使用原素材。
- 脚本：部分。项目设置 `perfProxyResolutionRatio` 等能脚本；代理也可外部生成后 `MediaPoolItem.LinkProxyMedia` 关联。
- 检查：播放流畅；交付成片仍是原素材画质。
- 常见错误：交付时仍用了代理。
- 状态：试用
- 来源：第 1 集

### 候选素材铺成一条挑
- 思路：一个个点开预览太慢；把候选素材首尾相接铺成一条，边听配音或音乐边扫。
- 用在：同一个镜头有很多候选 B-roll，需要按节拍或关键词挑选时。
- 不用在：平台素材匹配已给出明确候选时（先用平台的候选）。
- 做法：新建一条临时时间线，把候选素材全部追加进去；用 Edit 页的堆叠时间线（Stacked Timelines）与主时间线上下并排，或用 Source Tape 连续浏览；选中的片段设入出点后放回主时间线。
- 脚本：部分。临时时间线和追加能脚本；挑选需看画面。
- 检查：选中片段长度能盖住对应的话；情绪和音乐段落一致。
- 常见错误：在素材库里逐个点开。
- 状态：试用
- 来源：第 2、3 集

### 拆参考片读节奏
- 思路：想学一条好片子的节奏，先把它按镜头拆开，看每段多长、给了多少信息。
- 用在：用户给了参考成片；复盘自己的成片节奏。
- 不用在：参考片版权不明时，只做分析，不进入交付时间线。
- 做法：参考片单独建一条时间线 → `Timeline.DetectSceneCuts()` 按画面变化切开 → 读出每段时长，配合 `structure.md` 的时钟检查记录节点。
- 脚本：能。
- 检查：切出的段数和实际换镜一致，没有碎段或漏段。
- 常见错误：凭感觉估镜头长度。
- 状态：试用
- 来源：第 10、14 集

### 重效果先出中间件
- 思路：跟踪、抠像、复杂合成算好之后先渲染成一段视频，后面在它上面包装，工程轻、也不会误碰。
- 用在：跟踪贴字、抠像合成完成后还要继续叠包装；工程明显变卡。
- 不用在：效果之后还需要频繁修改的阶段。
- 做法：与 `native-execution.md` 的 AE 中间件规则一致：效果段单独渲染成高质量中间件（ProRes 422 HQ 或同级），放回主时间线替换原段；需要按镜头对齐包装时，对中间件做一次场景检测切开。原工程保留在 `work/`，需要改时回原工程改。
- 脚本：能。
- 检查：中间件里的效果完整；包装和每个镜头的起止对齐。
- 常见错误：把多条效果轨层层嵌套继续剪，工程卡死。
- 状态：试用
- 来源：第 10 集
