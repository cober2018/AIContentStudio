# 音乐卡点与变速

先读 `choose.md`。DaVinci 接口名以 Resolve 21 脚本文档为准（`search_scripting_api` 可查）。

### 先标节拍，再定切点
- 思路：音乐先给出节拍坐标，镜头长度和切点都往坐标上靠。
- 用在：无配音或配音很少、靠音乐撑结构的段落（开场预告、段落混剪、产品展示）。
- 不用在：配音驱动的讲解——切点跟配音走（见 `finishing.md`），音乐只垫底。
- 做法：取得音乐的节拍时间（本地分析音频得到拍点，或在 Fairlight 音乐编辑器里看拍点）→ 用 `Timeline.AddMarker` 在拍点打标记（重拍用一种颜色，弱拍用另一种）→ 镜头切点落在标记上。舒缓段只用重拍，密集段可用每拍。
- 脚本：能。拍点 → 帧号 → `AddMarker`；按标记计算每个镜头的帧数再追加。
- 检查：切点和听到的鼓点一致；标记密度和音乐段落匹配。
- 常见错误：全段每拍都切，眼睛累；切点比鼓点晚一两帧（以帧号计算，不凭拖动）。
- 状态：试用
- 来源：第 1、3 集

### 切分节拍：局部打破规律
- 思路：一直在意料之中的拍点上切，观众会麻木；偶尔在两拍之间切一刀，或抢在重拍前切，能制造惊喜。
- 用在：已经按节拍立住规律的段落中的一两个关键点。
- 不用在：规律还没立住之前；一段里超过两次。
- 做法：在两个拍点中间加一个标记（半拍位置），把关键镜头的切点对到这个标记，或提前到重拍前半拍。
- 脚本：能。半拍帧号 = 相邻两拍帧号的中点。
- 检查：整体仍能感到稳定节拍，只有个别切换出乎意料。
- 常见错误：改得太多，全段失去节拍感。
- 状态：试用
- 来源：第 3 集

### 音乐收在重拍上
- 思路：音乐在一句结束的重拍上收，比淡出更干脆。
- 用在：音乐长度对不上画面、需要在一个乐句末尾结束时。
- 不用在：音乐垫在配音下且结尾还有说话（用 `finishing.md` 的 1.5 秒淡出）。
- 做法：找到副歌或乐句末尾最强的那一拍 → 在该帧切开，删掉后面 → 画面最后一个镜头同帧结束；确实需要余韵时，见 `sound.md`「混响尾音」。
- 脚本：能。拍点帧号即裁切点；`TimelineItem.SetFades` 可补极短的淡出防咔哒声。
- 检查：听感收在拍上；音乐和画面同时结束。
- 常见错误：乐句中间一刀切断；只会淡出，结尾显得敷衍。
- 状态：试用
- 来源：第 4 集

### 变速基础
- 思路：统一变快压掉拖沓，统一变慢把动作展开；变速改变时长，不是裁剪。
- 用在：整段只需一个速度时。
- 不用在：需要速度起伏时（用「曲线变速」）。
- 做法：Edit 页右键 Change Clip Speed，或脚本 `TimelineItem.SetSpeed({"Percentage": 80.0})`（0 为定格；`RippleTimeline` 决定后面片段是否跟着移）。有原声需要保留时打开 Pitch Correction（`SpeedOptions.PitchCorrection`）。
- 脚本：能。
- 检查：时长与速度一致，没有黑帧或空隙。
- 常见错误：拖片段边缘当成变速（那只是改入出点）。
- 状态：试用
- 来源：第 7 集

### 曲线变速：加速冲过去、快放平台
- 思路：转场前后突然加速，把观众拽进下一个场景；需要一段持续快放时，做成「加速—平台—减速」。
- 用在：运动镜头之间的过渡、长动作需要压缩时。
- 不用在：讲解画面、需要看清细节的镜头。
- 做法：Edit 页 Retime Controls → Retime Curve，加速度关键帧；鼓包形是冲一下，平顶形是一段持续快放；两端回到 100%。Resolve 21 的 retime 曲线支持贝塞尔缓动，曲线拐角做圆。
- 脚本：不能（曲线需手动；脚本只能设单一速度）。在导演稿写明速度形状和时间点，交给人工或在 Resolve 中手动完成。
- 检查：加速集中在转场前后一两秒；两端回到正常速度；曲线没有直角。
- 常见错误：全片只用匀速；平台段做成单个尖峰。
- 状态：试用
- 来源：第 7 集

### 动作顶点快转慢
- 思路：在动作爆发点之前快，爆发那一刻骤降到 10–30%，速度反差让观众看清细节。
- 用在：有明确爆发点的运动画面（溅起、撞击、落地、开盖的一瞬）。
- 不用在：没有爆发点的平缓画面；一条片里超过一两次。
- 做法：找到爆发帧 → Retime Curve 在爆发帧之前拉高、爆发帧处骤降到 10–30% → 慢放段长约 0.5–1.5 秒 → 回到正常速度。慢放处理方式见下一节。
- 脚本：不能（同上）。
- 检查：高峰和深谷紧贴爆发帧；慢放段细节清楚；突变干脆。
- 常见错误：转折点偏离爆发帧；用得太多让人疲劳。
- 变体（试用）：定格。爆发帧直接定格 0.3–0.6 秒（Retime Controls 的 Freeze Frame），配一个重音或字卡，再恢复正常速度。比慢放更干脆，适合揭晓那一刻。
- 状态：试用
- 来源：第 7 集；video-shotcraft（speed-ramp-freeze）2026-10-28

### 慢放画面不卡：先看帧率，再选补帧
- 思路：慢放需要更多帧。原生高帧率最好；不够时再用算法补，补的永远比不上拍的。
- 用在：慢于 50% 的慢放。
- 不用在：需要证明真实动作的镜头（补帧会生成原本没有的画面）。
- 做法：素材 ≥ 时间线帧率 × 2（如 60/120 fps 用于 30 fps 时间线）时，直接按比例慢放即可。不够时设 `RetimeProcess` 为 Optical Flow（`RETIME_OPTICAL_FLOW`），`MotionEstimation` 选 Speed Warp（Better）；运动复杂的画面不用 Frame Blend（会重影）。
- 脚本：能。`TimelineItem.SetProperty("RetimeProcess", ...)` 与 `MotionEstimation`。
- 检查：逐帧看主体边缘没有重影、撕裂、糊团。
- 常见错误：在飞溅、毛发等复杂运动上用帧融合；把补帧当万能慢放。
- 状态：试用
- 来源：第 7 集

### 轻微慢放补空隙
- 思路：差一两秒就能接上时，把镜头放慢一点，比再找素材划算。
- 用在：镜头离下一个切点差 ≤ 约 30% 时长。
- 不用在：需要放慢到 70% 以下才能补满时（换素材或改结构）；有口型的镜头。
- 做法：算出需要的速度 = 现长 ÷ 目标长，`SetSpeed({"Percentage": …})` 设置，速度不低于约 70%。
- 脚本：能。
- 检查：空隙填满；看不出卡顿。
- 常见错误：为补空隙慢放到明显卡顿。
- 状态：试用
- 来源：第 7 集

### 硬切连闪与分格并行
- 思路：音乐副歌、高潮段需要密集节奏时，用硬切本身当打击乐，或把画面分格让几条线同时进行。
- 用在：无配音的音乐段、片头预告、清单类快速列举；有节拍清楚的音乐。
- 不用在：有口播的段落（抢注意力）；情绪安静的片子。
- 做法：先标节拍（见「先标节拍，再定切点」）。
  - 连闪定格：在连续几个重拍上各切一个 3–6 帧的短镜头，最后一个镜头定格停住。
  - 节拍列表：一组形容词或卖点每拍换一个，底色和字色同一拍跟着换（每拍约 0.5–0.6 秒）。底色卡在 AE 做。
  - 四宫格并行：画面硬切成 2×2 四格（达芬奇 Inspector 缩放到 50% 并摆到四角，或用 Video Collage 效果），四格各放一条相关素材，各自在不同拍点动作。
  - 漫画斜格：斜切分格依次填入画面。
  - 预告片式：短镜头和黑场字卡交替，节奏越来越快，最后一下落在重拍上收住。
- 脚本：部分。片段按节拍放置可用时间线 API；分格位置用 `SetProperty`（ZoomX、Pan、Tilt）。
- 检查：每一切都落在拍点上；分格时每格主体都看得清。
- 常见错误：切点偏离拍点一两帧；四格内容无关，观众不知道看哪。
- 状态：试用
- 来源：video-shotcraft（beat-cut-moves、beat-step-list-theme-cycle、quad-split-parallel-scenes、panel-grid-moves、trailer-grammar-moves）2026-10-28
