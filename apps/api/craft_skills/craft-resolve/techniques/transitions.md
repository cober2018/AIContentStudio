# 转场

先读 `choose.md`，再读 `cutting.md` 的「转场只放关键点」。默认硬切；转场只用在换段、换场、情绪转折这些关键点，一条片同一种转场最多一两次。需要图形色块的转场在 AE 做成带透明通道的中间件，再放回达芬奇时间线。

### 镜头运动接力（甩、推穿、后拉）
- 思路：出场镜头和入场镜头沿同一条运动轴接上，观众被「带」进下一段，而不是看到一个特效。
- 用在：换段、换场景；前后两个镜头本身有运动或可以加后期运动。
- 不用在：同一场景内的普通切换；口播精剪的跳切处。
- 做法：三种按情绪选：
  - 横甩：出场镜头沿横向快速甩出（约 0.4 秒，Inspector 的 Position X 加速 + 方向模糊，可轻微旋转约 1.5°），入场镜头从同一方向的另一侧滑入，约 0.35 秒刹住再小幅回稳。交叠约 9 帧（30 帧时间线）。节奏快，适合活泼段落。
  - 推穿：出场镜头加速推近到约 135% 同时变虚，入场镜头从约 116% 的虚焦状态反向落回 100%。交叠约 14 帧。适合「深入一层」。
  - 后拉：出场镜头不动，只是变暗变虚；入场镜头从约 90% 慢慢拉到 100%（约 0.9 秒）。交叠约 16 帧。最慢最安静，适合段落收住后重新开始。
  模糊用 Edit 页 Open FX 的 Directional Blur / Gaussian Blur，配合 Inspector 关键帧；也可在 Fusion 里做。
- 脚本：部分。Zoom / Pan 可用 `SetProperty`；关键帧曲线和模糊需在 Inspector 或 Fusion 手动完成。
- 检查：两侧运动方向一致；交叠处不出现两个画面都清楚的「叠化感」。
- 常见错误：出场向左、入场也从左来（方向反了）；整条片每个切点都用。
- 状态：试用
- 来源：video-talkcraft（whip-pan-transition、push-through-transition、pullback-cool-transition）、video-shotcraft（shot-transitions）2026-10-28

### 藏切点
- 思路：把切点藏在遮挡物、文字或快速运动里，观众感觉是一个连续镜头。
- 用在：想做「一镜到底」的感觉；两个镜头之间有可利用的遮挡（人走过、物体挡镜头、黑色衣服）。
- 不用在：素材里没有遮挡帧（不硬造）。
- 做法：
  - 前景遮挡：在遮挡物完全盖住画面的那几帧切换；遮挡不满屏时，在 Fusion 或 Color 页用遮罩沿遮挡物边缘做一个短擦除（4–8 帧）。
  - 穿越大字：章节大字放大到画面被字的笔画内部填满，在字里切到下一镜，再从字里退出来。字在 AE 做中间件。
  - 文字镂空：大字作为遮罩，字里透出下一段视频，字放大后整屏接管。
- 脚本：不能（切点和遮罩需人工判断、手动完成）。
- 检查：逐帧看切点，没有闪一下的痕迹。
- 常见错误：遮挡不完全，切点露出来。
- 状态：试用
- 来源：video-shotcraft（transition-hidden-cut、transition-travel、text-as-mask）2026-10-28

### 色块扫屏与纯色节拍卡
- 思路：用整屏色块换章节、打节拍，干净利落，适合知识口播和清单类内容。
- 用在：换章节；清单类内容每一条之间；需要重新抓注意力时。
- 不用在：情绪片、生活 Vlog（太硬）；一条片超过三四次。
- 做法：
  - 色块扫屏：两三层同色系色块错开约 60–80 毫秒从同一方向扫过全屏（每层约 0.45 秒），第二层扫过中线那一帧切到下一段。在 AE 做成带透明通道的中间件（ProRes 4444），放在达芬奇的上层轨道。
  - 底边上推：新段落连底色从底部整屏推上来，盖住上一段。
  - 纯色节拍卡：整屏硬切到一帧高饱和纯色底（不过渡），大字和素材卡随后升起，停 1.5–5 秒再硬切回口播。底色跳变本身就是节拍。
  - 黑场震切：出场镜头定格一拍（约 0.3 秒）配一个重音，零交叠硬切到入场镜头，入场镜头带一次小幅震动和从约 110% 拉回的运动。
  - 光标擦除：一条竖线光标从左扫到右，扫过的地方换成下一段。适合科技、文字类内容。
  颜色用全片主题色。
- 脚本：部分。中间件在时间线上的位置可脚本放置；AE 中间件见 craft-ae。
- 检查：色块边缘干净；切换点和音乐重拍或口播换句对齐。
- 常见错误：色块颜色和全片不搭；每段都用，变成套路。
- 状态：试用
- 来源：video-talkcraft（shape-wipe-transition、color-slam-beat-card、black-slam-transition、caret-wipe-transition）、video-shotcraft（bottom-push-stack-wipe、wipe-transitions）2026-10-28

### 线条接力
- 思路：上一段的一条线（进度条、下划线、图表轴）延伸出去，镜头跟着线走到下一段，线围成下一段的边框。全程没有切。
- 用在：两段画面有图形关系（进度条走满 → 下一张卡、下划线 → 图表轴），且都是 AE 图形画面。
- 不用在：两段都是实拍视频；线没有来由（只是装饰）。
- 做法：在 AE 里做成一个合成：线用 Trim Paths 生长，镜头横移（大画布 Position 或摄像机）和线的生长同速，线头始终在画面里；线拐角围出下一段的边框，框闭合后内容才出现。导出后在达芬奇当一个镜头用。
- 脚本：部分（AE 部分可脚本搭，速度同步需检查）。
- 检查：线头从不出画、不落后于镜头；交接处速度连续。
- 常见错误：线和镜头速度不一致，观众跟丢。
- 状态：试用
- 来源：video-talkcraft（line-carry-transition）、video-shotcraft（line-carry-transition）2026-10-28

### 过曝闪白
- 思路：画面亮到发白（或暗到全黑）再从亮心里出现下一段，像揭晓、回忆、情绪转折。
- 用在：揭晓结果、反转、情绪转折点；一条片一次。
- 不用在：普通换段；画面本来就很亮（白闪看不出）。
- 做法：出场镜头推近到约 150%，同时一层白色（暗底素材）或黑色（亮底素材）以切点为中心冲到最高再回落，交叠约 12 帧（30 帧时间线）；入场镜头从亮心里拉出来。达芬奇里用 Edit 页的 Dip to Color Dissolve（颜色选白），或在 Color 页对两侧几帧提亮 Gain；也可在 Fusion 里用径向渐变做从中心亮起。
- 脚本：部分（转场类型需手动添加）。
- 检查：最亮那一帧落在切点；不刺眼（白场时长不超过 4–6 帧）。
- 常见错误：白场太长，像出错；一条片用多次。
- 状态：试用
- 来源：video-talkcraft（overexpose-flip-transition）、video-shotcraft（white-flash-logo-simplify-cut）2026-10-28
