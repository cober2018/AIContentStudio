# craft-writing · 写作标准（不分平台）

一个选题只有一份**本体**（全文）。长文、图卡、横版视频、竖版视频都从本体取材，不另起炉灶。
这份标准四种形态共用，第三方模型和平台模型都用它。以后的通用写作要求加在这里，不按平台另写。

## 1. 开头
- 第一句（视频前 5 秒）就给矛盾或冲突的两样东西：两根 K 线、两个日期、两个几乎一样的因子。
- 让人马上知道要解决哪件事。不先讲比喻铺垫，不先自我介绍。

## 2. 带走物
- 每篇至少有一样观众能保存、下次照着用的东西：一张图、一份表、一个能复算的例子，或一张可勾选清单。

## 3. 可复算
- 写明样本、区间、定义、纳入和剔除规则。
- 公式落到能逐行核对的表上；读者照表能算出同样的数。

## 4. 如实
- 先算再定结论。样本区分不出来，就展示「区分不出来」，不硬说谁更好。
- 核不到的报价、权限、频率删掉，只留判断方法。
- 分开写「自家使用经验」和「供应商当前承诺」。

## 5. 节选与示意
- 为手机展示只挑几行时标「节选」。
- 只有示意数据时标「示意」，不能据此宣称真实结果。示例结果和全样本结果不能混说。

## 6. 本体怎么写（按块）
本体用二级标题分块，块名照下面写，导入的已发表文章可以保留原标题：

| 块 | 写什么 |
|---|---|
| 问题 | 这篇要回答的一个问题 |
| 结论 | 开头就说；区分不出就写区分不出 |
| 做法与口径 | 样本、区间、定义、纳入规则 |
| 结果表或算例 | 能逐行核对的表或算例 |
| 适用条件 | 什么时候适用、什么时候不适用 |
| 出处 | 每条素材和数据的来源、取数日期；区分自家经验与供应商承诺 |

## 7. 四种形态从本体取什么

| 形态 | 取什么 | 规格 |
|---|---|---|
| 长文 | 本体本身 | 不另写一篇，本体定稿后直接出平台版本 |
| 图卡 | 问题、结果表、判断步骤、结论 | 3～6 张，3:4；首张放问题，中间放表，末张揭晓或给可勾选清单 |
| 横版视频 | 完整过程：问题 → 做法 → 结果怎么核 → 结论 | 16:9，3～5 分钟 |
| 竖版视频 | 只追一个点 | 9:16，约 1 分钟 |

## 8. 存稿时平台自动查的
- 派生稿里的数字（阿拉伯数字）要能在本体或已冻结事实里找到；本体没有的数字存不进去。
- 本体说「区分不出 / 无显著差异」时，派生稿不能写「更好 / 跑赢 / 显著优于」这类更强的结论。
- 视频导演稿的画幅要和作品形态一致：横版 16:9，竖版 9:16。
- 查不出的（开头有没有矛盾、带走物、节选标注）靠这份标准和评审 skill 把关。

## 9. 平台差异
- 每个形态作品只有一份发布文案。各平台只按机械限制（标题字数、话题个数、简介长度、封面尺寸）提示超限，不另写一版。
