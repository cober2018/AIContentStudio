# 视频号（channel: wechat_channels）

后台：视频号助手 https://channels.weixin.qq.com （发表页一般是 /platform/post/create）。首版说明，第一次实跑后按真实页面校正。

1. 打开视频号助手。没登录会出微信扫码：停下，请用户用微信扫码登录，确认登录的是对的视频号（看左上角名称，和交付目标的 account 对得上）。
2. 进「发表视频」。
3. 上传视频：找页面上的文件输入框，`setInputFiles` 传 role `final` 的绝对路径。等上传和处理完成（进度到 100%、出现视频预览）再往下；大文件要等几分钟，期间不要刷新页面。
4. 描述：填 `publish_copy.description`；末尾空一格接话题，每个话题写成「#话题」（来自 `hashtags`）。描述框字数有上限时截短描述正文，话题保留。
5. 封面：点「编辑封面 / 更换封面」上传封面图（竖版作品用 `cover`；横版作品用 `cover_vertical`）。页面只让从视频里选帧时保留默认，note 里写明。
6. 短标题（选填）：用 `publish_copy.cover_text`；不够 6 字或超长时用 `title` 截短到页面要求。
7. 位置、合集、活动、链接、原创声明：保持默认，不选。
8. 发布：按 SKILL.md 红线核对账号、视频、封面、文案后点「发表」。只存草稿时点「保存草稿」，**不要点「发表」**。
9. 发表后进「内容管理」的视频列表，等这条出现（显示审核中也算），整页截图；视频号网页上一般没有作品链接，`link` 留空。只存草稿时进草稿箱确认这条在、标题和封面对，再截图。按 SKILL.md 第 5、6 步记录。
