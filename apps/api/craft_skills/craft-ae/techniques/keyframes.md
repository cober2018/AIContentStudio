# 关键帧与缓动

先读 craft-resolve 的 `choose.md`。模板库能做的先用模板（见本技能 `SKILL.md`）。

### 两点关键帧
- 思路：起点一帧、终点一帧，数值不同，中间由软件补齐。
- 用在：任何元素从 A 到 B、从小到大、从透明到不透明。
- 不用在：模板已经带了入出场动画时。
- 做法：时间指针放到起点，在属性上打关键帧（秒表）→ 移到终点，改数值，自动生成第二个关键帧。动画时长就是两帧之间的距离。
- 脚本：能。ExtendScript `property.setValueAtTime(t, v)`；`scripts/ae_build.py` 生成的合成同样写关键帧。
- 检查：两个关键帧数值不同；运动连续不跳。
- 常见错误：两个关键帧数值相同，元素不动。
- 状态：试用
- 来源：第 6 集

### 缓动：所有参与的属性用同一条曲线
- 思路：匀速运动显得机械；先慢后快再慢才有重量感。几个属性一起动时，要用同一种缓动，否则会「先放大再移动」。
- 用在：所有位移、缩放、旋转动画。
- 不用在：需要机械感的元素（进度条匀速走、计时器）。
- 做法：选中关键帧 F9（Easy Ease）；需要更有力时，在图表编辑器里把速度曲线做成两头缓、中间陡（影响度约 60–80%）。同一组动画的 Position、Scale、Rotation 起止帧相同、缓动相同。
- 脚本：能。`property.setTemporalEaseAtKey(index, [KeyframeEase(0, 75)], [KeyframeEase(0, 75)])`。
- 检查：起步缓、中段快、收尾缓；几个属性同时开始、同时结束。
- 常见错误：只给一个属性加缓动；关键帧起止帧没对齐。
- 状态：试用
- 来源：第 6 集

### 静态画面运镜
- 思路：截图、照片、长页面这类静态素材，用一条缓慢的镜头运动撑住整句口播，看不出哪一帧在动，但画面始终不死。
- 用在：截图、文档、照片、长网页撑 3–15 秒口播。
- 不用在：素材本身是动态视频；一条片里每张图都用同一种运动。
- 做法：一张图做成镜头先用模板 `photo-push`（缓推）。其他运动：
  - 缓拉全貌：起手放大约 125% 咬在某个细节上，匀速拉回到原始全貌，让观众在拉开的一刻看到全局。
  - 横向摇移：图比画面宽很多时，横向匀速平移扫过（约每秒 150–170 像素），可加 3–4° 的 Y 轴微倾；起步缓入，结束不完全停死。
  - 3D 立面：图先正视停一拍让人读清，再用 1.2–1.8 秒倾斜成立面（3D 图层，Y 轴转 12–25°，X 轴略转），投影同步加深。
  - 长页巡游：超长网页放在 3D 透视面上，摄像机依次停靠 2–3 个兴趣点（每点停 0.8–1 秒），最后拉开。
  - 分层视差：把图拆成前景、中景、背景几层（或用 3D 图层摆开深度），摄像机平移时近层移得多、远层移得少。
  - 环绕微漂：3D 空间里绕静态页面做小幅环绕，只作氛围。
  运动时长和这一句口播等长，一句话一条曲线。
- 脚本：能（Scale、Position、3D 摄像机关键帧）。
- 检查：运动速度均匀、看不出跳；结束时主体在构图位置。
- 常见错误：推得太多，看出明显在放大；一条片所有静态图都同一种推法。
- 状态：试用；**模板候选**（`photo-push` 的拉远、横摇变体）
