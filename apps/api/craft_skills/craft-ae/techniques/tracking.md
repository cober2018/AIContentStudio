# 跟踪

先读 craft-resolve 的 `choose.md`。跟踪是重活，完成后按 craft-resolve `workflow.md`「重效果先出中间件」渲染。

### 点跟踪：标签跟着物体走
- 思路：标签、箭头跟着画面里移动的物体走，观众一眼知道在说哪个东西。
- 用在：产品评测、装备清单，给运动中的物体贴名字或参数。
- 不用在：物体几乎不动（直接固定位置更稳）；物体频繁被遮挡。
- 做法：AE Tracker → Track Motion，跟踪点放在物体上对比强、不会消失的特征（镜头模组、logo 边、按钮），只勾 Position → 双向分析 → 把数据应用到一个空对象（Null）→ 标签图层父级绑到 Null。只要位置跟随、大小保持不变，所以不要勾 Scale / Rotation。DaVinci 可用 Fusion 的 Tracker 做同样的事。
- 脚本：部分。分析需在界面中运行；绑定父级、标签样式能 ExtendScript。
- 检查：整段标签贴住物体不漂；标签大小稳定。
- 常见错误：跟踪点放在低对比、会消失的区域；把缩放也跟上了，标签忽大忽小。
- 状态：试用
- 来源：第 10 集

### 平面跟踪：把画面贴到表面上
- 思路：要让文字或画面「长」在手机屏、墙面、桌面上，随镜头运动保持透视，用平面跟踪。
- 用在：屏幕替换、在墙面或桌面上放标题、产品表面贴信息。
- 不用在：表面大部分时间被遮挡；表面很小或几乎看不到。
- 做法：AE 用 Mocha AE：
  1. 从表面露出最大、最正、最清楚的那一帧开始画跟踪区域。
  2. 表面本身没有纹理时，选同一平面上的参照物（贴纸、卡片、边框）来画范围。
  3. 前后两个方向跟踪，检查后把 Surface 四角对齐真实边角。
  4. 导出 Corner Pin 数据贴到素材层；透视不对时手调四角。
- 脚本：部分。跟踪需人工；导出的角点数据应用能脚本。
- 检查：四角全程贴住表面；近大远小和物体一致；没有一跳一跳的抖动。
- 常见错误：在表面倾斜、很小或被挡的帧上开始画；无纹理的大平面直接框整块。
- 状态：试用
- 来源：第 11 集

### 平面离开画面前收掉
- 思路：跟踪的表面一旦转出画面，后面的数据就不可信，素材要在那之前退场。
- 用在：一镜到底中跟踪的表面会转走或被挡。
- 不用在：表面全程可见。
- 做法：找到表面完全离开画面的前一帧 → 素材在此结束，在此前 0.3–0.5 秒做出场动画（透明度或缩小）→ 表面再出现时重新跟踪一段新的。
- 脚本：能（图层出点和出场动画）。
- 检查：表面消失时素材已经退场，不会悬在空中乱飘。
- 常见错误：素材一直延续到表面消失之后。
- 状态：试用
- 来源：第 11 集
