# 数据与步骤

先读 craft-resolve 的 `choose.md`。单个数字先用模板 `number-card`，步骤先用 `diagram-flow`，地图先用 `map-route`；数据只用有来源的真实数据，画面角落标来源。

### 图表生长
- 思路：数据念出来记不住，让图表跟着口播长出来，结论最后一拍出现。
- 用在：增长、对比、趋势，3–8 个数据点。
- 不用在：只有一个数字（用 `number-card`）；数据没有来源。
- 做法：
  - 柱状：坐标轴或基线先画出（约 0.25 秒），柱子从基线依次升起，错开约 0.06 秒，读起来像一次连续动作；最后一根到顶那一帧，结论标签在柱顶弹出。
  - 折线分段：已有的部分一开始就在，讲到新阶段时，新线段从拐点向右画出（Trim Paths，0.4–0.8 秒），画完那一刻涨跌标签弹出；需要对比时第二条虚线从同一拐点岔出。
  - 渐变强调：柱子入场错开的同时，颜色从中间向两边渐变，最高那根脉冲一次。
  柱子高度用真实数值按比例算，不夸大差距；纵轴不从 0 开始时要标出。
- 脚本：能（形状图层 + Trim Paths；数值可从 JSON 生成）。
- 检查：比例正确；结论出现在数据长完之后。
- 常见错误：为了好看拉大差距；所有柱子同时升起。
- 状态：试用；**已有模板** `bar-grow`（柱状）、`line-story`（折线分段）、`metric-trend`（数字带趋势线）
- 来源：video-talkcraft（bar-chart-growth、chart-grow、line-chart-story-draw）、video-shotcraft（chart-live-moves、value-stagger-gradient）2026-10-28

### 比例点阵
- 思路：「十个人里有三个」「37%」这类比例，摊成 100 个小格染色，比一个百分数更有体感。
- 用在：比例、占比、概率。
- 不用在：比例很小（低于 3%，染色看不出）；需要精确到小数。
- 做法：10×10 小方格从中心一圈圈长出来（每圈约 4 帧，约 1.1 秒铺满，只动不透明度和缩放）；然后按阅读顺序逐格染成强调色（约 0.035 秒一格），旁边大数字用同一时钟从 0 数到目标值；图例最后出现。
- 脚本：能（Repeater 或表达式生成网格，染色用索引和时间比较）。
- 检查：染色格数和数字一致；数字停住时染色也正好停。
- 常见错误：格子数和比例对不上。
- 状态：试用
- 来源：video-talkcraft（unit-grid-proportion）2026-10-28

### 步骤与时间线
- 思路：讲步骤、讲先后时，让观众看到「一共几步、现在第几步」。
- 用在：教程步骤、使用方法、事件经过（3–6 项）。
- 不用在：项与项没有先后（用多图排版或词槽轮换）。
- 做法：先看模板 `diagram-flow` 是否够用。其他版式：
  - 编号堆入：几条带编号方块的横条从右侧以均匀间隔（约 0.11 秒）依次堆入，每条落定那一帧编号方块弹一下（112→100%，4 帧）；全部到位后整组上浮约 4 像素。
  - 竖向时间线：一条竖线从上往下画出（约 0.6 秒），线画到哪个节点，那个节点就弹出，2 帧后右侧文字跟着出现；全部到位后，当前这一步换成强调色空心环并放大约 125%。
  - 横向时间轴：镜头沿一条水平刻度轴移动，先加速后急停在目标年份。
  - 照片时间带：有先后的几张照片沿一条线依次排开。
  - 逐项列表：菜单式列表逐项缩放出现，间隔约 10 帧。
- 脚本：能。
- 检查：顺序一眼看出；当前步骤明确。
- 常见错误：间隔不均匀，节奏乱；全部同时出现。
- 状态：试用；**已有模板** `step-line`（竖向步骤线）、`timeline-travel`（时间轴横移）
- 来源：video-talkcraft（numbered-step-stack、step-timeline-vertical、timeline-photo-strip）、video-shotcraft（timeline-travel、list-reveal、list-stack-press、row-embed）2026-10-28

### 选项揭晓
- 思路：几选一的问题，先让观众看清所有选项、自己猜，再揭晓答案。
- 用在：「这几个里哪个最适合你」「答案是哪个」类互动段。
- 不用在：答案没有依据；选项超过 6 个。
- 做法：几个选项标签居中排开（如 3+2），先停约 2 秒让人读题；揭晓那一帧先插 1 帧灰色按压，接着约 5 帧线性反色（底变深、字变白）并轻弹（100→104→100%），其余选项降到约 18% 不透明度但位置不动；停约 1.5 秒后其余消失，答案上移变成标题。
- 脚本：能。
- 检查：读题时间够；揭晓瞬间清楚。
- 常见错误：揭晓太快，观众还没读完选项。
- 状态：试用
- 来源：video-talkcraft（chip-grid-single-select）、video-shotcraft（chip-grid-single-select-blackout）2026-10-28

### 地图路线与流程汇聚（模板补充）
- 思路：模板 `map-route` 和 `diagram-flow` 之外的两种常用补充。
- 用在：路线讲到达点；几个来源汇成一个结果。
- 不用在：模板已经够用。
- 做法：
  - 到点落钉：路线虚线从 A 长到 B（0.8–1.5 秒），到达那一刻图钉从上方落下，压扁回弹一次（约 0.25 秒），地名标签侧滑出现。
  - 多源汇聚：左侧几个来源标签各有一条曲线连到右侧汇聚点，曲线依次接通（错开约 0.15 秒）；来源标签沿各自曲线滑向汇聚点并缩小，像被吸进去；汇聚点脉冲一次（放大约 12%），结果标签出现。
- 脚本：能（沿路径运动用 Position 粘贴路径，或表达式 `pointOnPath`）。
- 检查：路线、连线不交叉；终点信息清楚。
- 常见错误：曲线交叉缠在一起。
- 状态：试用；**已有模板** `route-pin`（地图落钉）、`converge`（多源汇聚）
- 来源：video-talkcraft（map-route-pin、source-converge）、video-shotcraft（bezier-source-converge-merge、integration-hub-map）2026-10-28
