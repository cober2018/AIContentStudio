# 抠像与叠加合成

先读 craft-resolve 的 `choose.md`。简单的人物分离也可以直接在 DaVinci 做，写在对应节里。

### 人物或物体分离
- 思路：把主体从背景里拿出来，才能换背景或在主体后面放东西。
- 用在：口播、评测里人物清楚、背景不太乱；或要把某个物体单独拿出来。
- 不用在：边缘很复杂（大量飘动发丝、透明物体）又必须精细时，先评估工作量，写进导演稿让用户决定。
- 做法：
  - DaVinci：Color 页 Magic Mask（`TimelineItem.CreateMagicMask("BI")` 双向追踪），人物模式或物体模式；需要时 Resolve 21 可把 Magic Mask 渲染成外部遮罩。
  - AE：Roto Brush 3 在主体上涂一笔 → 往前后传播 → 用 Refine Edge 处理头发边缘。
  - 完成后快速拖动时间线检查整段，有漏的地方补涂、多的地方减掉。
- 脚本：部分。Magic Mask 能脚本发起；修补需人工。
- 检查：整段没有残留背景，也没有缺块；边缘不闪。
- 常见错误：只看一帧就认为抠好了；漏抠的地方不补。
- 状态：试用
- 来源：第 8 集

### 绿幕
- 思路：按颜色把背景去掉，再收边缘、去溢色。
- 用在：绿幕、蓝幕素材。
- 不用在：非纯色背景。
- 做法：AE 用 Keylight：吸背景色 → Screen Matte 视图下调 Clip Black / Clip White，让背景全黑、主体全白 → Screen Shrink/Grow 收 1 像素左右、Screen Softness 轻微羽化 → Despill 去掉边缘绿色。DaVinci 可用 3D Keyer 做同样的事。绿幕没覆盖到的地方先用遮罩挡掉（见下一节）。
- 脚本：部分。效果和参数能 ExtendScript 设置；数值需看画面调整。
- 检查：遮罩视图里背景纯黑、主体纯白；边缘没有绿边、没有锯齿；参数不过头（主体没被吃掉）。
- 常见错误：只吸一次色不收边；参数拉过头，主体边缘被吃掉。
- 状态：试用
- 来源：第 8 集

### 遮罩挡穿帮
- 思路：绿幕不够大、灯架入画时，先用一个形状把主体框住，框外全部扔掉。
- 用在：画面边缘有穿帮、背景杂物。
- 不用在：主体运动幅度大到框不住时（改用跟踪遮罩或换镜头）。
- 做法：AE 在图层上画椭圆或矩形 Mask，羽化 20–60 像素，确保主体动作最大时也在框内；需要跟着主体动时给 Mask Path 打关键帧或用跟踪。DaVinci 用 Power Window 同理。
- 脚本：能（固定遮罩）；跟随主体需人工。
- 检查：主体全程在框内；框外没有穿帮。
- 常见错误：框太紧，主体动作时被切掉。
- 状态：试用
- 来源：第 8 集

### 三层夹心：人在前、字在中、背景在后
- 思路：让关键字出现在人物身后，强调感和空间感都比字直接压在画面上强。
- 用在：口播或评测讲到一个关键词、关键数字的那一两秒。
- 不用在：人物大面积挡住文字的位置；一条片超过两三次。
- 做法：同一素材放两层：下层原画面（背景），上层做人物分离（见上）→ 文字层放在两层之间 → 文字加入场动画，时间点对上配音说到该词的帧（ASR 对齐时间，见 `components.md` 时间规则）。
- 脚本：部分。分层和文字能用 ExtendScript 搭；人物分离的质量需人工确认。
- 检查：层级正确；关键字没被身体挡住；人物边缘干净。
- 常见错误：上下两层叠在一起看不出抠像问题（检查时先关掉下层）。
- 变体（试用）：大字从人身后升起——超大标题约 0.6 秒从人物身后升起，字距同时由松收紧，下缘被人物挡住；停留时标题和人物各自反向极缓漂移约 4 像素，平面画面也有前后层次。
- 状态：试用
- 来源：第 8 集；video-talkcraft（behind-text-title）2026-10-28

### 黑白素材用混合模式叠
- 思路：烟雾、粒子、光效这类黑底或白底素材，不需要抠，换个混合模式就行。
- 用在：叠加光效、粒子、烟雾、漏光等黑底或白底素材。
- 不用在：彩色复杂背景的素材。
- 做法：黑底要保留亮的部分 → Screen 或 Add；白底要保留暗的部分 → Multiply；只想增加质感 → Overlay / Soft Light，再降不透明度。DaVinci 的 Composite Mode 同名可用。
- 脚本：能。图层 `blendingMode` 属性。
- 检查：底色完全消失，没有发灰的底；元素完整。
- 常见错误：用抠像去处理这类素材，边缘很粗糙。
- 状态：试用
- 来源：第 8 集

### 光效叠加只当调味
- 思路：漏光、光晕能强化情绪，但用多了每条片都一个样。
- 用在：情绪最强的一两个点；夜景或回忆段落。
- 不用在：说明、证明类镜头；一条片超过两次。
- 做法：黑底光效素材按上一节用 Screen 叠在镜头上，时长 0.5–1.5 秒，不透明度 30–70%；DaVinci 可直接用 Resolve FX 的 Light Rays / Glow。素材来自项目或通用素材库。
- 脚本：能（素材叠加与混合模式）。
- 检查：光效没有盖住主体和文字。
- 常见错误：每个镜头都加。
- 状态：试用
- 来源：第 3 集

### 讲者让位给图形
- 思路：口播人物和图表、素材抢画面时，人缩小让台但不消失，观众既看得清图形，也知道是谁在讲。
- 用在：口播中段要上图表、截图、多项并列内容时。
- 不用在：图形很小，放在人旁边就够（用标注或信息卡）；没有人物出镜。
- 做法：
  - 缩成头像章：图形上台时，人物 0.35–0.5 秒缩进角落的圆形头像（圆形遮罩，缓入缓出），继续说话；图形从对侧晚约 0.15 秒进入。讲完再放大回全屏或直接切下一镜。
  - 竖卡加展示台：人物装进左侧约 1/3 宽的竖卡（圆角、半透明白描边）常驻，右侧约 2/3 放一块展示区，图形按口播依次放进去。
  - 人在场的并列项：口播讲「A、B、C」三件事而人物还在画面里时，三项按口播逐个弹出（约 0.6 秒一项），放在人物头顶或侧边空位，标签大、压在小图上，不挡脸。
  人物缩小后仍在安全区内，口型可辨。
- 脚本：能（Scale、Position、遮罩关键帧）。
- 检查：图形清楚、人脸不被挡；切换时口播不断。
- 常见错误：人物缩进角落后被平台按钮挡住；图形和人同时动。
- 状态：试用
- 来源：video-talkcraft（host-shrink-to-chip、host-card-glass-board、parallel-items-with-host）2026-10-28
