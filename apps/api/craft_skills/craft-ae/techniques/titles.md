# 文字与数据包装

先读 craft-resolve 的 `choose.md`。数字、标题已有模板（`number-card`、`title-card`）时先用模板；版式、字号、位置以 `components.md` 为准。字幕本身按 craft-resolve `finishing.md`（ASR 对齐、按标点断句）。

### 文字可读性：阴影优先，描边兜底
- 思路：文字压在运动或明暗变化大的画面上时，每一帧都要读得清。
- 用在：直接压在画面上的文字（没有底板的标题、标签）。
- 不用在：已有底板或素材卡片的文字。
- 做法：先加柔和阴影：Drop Shadow 不透明度约 20–40%、柔化 10–20、距离 3–6；仍不清楚再加 2–4 像素细描边。同一条片所有同类文字用同一组参数。
- 脚本：能。
- 检查：亮画面和暗画面上都读得清；阴影不糊，描边不把字压粗。
- 常见错误：阴影太重成一团黑；描边太粗。
- 状态：试用
- 来源：第 10 集

### 字幕位置避开平台界面
- 思路：字幕或标题被平台按钮、文案挡住，等于没有。
- 用在：所有竖屏交付。
- 不用在：无。
- 做法：按 `safe-zones/` 的播放安全区（9:16：x 59–1016、y 268–1482，中下部右侧按钮列处右边界 886）；字幕由配音生成，先生成字幕，再垫音乐，避免识别受干扰。
- 脚本：能（位置检查）。
- 检查：关键文字不在安全区外。
- 常见错误：字幕贴边。
- 状态：试用
- 来源：第 2 集

### 人名条
- 思路：多人出现时，左下角一条「姓名 + 身份」，观众马上知道谁是谁。
- 用在：采访、对谈、多人出镜，每人第一次开口时。
- 不用在：只有一个人且身份已在开头交代过。
- 做法：左下角固定位置，两行（姓名大、身份小），入场 0.3–0.4 秒、停留约 3 秒、出场 0.3 秒；所有人名条位置和字号一致，不压脸。
- 脚本：能。
- 检查：一眼能对上人；几条人名条位置一致。
- 常见错误：每条位置、样式都不一样。
- 变体（试用）：姓名从左推出约 26 像素（0.26 秒），身份底块错开 0.1 秒从左按 Scale X 展开，块内文字晚 2 帧淡入；停约 2 秒后整条从左收回。入场和出场方向一致，不要一个从左来、一个向下走。
- 状态：试用；**已有模板** `name-plate`、`name-chevron`
- 来源：第 12 集；video-talkcraft（chevron-lower-third、lower-third-nameplate）2026-10-28

### 数字快速跳动
- 思路：价格、计数在很短时间里乱跳，最后停在目标值，制造紧张感。
- 用在：揭示价格、数量、结果之前的 0.5–1 秒。
- 不用在：需要观众读清中间数值时（用滚动数字）。
- 做法：文字图层的 Source Text 每 2 帧打一个关键帧（定格关键帧），共 8–12 个随机数值，最后一帧是目标值；或用表达式按时间生成随机数，到点后固定为目标值。
- 脚本：能。
- 检查：在 30 帧时间线里是闪动而不是逐格停留；最后准确停在目标值。
- 常见错误：间隔太长，看起来像幻灯片。
- 变体（试用）：
  - 数字重音标题：标题里的数字先单独从约 160% 缩到 100%（约 0.3 秒），落定那一帧换强调色，后面的文字再从数字右缘被遮罩推出来；收尾数字再弹一下（5 帧，100→110→100%）。
  - 色块托数字：实色块先落定（约 0.24 秒），数字随后从 72% 弹到 100%（Overshoot 缓动），小数和单位晚 6 帧单独淡入。
  - 数字带趋势线：大数字滚动的同一刻，下方小折线用 Trim Paths 在 0.6 秒内画完，数据点随线端依次弹出；单位和涨跌箭头等数字停住那一帧才出现，结论比过程晚半拍。
  - 倒数弧：一串递减数字沿大弧排开、整体快速扫过一次，停在目标数字。只在「倒计时、清单第几条」时用，一条片最多一次。
- 状态：试用
- 来源：第 10 集；video-talkcraft（count-badge-title、number-slab-pop、metric-with-sparkline、countdown-arc-scatter）、video-shotcraft（gauge-readout-moves）2026-10-28

### 滚动数字窗
- 思路：数字从旧值向上滚到新值，只在一行字高的窗口里滚，像计分牌翻页。
- 用在：价格变化、计数增加、计时器。
- 不用在：只出现一次的静态数字（用 `number-card`）。
- 做法：旧数字向上滑出、新数字从下滑入（各约 0.3–0.4 秒，同一缓动，新数字比旧数字晚 2–3 帧开始）→ 两层预合成后加一个只有一行字高的矩形遮罩，边缘轻微羽化。多位数字时每一位依次错开 2–3 帧，形成阶梯。
- 脚本：能。
- 检查：像同一个数字在窗口里被替换；多位数字有先后层次；窗口边缘柔和。
- 常见错误：不加遮罩，整屏都在滚；出场入场不配对。
- 状态：试用；**已有模板** `number-roll`
- 来源：第 10、13 集

### 半透明信息卡
- 思路：一组半透明的圆角小卡片放数字或标签，有存在感又不挡背景。
- 用在：计时器、数据看板、多项参数并列。
- 不用在：背景本身很花、半透明后读不清时（改用实底卡片）。
- 做法：形状图层圆角矩形（圆角约为高度的 1/4），黑色填充，不透明度 40–50%，1–2 像素浅色描边，外发光轻微；多张卡片用对齐面板等距水平排列；下方可加一条压扁的标签底条。
- 脚本：能。
- 检查：卡片对齐、等距；背景可辨、文字清楚。
- 常见错误：描边太粗；卡片靠肉眼摆，间距不齐。
- 变体（试用）：
  - 名词解释卡：口播说到专业名词的那一刻，一张「图标 + 词条 + 两行解释」的圆角卡从人物对侧滑入（约 0.35 秒，轻微过冲），停留时上下浮动几个像素，念完原路滑出。卡不压人脸。
  - 逐字段自建的参数卡：商品参数卡或工具卡按阅读顺序一项项长出来（图 → 名称 → 标签 → 价格 → 要点），相邻两项只隔 2 帧、每项动 0.4–0.5 秒，看起来像一次连续动作。只写资料里有的参数，价格会变的不上卡。
- 状态：试用；**模板候选**（字段：卡片数、每张的数值、标签）
- 来源：第 13 集；video-talkcraft（info-term-card、info-card-assemble）、video-shotcraft（product-card-progressive-assemble）2026-10-28

### 关键词重音
- 思路：口播里最重要的那个词要从字幕里跳出来，观众扫一眼就知道这句的重点。
- 用在：每段口播里真正的关键词、关键数字，一句最多一个。
- 不用在：整句都想强调（等于没强调）；一条片超过五六次。
- 做法：四种选一种，全片统一：
  1. 色块弹出：关键词带底色块从 0 弹到约 165% 再回落到约 115% 定住（弹出 0.18 秒、回落 0.22 秒），画面同时轻震 2–4 像素。
  2. 字体落差：普通词无衬线小字轻轻出现（95→100%，不回弹）；重音词换一种字体（衬线或粗斜体）并放大到 150–200%，或换唯一的强调色。动作做轻，靠字体反差。
  3. 斜切色块：第二行重点词坐在一块斜切色块上；色块从中心按 Scale X 撑开（0.22 秒），撑满那一帧白字才出现并从 112% 落到 100%（5 帧）。
  4. 描边转实心：关键词先是空心描边，缩小到位的同时填满颜色（0.2–0.3 秒）。
  出现时间对准配音念到这个词的帧（ASR 对齐）。
- 脚本：能。
- 检查：静音看也能找到每句的重点；强调词出现时配音正好念到。
- 常见错误：几种强调混用；强调词比配音早或晚半拍。
- 状态：试用
- 来源：video-talkcraft（keyword-pop-highlight、type-contrast-emphasis、slab-punch-title、speed-slab-title、outline-box-title）、video-shotcraft（gradient-word-sweep、outline-word-fill、type-rhythm-sync、brace-expand）2026-10-28

### 对句与改口
- 思路：「不是 A，而是 B」「以前 / 现在」这类对照，靠形式让两行读成一对；改口用划掉重写表现观点转折。
- 用在：口播里有明确对照或纠正常见误解时。
- 不用在：两行没有对照关系；一条片超过两次。
- 做法：
  - 双色块对句：两行各坐在贴合文字宽度的色块上，结构完全相同、明暗相反（一行实色白字，一行白底黑字加 1 像素灰描边）。每行色块从左按 Scale X 展开约 0.26 秒，文字用遮罩跟着色块右缘被「刷」出来，晚 2 帧；第二行错开 0.12 秒。
  - 划线替换：一条横线 0.15 秒快速划过旧词，隔 0.1 秒旧词淡出，新词从同一位置下方约 8 像素升上来（0.25 秒）；划线和新词同屏停 2 秒。句子其余部分不动。
  - 打字改口：后半句逐字打出（约 0.09 秒一字），光标停顿闪两下，再用更快的速度退格（约 0.06 秒一字），然后重新打出正确的词。三种速度的差别就是戏。
- 脚本：能（Source Text 关键帧或 Text Animator 的 Range Selector）。
- 检查：一眼看出两行是一对、谁对谁错；替换时句子不跳位。
- 常见错误：两行各自淡入，看不出对照；色块和字分别出现。
- 状态：试用
- 来源：video-talkcraft（alt-block-lines、strike-and-replace、error-retype、typewriter-reveal）、video-shotcraft（text-column-converge、typewriter-moves、document-typewriter-reveal）2026-10-28

### 金句卡
- 思路：一句核心观点需要观众停下来读，把它从字幕升级成一张卡。
- 用在：一条片里最核心的一句话，通常在中段或结尾前。
- 不用在：普通信息句；一条片超过一次。带货片结尾不用金句收（见脚本评审）。
- 做法：
  - 底板盖住画面：底板 0.25 秒盖过人物，3–5 行大字自上而下逐行弹出（每行 0.4 秒、错开 0.15 秒），关键词换色放大；停 2–4 秒后整卡下滑退场。
  - 先平后升：几行字先用普通样式淡入，最后一行原地停约 0.3 秒，然后高亮框从文字中心按 Scale X 铺开（0.24 秒），文字再弹一下。
  - 大引号夹句：两枚比正文大约三倍的引号从左右两侧对向进入夹住句子。
- 脚本：能。
- 检查：停留时间够读完（每秒约 4–5 个字）；退场后口播自然接上。
- 常见错误：句子太长，一屏塞不下；停留太短读不完。
- 状态：试用
- 来源：video-talkcraft（quote-card、quote-hold-arrow、quote-bracket-pull）2026-10-28

### 标题入场四式
- 思路：标题出现的方式决定气质；这四种都轻、稳、不抢戏，适合讲解类竖屏。
- 用在：段落标题、要点标题、大字陈述。
- 不用在：需要冲击力的开场（用「冲击开场字」）。
- 做法：全片选一两种：
  1. 柔焦淡入：整句从模糊（约字号的 1/6）边解模糊边淡入，约 0.9 秒；轻微下沉位移只占前 0.3 秒；逐字错开 1 帧。
  2. 逐字升起：每个字从自己位置下方（约字号 40–45%）升到位，位移 0.33 秒、淡入 0.7 秒，逐字错开 1 帧，读起来像一股气顶上来。
  3. 逐行滑入：多行要点逐行从左侧滑进（位移约 0.5 秒、淡入约 0.9 秒，行间错开约 0.13 秒）；退场向右滑出，错开时间减半。
  4. 字距收拢：字距从约 0.5em 收到正常，同时解开约 9 像素模糊，前 0.3 秒走掉大半，剩下慢慢到位，不回弹。
- 脚本：能（Text Animator：Position、Opacity、Blur、Tracking 加 Range Selector；或 Effect → Animation Presets 的对应预设）。
- 检查：在手机上看整句清楚、不发虚；同一条片入场方式统一。
- 常见错误：每个标题换一种入场；逐字错开太大，像一个个蹦出来。
- 状态：试用
- 来源：video-talkcraft（soft-blur-in、per-character-rise、line-by-line-slide、tracking-in、split-text-stagger）、video-shotcraft（blur-slide、type-assembly-moves、type-entrance-moves、letterspace-materialize、stroke-segment-build）2026-10-28

### 词槽轮换
- 思路：一句话固定前半句，后面的词槽轮换几个词，一屏讲清「它能用在很多地方」。
- 用在：列举用途、场景、人群（三到五个）。
- 不用在：要逐个详细讲的内容；词长度差太多。
- 做法：前半句左端固定；句尾放一个深色圆角底块，每 0.6–0.8 秒向上翻一格换一个词（前 8 帧换位带运动模糊，后面静止让人读），底块宽度跟词长同步伸缩；上下各露一点半透明的下一个词，暗示还有更多。换完收到结论句。
- 脚本：能（Source Text 关键帧 + 形状宽度表达式 `sourceRectAtTime`）。
- 检查：每个词停留够读；句子前半部分完全不动。
- 常见错误：换得太快读不完；底块宽度跳变。
- 状态：试用
- 来源：video-talkcraft（word-slot-cycle）、video-shotcraft（pill-slot-cycle、vertical-word-roll-blur-cycle、pill-chip-slot-cycle-handled、avatar-bracket-carousel、glitch-cycle）2026-10-28

### 冲击开场字
- 思路：第一秒用一个大字或一句话压住画面，配合开头机制停住手指。
- 用在：开头 0–1 秒；无人出镜、以文字开场的片子。
- 不用在：开头已有强画面（字会抢画面）；中段。
- 做法：
  - 首词占满再补句：第一个词以约 230% 字号独占画面中央，停约 0.4 秒并继续轻推近约 6%；然后同一条缓动同时缩回正常字号并整行左移归位，后面的词从右侧依次推入。
  - 整句砸出：整句从 108% 落到 100%（约 0.2 秒），最后一个词晚 3 帧换强调色再弹一下；四角小取景框同时向内收约 12 像素。
  - 砸入冲击（高能，最多一次）：文字或素材卡从画外高速砸入，落点画面轻震 3–6 像素，配一个短促音效。
- 脚本：能。
- 检查：静音看第一秒就知道这条讲什么；字在 0.5 秒内读得清。
- 常见错误：开场字太长；砸入后震动太久。
- 状态：试用
- 来源：video-talkcraft（lead-word-zoom-assemble、impact-open-title）、video-shotcraft（slam-entrance-moves、impact-feedback）2026-10-28

### 章节卡与进度
- 思路：长口播分成几段时，让观众知道「现在讲到第几步、还有几步」。
- 用在：60 秒以上、分 3 段以上的讲解片。
- 不用在：30 秒以内的短片；带货片（打断节奏）。
- 做法：
  - 色块章节卡：全屏色块 0.3 秒扫入，章节编号先落位，章节名随后用遮罩揭开；停约 1.2 秒后色块同向扫出，切回口播。每章一种主题色，全片色系统一。
  - 进度列表：几条章节依次滑入，站定后只有当前这一条换强调色并往前一步。
  - 标题降格成标签：章节标题先在中央出现、站稳约 0.7 秒，然后缩到约 40% 并飞到左上角，变成这一段的小标签，留在画面上直到下一章。
- 脚本：能。可沉淀为 `title-card` 的章节变体。
- 检查：章节卡总长不超过 2.5 秒；当前章节一眼可辨。
- 常见错误：章节卡太长打断节奏；每章样式不一样。
- 状态：试用；**已有模板** `chapter-card`（章节转场）、`chapter-list`（章节进度）
- 来源：video-talkcraft（chapter-title-card、chapter-progress-list、title-demote-to-label）、video-shotcraft（paper-title-card、title-demote-to-label）2026-10-28

### 关注引导卡
- 思路：结尾的关注引导做成一个「点关注」的小动作，比口头喊更自然。
- 用在：角色账号的片尾最后 2–3 秒。
- 不用在：带货片的下单引导时段（引导只留一个）；片中。
- 做法：账号资料卡弹入（约 0.6 秒，轻微过冲），头像、昵称、简介按阅读顺序错开淡入；光标沿弧线移到「关注」按钮，点击那一帧按钮变成已关注状态并荡开一圈涟漪。头像、昵称用账号真实信息，粉丝数不写或写真实值，不做假增长。
- 脚本：能。
- 检查：在安全区内，不被平台按钮挡；总长不超过 3 秒。
- 常见错误：用别的平台的界面样式；伪造粉丝数。
- 状态：试用；**模板候选**（字段：头像、昵称、简介）
- 来源：video-talkcraft（douyin-follow-card、x-follow-card、subscribe-cta）2026-10-28
