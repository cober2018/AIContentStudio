# 强调与标注

先读 craft-resolve 的 `choose.md`。标注是为了让观众看向某一处，一个画面同时最多一处标注在动；颜色只用一种强调色。出现时间对准配音说到那处的帧（ASR 对齐）。

### 手绘圈注
- 思路：像有人拿笔在截图或实物上圈一下，观众视线马上被带过去，亲切不生硬。
- 用在：截图、文档、商品细节上要指出一个词、一处部件。
- 不用在：画面已经很乱；同一画面圈三处以上。
- 做法：形状图层画路径 + Trim Paths 的 End 从 0 到 100%，0.4–0.6 秒画完。四种笔触任选一种：
  - 歪椭圆圈：一笔画圈，终点超过起点约 8%，两端交叉才像手画的；圈完被圈的词弹一下（106→100%）。
  - 墨迹下划线：起笔粗、收笔细（Taper 开启，或 Stroke Width 关键帧），0.4–0.5 秒长出来。
  - 荧光笔扫过：半透明黄色矩形用 Scale X 从左到右扫过关键句（0.4–0.8 秒，随语速），混合模式 Multiply，同时其余文字压暗约 30%。
  - 手绘箭头：线条先画出，箭头头部最后出现。
  笔触颜色全片统一。
- 脚本：能（Trim Paths 的 `ADBE Vector Filter - Trim` 属性）。
- 检查：圈和线压在正确位置；画出的速度跟得上口播。
- 常见错误：圈得太正，像软件画的；荧光笔不用混合模式，把字盖住。
- 状态：试用
- 来源：video-talkcraft（hand-drawn-ellipse、scribble-annotation、ink-underline、highlighter-sweep）、video-shotcraft（draw-svg-trace、marker-underline-title）2026-10-28

### 标注线与取景框
- 思路：给部件、参数、界面元素贴上说明，像产品说明书里的引出线；取景框把目标框出来。
- 用在：讲商品结构、参数位置；讲界面上某个按钮。
- 不用在：目标本身已经够大够清楚。
- 做法：
  - 引出线：目标上一个圆点弹出并荡开一圈涟漪（0.2 秒）→ 折线按 45° 或水平拐出（Trim Paths，0.4 秒）→ 线端标签用遮罩揭开（0.25 秒，文字晚 0.1 秒）。三步依次走完。多处标注错开 0.3–0.5 秒。
  - 对角角框：左上和右下两个 L 形角同时从外侧对角方向平移约 20 像素进入，框住标题或目标。
  - 准星咬合：四个 L 角从画外扑向目标，先停在约 2 倍目标大小，再收到略小于目标（约 94%）后回弹到 100%；咬合那一帧目标轻微提亮，标签同时弹出。科技感强，只在讲界面、数据时用。
- 脚本：能。
- 检查：标签不压住目标；线条和标签在安全区内。
- 常见错误：标注线交叉；多处标注同时出现。
- 状态：试用
- 来源：video-talkcraft（callout-line-label、converging-arrows、corner-bracket-frame、reticle-lock-on）、video-shotcraft（fui-hud-moves、scan-bracket-sweep）2026-10-28

### 聚焦压暗与扫描点名
- 思路：画面信息多时，讲到哪里哪里亮，其余压暗，观众视线被押着走。
- 用在：一张截图、清单、界面上要按顺序讲几处。
- 不用在：只讲一处（用圈注或标注线）。
- 做法：
  - 聚焦压暗：上面加一层黑色纯色层，不透明度约 40%，用遮罩挖出目标位置并给目标加发光描边；讲到下一处时遮罩路径用约 0.2 秒滑过去；讲完 0.4 秒恢复全亮。
  - 扫描点名：一条强调色细线自上而下匀速（线性，不缓动）扫过画面，扫过每个目标的那一刻，取景框从约 175% 收拢对准它，右侧标注晚 5 帧淡入并留下。一次扫完点出几处。
  - 聚光显影：暗场里一束光（径向渐变遮罩）扫过，扫到的地方亮起。只用在开场或揭晓。
- 脚本：能（遮罩路径关键帧 `ADBE Mask Shape`）。
- 检查：亮区跟着口播走；压暗后其余内容仍能辨认。
- 常见错误：压得太暗，像黑屏；亮区移动比口播慢。
- 状态：试用
- 来源：video-talkcraft（focus-dim-spotlight、scanline-annotate）、video-shotcraft（scanline-annotate-focus、spotlight-sweep-moves、light-play-moves、spotlight-hero-card）2026-10-28

### 局部放大镜
- 思路：细节太小看不清时，不放大整个画面，而是把那一小块放大到旁边，原图保留做参照。
- 用在：截图里的小字、商品上的小标识、人物手里的小物件。
- 不用在：素材分辨率不够、放大后糊掉；空白区不够放。
- 做法：
  - 放大镜：复制素材层，圆形遮罩只留目标区域，放大约 180%，移到旁边空白处，加 2 像素深灰细描边（不加投影）；原图同一帧压暗约 30%，原处留一圈细框，连接线随后从放大镜画回原处。弹出约 0.3 秒。
  - 画中画取景：细描边取景框先出现在目标上停一拍，再带着框里的画面平移放大到空白处（约 0.5 秒），落位时变成白边卡片。
- 脚本：能。
- 检查：放大后的内容清楚可读；连接关系一眼看懂。
- 常见错误：放大镜挡住其他要讲的内容；放大倍数太小。
- 状态：试用
- 来源：video-talkcraft（magnifier-detail、pip-zoom-box）2026-10-28
